# 3-1 類別

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡，刪掉 Node.js `util.inherits` 的舊寫法，補上 2017 年之後加入的類別欄位、`#` 私有成員（ES2022）、`static` 區塊。原型鏈怎麼運作見 [1-3-3](./1-3-3.md)。
:::

### 3-1-1 基本語法 {#3-1-1}

`class` 是建構函式加原型的語法糖，但多了幾個保護：

```js
class Fruit {
  pieces = 1 // 類別欄位（ES2022）：每個實例各自一份

  constructor(name, calories) {
    this.name = name
    this.calories = calories
  }

  chop() { this.pieces++ } // 方法之間不加逗號；方法放在原型上，所有實例共用

  bite(person) {
    if (this.pieces < 1) return
    const calories = this.calories / this.pieces
    person.satiety += calories
    this.calories -= calories
    this.pieces--
  }
}
const apple = new Fruit('apple', 140)
```

| 和 ES5 建構函式的差別 | 說明 |
| --- | --- |
| 不會提升 | 宣告前使用會丟 `ReferenceError`（TDZ），函式宣告則可以 |
| 一定要 `new` | 直接呼叫 `Fruit()` 會丟 `TypeError` |
| 內部自動嚴格模式 | 方法被單獨取出呼叫時，`this` 是 `undefined` |
| 方法不可列舉 | `for...in` 不會列出原型上的方法 |

類別也可以寫成運算式，甚至由函式動態產生：

```js
const createPersonClass = (name) =>
  class extends Person {
    constructor() { super(name) }
  }
const JakePerson = createPersonClass('Jake')
```

### 3-1-2 存取器、靜態成員、私有成員 {#3-1-2}

```js
class Counter {
  #count            // 私有欄位：類別外部完全存取不到（不是命名慣例，是語言保證）
  static instances = 0

  static { /* static 區塊：類別建立時執行一次，可做複雜的初始化 */ }

  constructor(start = 0) {
    this.#count = start
    Counter.instances++
  }

  get next() { return this.#count++ } // getter：當屬性讀取
  set value(v) {                       // setter：當屬性賦值時執行，可以做驗證
    if (!Number.isInteger(v)) throw new TypeError('必須是整數')
    this.#count = v
  }

  static isCounter(x) { return #count in x } // 判斷物件有沒有這個私有欄位（ES2022）
}

const c = new Counter(2)
c.next // 2
c.next // 3
c.#count // SyntaxError
```

getter／setter 適合把某個儲存區包成屬性，例如：

```js
class LocalStore {
  constructor(key) { this.key = key }
  get data() { return JSON.parse(localStorage.getItem(this.key)) }
  set data(v) { localStorage.setItem(this.key, JSON.stringify(v)) }
}
const ls = new LocalStore('groceries')
ls.data = ['apples', 'bananas'] // 自動存成 JSON
```

靜態方法（`static`）屬於類別本身，用 `Counter.isCounter()` 呼叫，常用於工廠方法、工具函式。

### 3-1-3 繼承 {#3-1-3}

```js
class Banana extends Fruit {
  constructor() {
    super('banana', 105) // 一定要先呼叫 super，之後才能用 this
    this.pieces = 12
  }
  slice() { this.pieces++ }
  bite(person) {
    console.log('咬一口香蕉')
    super.bite(person) // 呼叫父類別的同名方法
  }
}
```

ES5 要自己寫 `Banana.prototype = Object.create(Fruit.prototype)`、修正 `constructor`、在建構函式裡 `Fruit.call(this, …)`，`extends` 把這些都包了。靜態成員也會一起繼承。

`extends` 後面可以是任何回傳建構函式的運算式，所以能做 **mixin**：

```js
const Serializable = (Base) => class extends Base {
  toJSON() { return { ...this } }
}
class Plum extends Serializable(Fruit) {}
```

也能繼承內建物件：`class MyArray extends Array {}`、`class AppError extends Error {}`。
