# 17-4 Array.prototype.findLast {#17-4}

`Array` 實例的 `findLast()` 方法以相反的順序迭代陣列，並回傳滿足所提供的測試函數的第一個元素的值。如果沒有元素滿足測試功能，則回傳 undefined。

假如你需要找：

- 第一個匹配的元素，使用 [`find()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/find) 。
- 陣列中最後一個匹配元素的索引，使用 [`findLastIndex()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/findLastIndex) .
- 值的索引，使用 [`indexOf()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/indexOf) 。 （它類似於 [`findIndex()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/findIndex) ，但檢查每個元素是否與值相等，而不是使用測試函數。）
- 陣列中是否存在某個值，請使用 [`includes()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/includes) 。同樣，它檢查每個元素是否與值相等，而不是使用測試函數。
- 如果任何元素滿足提供的測試功能，請使用 [`some()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/some) .

```js
const array1 = [5, 12, 50, 130, 44];

const found = array1.findLast((element) => element > 45);

console.log(found);
// Expected output: 130
```

### 語法

```js
findLast(callbackFn)
findLast(callbackFn, thisArg)
```

### 回傳值

陣列中索引值最高且滿足以下條件的元素的值提供測試功能；如果未找到匹配元素，則 `undefined` 。

### 說明

`findLast()` 方法是一種迭代方法。它按降序索引順序為陣列中的每個元素調用一次提供的 `callbackFn` 函數，直到 `callbackFn` 回傳 `truthy` 。 `findLast()` 然後回傳該元素並停止遍歷陣列。如果 `callbackFn` 從不回傳 `truthy` ，則 `findLast()` 回傳 `undefined` 。

為陣列的每個索引調用 `callbackFn` ，而不僅僅是那些具有指定值的索引。 [稀疏陣列](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Indexed_collections#sparse_arrays) 中的空槽的行為與 `undefined` 相同。

`findLast()` 不會改變調用它的陣列，但作為 `callbackFn` 提供的函數可以。但請注意，陣列的長度是在第一次調用 `callbackFn` 之前保存的。所以：

- 當調用 `findLast()` 開始時， `callbackFn` 不會訪問超出陣列初始長度的任何元素。
- 給已訪問過的索引重新賦值將不會被 `callbackFn` 重新訪問。
- 如果 `callbackFn` 更改了陣列中現有的、尚未訪問的元素，則傳遞給 `callbackFn` 的其值將是該元素被訪問時的值。訪問 [已刪除](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/delete) 的元素就好像它們 `undefined` 一樣。

::: warning 注意
上一段描述的並發修改的情況經常導致難以理解的代碼，通常應該避免（特殊情況除外）。
:::

`findLast()` 方法是通用的。它只期望 `this` 值具有 `length` 屬性和整數鍵的屬性。

### 範例：

### Find last object in an array matching on element properties 查找陣列中與元素屬性匹配的最後一個物件

此範例顯示如何根據陣列元素的屬性創建測試。

```js
const inventory = [
  { name: "apples", quantity: 2 },
  { name: "bananas", quantity: 0 },
  { name: "fish", quantity: 1 },
  { name: "cherries", quantity: 5 },
];

// return true inventory stock is low
function isNotEnough(item) {
  return item.quantity < 2;
}

console.log(inventory.findLast(isNotEnough));
// { name: "fish", quantity: 1 }
```

### Using arrow function and destructuring 使用箭頭函數和解構

前面的範例可以使用箭頭函數和物件解構來編寫：

```js
const inventory = [
  { name: "apples", quantity: 2 },
  { name: "bananas", quantity: 0 },
  { name: "fish", quantity: 1 },
  { name: "cherries", quantity: 5 },
];

const result = inventory.findLast(({ quantity }) => quantity < 2);

console.log(result);
// { name: "fish", quantity: 1 }
```

### Find the last prime number in an array 查找陣列中的最後一個質數

以下範例回傳陣列中最後一個質數元素，如果不存在質數則回傳 `undefined` 。

```js
function isPrime(element) {
  if (element % 2 === 0 || element < 2) {
    return false;
  }
  for (let factor = 3; factor <= Math.sqrt(element); factor += 2) {
    if (element % factor === 0) {
      return false;
    }
  }
  return true;
}

console.log([4, 6, 8, 12].findLast(isPrime)); // undefined, not found
console.log([4, 5, 7, 8, 9, 11, 12].findLast(isPrime)); // 11
```

### Using findLast() on sparse arrays

稀疏陣列中的空槽會被訪問，並被視為與 `undefined` 相同 .

```js
// Declare array with no elements at indexes 2, 3, and 4
const array = [0, 1, , , , 5, 6];

// Shows all indexes, not just those with assigned values
array.findLast((value, index) => {
  console.log(`Visited index ${index} with value ${value}`);
});
// Visited index 6 with value 6
// Visited index 5 with value 5
// Visited index 4 with value undefined
// Visited index 3 with value undefined
// Visited index 2 with value undefined
// Visited index 1 with value 1
// Visited index 0 with value 0

// Shows all indexes, including deleted
array.findLast((value, index) => {
  // Delete element 5 on first iteration
  if (index === 6) {
    console.log(`Deleting array[5] with value ${array[5]}`);
    delete array[5];
  }
  // Element 5 is still visited even though deleted
  console.log(`Visited index ${index} with value ${value}`);
});
// Deleting array[5] with value 5
// Visited index 6 with value 6
// Visited index 5 with value undefined
// Visited index 4 with value undefined
// Visited index 3 with value undefined
// Visited index 2 with value undefined
// Visited index 1 with value 1
// Visited index 0 with value 0
```

### Calling findLast() on non-array objects 在類陣列物件中使用 findLast()

`findLast()` 方法讀取 `this` 的 `length` 屬性，然後訪問每個屬性 其鍵是小於 `length` 的非負整數。

```js
const arrayLike = {
  length: 3,
  0: 2,
  1: 7.3,
  2: 4,
  3: 3, // ignored by findLast() since length is 3
};
console.log(
  Array.prototype.findLast.call(arrayLike, (x) => Number.isInteger(x)),
); // 4
```
