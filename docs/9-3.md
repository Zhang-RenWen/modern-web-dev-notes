# 9-3 簡化語法與物件解構賦值

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017），已精簡。
:::

**屬性簡寫和解構常常一起出現**：從輸入解構出需要的欄位，處理後再用簡寫組成輸出。

```js
function getGroceryModel({ name, unitPrice }, units) {
  return { name, unitPrice, units, totalPrice: unitPrice * units }
}
```

什麼時候解構、什麼時候直接用 `obj.prop`：

| 情況 | 建議 |
| --- | --- |
| 同一個物件的好幾個欄位、用了好幾次 | 解構，省掉重複的物件名稱 |
| 只用一個欄位一次 | 直接 `model.name`，解構反而多一行，讀者還要往上找變數從哪來 |
| 函式回傳值只需要其中幾個欄位 | 解構：一眼看出呼叫端在意哪些輸出 |
| 函式參數 | 參數是選項物件時解構並給預設值；但函式內部要把整個物件傳下去時，就保留原本的物件 |

```js
const { name, units, unitPrice, totalPrice } = getGroceryModel(tomato, 4)
const summary = `${units}x ${name} ($${unitPrice}) = $${totalPrice}` // '4x Tomato ($1.25) = $5'

const label = `This is a ${model.name} summary` // 只用一次，不用解構
```

解構太深（`const { a: { b: { c } } } = obj`）既難讀，中間任何一層是 `undefined` 還會直接報錯；這時改用 `obj.a?.b?.c`。
