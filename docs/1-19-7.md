# 1-19-7 傳輸層與 HTTP Security Headers {#1-19-7}

::: info 新增（2026-11）
整理自 Notion「資安」第 2.7 節。
:::

- 檢測：[SSL Labs](https://www.ssllabs.com/ssltest/)（TLS 版本與 cipher）、[securityheaders.com](https://securityheaders.com/)（headers）。
- TLS：關閉 TLS 1.0/1.1 與弱 cipher；Windows/IIS 可用 [IIS Crypto](https://www.nartac.com/Products/IISCrypto/Download)。⚠️ 需重開機、可能影響內部系統間連線，先從最弱的演算法關起並在測試環境驗證。
- 建議 headers（IIS `web.config` 範例，已修正原筆記錯誤）：

```xml
<system.webServer>
  <httpProtocol>
    <customHeaders>
      <!-- 原筆記 max-age=0 等於「關閉」HSTS，改為一年 -->
      <add name="Strict-Transport-Security" value="max-age=31536000; includeSubDomains" />
      <add name="X-Content-Type-Options" value="nosniff" />
      <add name="Referrer-Policy" value="strict-origin-when-cross-origin" />
      <!-- 原筆記只限制 img-src，幾乎沒有防 XSS 效果；frame-ancestors 取代 X-Frame-Options -->
      <add name="Content-Security-Policy" value="default-src 'self'; img-src 'self' https: data:; object-src 'none'; base-uri 'self'; frame-ancestors 'self'" />
      <!-- Feature-Policy 已淘汰，改用 Permissions-Policy -->
      <add name="Permissions-Policy" value="camera=(), microphone=(), geolocation=(), usb=()" />
      <add name="X-Frame-Options" value="SAMEORIGIN" />
    </customHeaders>
  </httpProtocol>
</system.webServer>
```

- CSP 上線前先用 `Content-Security-Policy-Report-Only` 觀察，避免擋掉自家 script。
