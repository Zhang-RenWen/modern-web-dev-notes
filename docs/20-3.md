# 20-3 Math.sumPrecise() {#20-3}

精確地加總一組數字。一般用 `reduce()` 逐一相加時，每加一次就會四捨五入一次，誤差會累積；`Math.sumPrecise()` 會先算出完全精確的總和，最後只四捨五入一次。

```js
const values = [0.1, 0.2, 0.3]

values.reduce((a, b) => a + b, 0) // 0.6000000000000001
Math.sumPrecise(values) // 0.6
```

數量級差很多時，差異更明顯：

```js
const values2 = [1e20, 0.1, -1e20]

values2.reduce((a, b) => a + b, 0) // 0，0.1 在加到 1e20 時就被吃掉了
Math.sumPrecise(values2) // 0.1
```

### 注意事項

- 參數是**可迭代物件**（例如陣列、Set），不是展開的參數列：寫 `Math.sumPrecise([1, 2])`，不是 `Math.sumPrecise(1, 2)`。
- 元素必須都是數字，否則會拋出 `TypeError`（不會自動轉型，`'1'` 也不行）。
- 空的可迭代物件回傳 `-0`。
- 這是 ES2026 中支援最晚推出的功能之一，例如 Node.js 26 仍需加上 `--js-staging` 旗標才能使用。
- 它解決的是「加總過程中」的誤差，`0.1` 本身無法以二進位浮點數精確表示的問題仍然存在。處理金額等需要十進位精確度的情境，還是應該用整數（例如以「分」為單位）計算。
