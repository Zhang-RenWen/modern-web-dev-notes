# 9-4 其餘展開運算子

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017），已精簡，淺拷貝補上 `structuredClone`。
:::

**陣列解構取比對結果**：跳過第一個（整段比對），直接拿群組。

```js
const [, integer, fractional] = /(\d+)\.(\d+)/.exec('1234.56')
// 或用具名群組：const { integer, fractional } = /(?<integer>\d+)\.(?<fractional>\d+)/.exec(s).groups
```

**合併陣列**：展開比 `concat` 好讀，也能在中間插入單一元素。

```js
const everyone = [...administrators, ...moderators, bob]
```

**合併物件、產生修改過的新物件**（不改原物件）：

```js
const options = { ...defaults, ...userOptions, important: true }

const castHealingSpell = (player) => ({
  ...player,
  mana: player.mana - 40,
  health: player.health + 110,
})
```

不可變的更新方式是 React、Redux 判斷「有沒有變」的基礎。巢狀很深時，每一層都要展開，可以改用 Immer 或 ES2023 的 `arr.with()`／`toSorted()` 這類不改原陣列的方法。

**淺拷貝的幾種寫法**（都只複製第一層）：

```js
const a = { ...obj }
const b = Object.assign({}, obj)
const c = [...arr]       // 或 arr.slice()
const deep = structuredClone(obj) // 需要深拷貝時
```

**其餘屬性**：把已知欄位和其他欄位分開，例如元件把自己用到的 props 取出，其餘的傳給底層元素。

```js
function Button({ variant, children, ...rest }) {
  return <button className={variant} {...rest}>{children}</button>
}
```
