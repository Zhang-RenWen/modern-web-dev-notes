# About

這裡是我的前端開發個人筆記，用來整理、記錄自己學過的前端工程知識。讀到的觀念盡量都會實際寫程式驗證，並把結果一起記下來。

## 內容涵蓋

- **第 1 章 前端工程通用知識點**：依主題分成 3 個部分：
  - **網頁前端基礎**：HTML、CSS、JavaScript 核心、TypeScript、瀏覽器原理、效能調校。
  - **前端框架與工程化**：前端框架原理、前端架構與實戰、前端工程化、視覺與動畫。
  - **瀏覽器網路與前端資安**：瀏覽器網路 API 與即時通訊、前端資安。
- **第 2～9 章 ES6 與實務應用**：類別、符號、迭代與流程控制、集合、代理器、內建功能優化、模組，以及實務上的使用考量。
- **新標準 ES2016～ES2026**：逐年整理 ECMAScript 的新語法，每項功能都附上範例。
- **模擬面試**：依主題整理的前端面試題庫，每題附解題思路、標準答案與相關筆記連結；Event Loop、原型鏈、渲染管線、快取、CORS 等原理題附可逐步播放的動畫解析。
