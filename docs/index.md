# About

這裡是我的前端開發個人筆記，用來整理、記錄自己學過的前端工程知識。讀到的觀念盡量都會實際寫程式驗證，並把結果一起記下來。

## 內容涵蓋

- **第 1 章 前端工程通用知識點**：HTML5 & CSS3、JavaScript 核心、瀏覽器運作、效能調校、設計模式、程式架構、資料結構與演算法、數學基礎、網路架構、資安議題與常見面試題。
- **第 2～9 章 ES6 與實務應用**：類別、符號、迭代與流程控制、集合、代理器、內建功能優化、模組，以及實務上的使用考量。
- **新標準 ES2016～ES2026**：逐年整理 ECMAScript 的新語法，每項功能都附上範例。
