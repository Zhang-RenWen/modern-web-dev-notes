## DDD：Cycle Time 去哪了？ {#1-22-10-1}

課堂上用 CardCreated、CardMoved、CardDeleted 三個 domain event 計算 Cycle Time Report，Command Model 不需要 CycleTimeLog 物件。學生問：那領域模型不就少了「Cycle Time」這個看板領域的重要概念？

回答：它沒有消失，而是出現在 **Query Model**（CycleTimeDto）。Cycle Time 是「分析性 / 觀測性」概念，不是「行為性」概念——後者才會出現在 Command Model。**Ubiquitous Language 屬於整個 Bounded Context，不屬於某一個 model；Command Model 與 Query Model 只是同一套語言的兩種投影。**

## 學習優先順序 {#1-22-10-3}

1. **資料庫與後端交易**：schema、transaction、ACID / isolation level、audit log、append-only、migration、backup / restore、idempotency。
2. **API 與效能**：API design、pagination、cache、connection pool、async、rate limit、retry / timeout、queue / worker。
3. **Auth / 權限 / 安全**：session、cookie、JWT、OAuth 2.0 / OIDC、SSO、OTP、trusted device、RBAC。
4. **部署與維運**：Docker、Nginx、Cloudflare、CI/CD、logging、monitoring、rollback。
5. **架構模式**（有真系統長出問題後再學）：DDD、Hexagonal、Modular Monolith、Microservices、Event-driven、Outbox、Saga、CQRS。

CS 基礎優先序：**資料結構 → Big-O → Graph → DB Modeling → Distributed Systems**；其次 Algorithm、OS、Network、Concurrency、機率（P95/P99、容量規劃）；線代只有 AI / 推薦 / 搜尋才重要。學的時候反問應用：Hash 在 index / cache / 去重哪裡用？Graph 怎麼表示服務依賴與權限？資料從 10 萬變 1 億，哪裡先炸？

## 作品方向 {#1-22-10-4}

- **Online Banking**：登入驗證、帳戶、轉帳、餘額不可為負、DB transaction、append-only ledger、權限、審計紀錄——貼合金融背景。
- **企業文件知識庫（RAG）**：Vue / React + Fastify + PostgreSQL + pgvector + Embedding + RBAC + Chunking + 來源引用。
- 架構演進示範：Reverse Proxy → App → 獨立 DB（備份、監控）→ LB + 多 App + Redis + Read Replica → Queue / Worker / Reporting DB。**Minimum Viable Architecture + Evolution Path。**
