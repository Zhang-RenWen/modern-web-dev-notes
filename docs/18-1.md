## 18-1 Object.groupBy() / Map.groupBy() {#18-1}

依據回呼函式的回傳值，把可迭代物件中的元素分組。以前要自己用 `reduce()` 實作，現在有內建方法。

```js
const inventory = [
  { name: 'asparagus', type: 'vegetables', quantity: 5 },
  { name: 'bananas', type: 'fruit', quantity: 0 },
  { name: 'goat', type: 'meat', quantity: 23 },
  { name: 'cherries', type: 'fruit', quantity: 5 },
]

// 以前的寫法
const grouped = inventory.reduce((acc, item) => {
  ;(acc[item.type] ??= []).push(item)
  return acc
}, {})

// ES2024
const result = Object.groupBy(inventory, ({ type }) => type)
console.log(result.fruit)
// [{ name: 'bananas', type: 'fruit', quantity: 0 }, { name: 'cherries', type: 'fruit', quantity: 5 }]
```

`Object.groupBy()` 回傳的是**沒有原型的物件**（`Object.create(null)`），所以不會有 `toString`、`hasOwnProperty` 等繼承屬性，也不會和分組的 key 撞名。

```js
Object.getPrototypeOf(result) // null
Object.hasOwn(result, 'meat') // true
```

### Map.groupBy()

`Object.groupBy()` 的 key 會被轉成字串。如果想用物件或其他型別當作 key，改用 `Map.groupBy()`，它回傳 `Map`。

```js
const restock = { restock: true }
const sufficient = { restock: false }

const map = Map.groupBy(inventory, ({ quantity }) => (quantity < 6 ? restock : sufficient))

console.log(map.get(restock).map((item) => item.name))
// ['asparagus', 'bananas', 'cherries']
console.log(map.get(sufficient).map((item) => item.name))
// ['goat']
```

::: tip 為什麼不是 Array.prototype.groupBy()
這個提案原本打算加在陣列原型上，但因為會和網路上既有網站或函式庫自行在陣列原型上定義的同名方法衝突（Web 相容性問題），最後改成 `Object` / `Map` 的靜態方法。好處是它接受任何可迭代物件，不限於陣列。
:::
