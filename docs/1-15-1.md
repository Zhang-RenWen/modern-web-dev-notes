## 渲染技術定位 {#1-15-1-1}

| 技術 | 適合 |
| --- | --- |
| SVG | 結構化圖形：Logo/Icon、path morph、mask、少量互動圖表、座標軸 |
| Canvas | 2D 即時渲染：K 線、大量資料點、粒子、波形、軌跡 |
| WebGL / Shader | 3D、折射、流體、noise field、大量粒子、GPU 運算 |

- 實際產品混合使用：HTML/CSS 排版 + SVG 圖示座標軸 + Canvas 大量資料 + WebGL 特效。

## 變形效果怎麼判斷 {#1-15-1-2}

- **物件換形狀 → path morphing**（兩個 path 節點結構要一致；不一致用 GSAP MorphSVG 或 flubber）。
- **表面被扭曲 → SVG filter**（`feTurbulence` 產生 noise，`feDisplacementMap` 推像素）。
- **整個畫面流體變形 → WebGL / shader**。
- D3 的本質是**管理「資料狀態 A → 視覺狀態 B」的插值**（`d3.interpolate*`），不是動畫庫；很適合金融圖表讓線、軸、標籤隨資料一起 transition。

```html
<filter id="noise">
  <feTurbulence type="fractalNoise" baseFrequency="0.01" numOctaves="2" />
  <feDisplacementMap in="SourceGraphic" scale="30" />
</filter>
```

## 滾動動畫：跟 AI 溝通直接報名字 {#1-15-1-3}

Scroll-triggered（滑到才播）、Scroll-linked（滑多少動多少）、Parallax（背景慢於前景）、Sticky（黏頂）、Scroll Snap（一次一頁）、Horizontal Scroll（往下滑、內容往旁走）。

## 滾動控制影片播放（得獎網站常見手法） {#1-15-1-4}

- 不用 `video`，而是**圖片序列 + Canvas**：影片匯出全部影格（200+ 張 JPG），全部預載進記憶體。
- Canvas 依 `devicePixelRatio` 放大解析度再 `scale` context，避免模糊；繪製時用 cover 演算法依長寬比裁切置中。
- GSAP ScrollTrigger：`pin: true` + `scrub: true`，在 `onUpdate` 用 progress 算出影格 index 再重繪；預留尾段給 unpin。
- 其他元素依 progress 分段：前 10% 淡出導覽、前 25% 標題往 Z 軸退後並淡出、60–90% 主圖從前方淡入。搭配 Lenis 平滑捲動；resize 時重設 canvas 並 `ScrollTrigger.refresh()`。

## 動畫與特效工具地圖 {#1-15-1-5}

| 場景 | 工具 |
| --- | --- |
| 基本功（95% 專案） | CSS transition / keyframes、IntersectionObserver、requestAnimationFrame |
| Landing 滑入、時間軸、滾動 | GSAP + ScrollTrigger、Framer Motion（React） |
| AE 動畫、動態 icon | Lottie、Rive |
| 路徑描邊、文字拆解 | SVG path + Anime.js |
| 2D 高效能 | PixiJS、Canvas |
| 3D 產品展示、粒子 | Three.js + GLTF、GLSL shader |
