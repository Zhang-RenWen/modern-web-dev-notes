# 1-12-4 線性代數的幾何直覺 {#1-12-4}

::: info 新增（2026-11）
整理自 Notion「計算機基礎」第 12 節〈數學工具箱〉的「線性代數：用幾何直覺學，不是矩陣算術」。
:::

- **為什麼需要**：人腦擅長單變量；現實系統（天氣、橋梁、推薦）有成千上萬互相影響的變數，線代把它們打包成 $Ax=b$：x 是狀態向量、A 是規則矩陣。
- **向量＝空間中的狀態；矩陣＝對空間的變換**（旋轉、縮放、剪切）。「線性」＝原點不動、直線仍是直線、平行仍平行。
- $AB$＝先做 B 再做 A，所以 $AB \neq BA$（先左轉再前進 ≠ 先前進再左轉）。
- **行列式＝變換後體積的縮放比**；det＝0 → 空間被壓扁、資訊丟失 → 不可逆，所以沒有反矩陣。**Rank＝變換後保留的真實維度。**
- **齊次座標**：平移會移動原點，不是線性變換；加一個 w 維、用 4×4 矩陣，就能把平移也寫成矩陣乘法 → 圖學永遠用 4×4。GPU 的本事就是大量並行做這種矩陣乘法。
- **神經網路每層**：$y = Wx + b$＋非線性激活函數；「千億參數」＝權重矩陣裡的數字；訓練＝用梯度下降調整這些數字。深度學習日常最痛的是張量 shape 對不上。
- **特徵向量＝變換後方向不變的向量 → 系統的內在趨勢。**PageRank＝求網頁轉移機率矩陣的主特徵向量；橋梁的固有振動模式也是特徵值問題（Tacoma 海峽大橋共振崩塌）。
- **SVD**：把巨大稀疏的「用戶 × 商品」矩陣拆出潛在特徵 → 推薦系統、協同過濾的老祖宗。
- 實感：看不懂「矩陣狀態轉移」的 code，就是缺這塊；計算機圖學 3D 繪圖更是滿滿矩陣。
- **學習路線**：3Blue1Brown《線性代數的本質》建直覺 → Gilbert Strang MIT 18.06 理解四個基本子空間、正交投影與最小平方法 → fast.ai《Computational Linear Algebra》用 NumPy／PyTorch 實作。練習題：用 SVD 壓縮一張照片，看丟掉小奇異值後變多模糊。
