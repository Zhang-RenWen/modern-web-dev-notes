# 19-6 RegExp 修飾符 {#19-6}

可以只在正規表示式的**某一段**開啟或關閉旗標，不必套用到整個表達式。支援的旗標有 `i`（忽略大小寫）、`m`（多行）、`s`（dotAll）。

- `(?i:...)`：只在這個群組內開啟 `i`
- `(?-i:...)`：只在這個群組內關閉 `i`
- `(?i-m:...)`：同時開啟 `i`、關閉 `m`

```js
// 只有 hello 忽略大小寫
const re = /^(?i:hello) world$/

re.test('HELLO world') // true
re.test('HELLO WORLD') // false
```

```js
// 整體忽略大小寫，但第二個字元必須是小寫
const re2 = /^[a-z](?-i:[a-z])$/i

re2.test('ab') // true
re2.test('Ab') // true
re2.test('aB') // false
```

### 實際應用

當正規表示式是由多個片段組合而成，而各片段需要不同的比對規則時特別有用。例如 HTTP 標頭名稱不分大小寫，但值要區分大小寫：

```js
const contentType = /^(?i:content-type): application\/json$/

contentType.test('Content-Type: application/json') // true
contentType.test('content-type: application/json') // true
contentType.test('Content-Type: Application/JSON') // false
```
