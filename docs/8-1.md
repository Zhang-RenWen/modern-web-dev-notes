## 8-1 CommonJS

Node.js 原本的模組系統：**每個檔案就是一個模組**，有自己的作用域，用 `module.exports` 匯出、`require` 匯入。

```js
// union.js
module.exports = function union(...arrays) {
  return [...new Set(arrays.flat())]
}

// app.js
const union = require('./union.js')
console.log(union([1, 2], [2, 3])) // [1, 2, 3]
```

- 匯出多個值：`module.exports = { a, b }` 或 `exports.a = a`（不能 `exports = { … }`，那只是改了區域變數）。
- `require` 是**同步**執行的普通函式，可以寫在 `if` 裡、用變數組路徑（所以打包工具很難做 tree shaking）。
- 第一次 `require` 時執行模組並快取結果，之後再 `require` 拿到的是同一份。
- 可以省略副檔名 `.js`、`.json`，但建議寫出來，路徑解析比較快也比較清楚。

**用統一的介面動態載入**：例如每個樣板模組都匯出 `(model) => html`，就能用一個函式依名稱載入：

```js
// render.js
module.exports = (template, model) => require(`./views/${template}.js`)(model)

// app.js
const render = require('./render.js')
render('list', { items })
```

這種「依變數決定載入哪個檔案」的寫法在 ES Module 裡要改用 `import()`，打包工具會把整個 `views/` 資料夾都打包進來。

新專案在 Node.js 也用 ES Module（`package.json` 加 `"type": "module"`）；CommonJS 主要出現在舊專案與設定檔。兩者互相引用的規則見 [1-9-1](./1-9-1.md#1-9-1-4)。
