# 18-5 可調整大小的 ArrayBuffer 與 ArrayBuffer transfer {#18-5}

ES2024 同時加入兩個和 `ArrayBuffer` 有關的功能：可以在原地調整大小，以及可以「轉移」緩衝區的所有權。

### 可調整大小的 ArrayBuffer

建立時傳入 `maxByteLength`，之後就能用 `resize()` 在上限內調整大小，不必重新配置再複製資料。

```js
const buffer = new ArrayBuffer(8, { maxByteLength: 16 })

buffer.resizable // true
buffer.byteLength // 8
buffer.maxByteLength // 16

buffer.resize(12)
buffer.byteLength // 12

buffer.resize(32) // RangeError：超過 maxByteLength
```

不指定長度建立的 TypedArray 會**自動追蹤**緩衝區大小：

```js
const view = new Uint8Array(buffer)
view.length // 12

buffer.resize(16)
view.length // 16
```

`SharedArrayBuffer` 也支援類似功能，但只能變大：

```js
const shared = new SharedArrayBuffer(8, { maxByteLength: 16 })
shared.growable // true
shared.grow(16)
```

### ArrayBuffer transfer

`transfer()` 會把內容移到一個新的 `ArrayBuffer`，原本的緩衝區變成「已分離」（detached），長度歸零、無法再使用。引擎通常可以直接搬移底層記憶體，不必複製。

```js
const original = new ArrayBuffer(8)
const moved = original.transfer()

original.detached // true
original.byteLength // 0
moved.byteLength // 8

// 轉移時可以同時改變長度
const bigger = moved.transfer(16)
bigger.byteLength // 16

// 把可調整大小的緩衝區轉成固定長度
const resizable = new ArrayBuffer(8, { maxByteLength: 16 })
const fixed = resizable.transferToFixedLength()
fixed.resizable // false
```

適合用在「把資料交給別人之後，自己就不該再碰」的情境，例如把緩衝區傳給其他函式或模組處理，避免雙方同時修改同一份資料。
