# 3-4 修飾器

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017），原文介紹的是 2018 年以 descriptor 為基礎的提案，那套設計**已被廢棄**。已改寫成 2022 年進入 Stage 3 的新版修飾器：TypeScript 5.0 起支援，截至 2026 年仍在 Stage 3，瀏覽器尚未原生支援，要透過 TypeScript 或 Babel 轉譯。
:::

### 3-4-1 修飾器是什麼 {#3-4-1}

修飾器是一個函式，寫在 class 或 class 成員前面，用來**替換或包裝**被修飾的東西。概念上就是高階函式的語法糖：

```js
class View {
  @throttle(200) // 最多每 200ms 執行一次
  reconcile() {}
}
// 大致等同：View.prototype.reconcile = throttle(200)(View.prototype.reconcile)
```

`@` 後面可以是識別字、屬性存取（`@decorators.frozen`）、函式呼叫（`@speed('fast')`），或用括號包起來的任意運算式。

### 3-4-2 新版 API {#3-4-2}

修飾器函式收到兩個參數：被修飾的值，以及描述它的 `context`。

```js
function logged(method, context) {
  // context.kind：'class'、'method'、'getter'、'setter'、'field'、'accessor'
  // context.name：成員名稱；context.static、context.private：是否靜態、私有
  return function (...args) {
    console.log(`呼叫 ${String(context.name)}`, args)
    return method.apply(this, args) // 回傳的函式會取代原本的方法
  }
}

class Calculator {
  @logged
  add(a, b) { return a + b }
}
```

| 修飾對象 | 收到的 value | 可以回傳 |
| --- | --- | --- |
| class | class 本身 | 新的 class（例如加上 mixin） |
| 方法、getter、setter | 函式 | 取代用的函式 |
| 欄位 | `undefined` | 初始化函式：`(initialValue) => 新的初始值` |
| `accessor` 欄位 | `{ get, set }` | 新的 `{ get, set, init }`，可以攔截讀寫 |

```js
// 自動綁定 this：在每個實例建立時把方法 bind 到實例上
function bound(method, context) {
  context.addInitializer(function () {
    this[context.name] = method.bind(this)
  })
}

// accessor：讀寫時自動驗證
function positive({ get, set }) {
  return {
    get,
    set(v) {
      if (v < 0) throw new RangeError('必須是正數')
      set.call(this, v)
    },
  }
}
class Account {
  @positive accessor balance = 0
}
```

### 3-4-3 疊加多個修飾器 {#3-4-3}

```js
class Lamborghini {
  @expensive
  @speed('fast')
  drive() {}
}
```

由下往上（由內往外）套用：先 `speed('fast')`，再 `expensive`。修飾器只能用在 class 和 class 成員上，不能用在一般函式或物件實字。

### 3-4-4 實務上的使用情境 {#3-4-4}

- **框架**：Angular 的 `@Component`、`@Input`；NestJS 的 `@Controller`、`@Get`；MobX 的 `@observable`；Lit 的 `@property`。
- **橫切關注點**：記錄、計時、快取（memoize）、節流、權限檢查，不用改方法本身的程式碼。
- **中繼資料**：`context.metadata`（搭配 `Symbol.metadata`）讓修飾器在 class 上記錄資訊，例如欄位的驗證規則，之後由驗證函式統一讀取。這個功能類似 C# 的 Attributes、Java 的 Annotations。

::: warning 新舊兩套修飾器不相容
Angular、NestJS、TypeORM 等很多套件仍使用 TypeScript 舊版的 `experimentalDecorators`（參數是 `target, key, descriptor`），和標準修飾器的寫法與行為都不同，同一個專案只能選一種。寫新的修飾器時先確認專案用的是哪一套。
:::
