# 19-8 Float16Array 與 Math.f16round() {#19-8}

新增 16 位元（半精度）浮點數的支援：

- `Float16Array`：新的 TypedArray，與既有的 `Float32Array`、`Float64Array` 並列。
- `Math.f16round()`：把數字四捨五入到最接近的半精度浮點數，類似既有的 `Math.fround()`（32 位元）。
- `DataView.prototype.getFloat16()` / `setFloat16()`：讀寫二進位資料中的半精度浮點數。

```js
const f16 = new Float16Array([1.5, 0.1, 65504, 70000])

console.log(f16)
// Float16Array [1.5, 0.0999755859375, 65504, Infinity]

Math.f16round(0.1) // 0.0999755859375
Math.f16round(65504) // 65504，半精度能表示的最大值
```

半精度浮點數只有約 3 位有效數字，可表示的最大值是 65504，超過就會變成 `Infinity`。

```js
const view = new DataView(new ArrayBuffer(2))
view.setFloat16(0, 3.14)
view.getFloat16(0) // 3.140625
```

### 使用情境

精度較低，但記憶體用量只有 `Float32Array` 的一半，傳輸也更快。常見於：

- WebGPU / WebGL 的貼圖與頂點資料
- 機器學習模型的權重（許多模型以 FP16 格式儲存）
- 需要大量儲存、但不需要高精度的數值資料
