## CSS 變數與主題切換 {#1-2-3-1}

CSS 自訂屬性（俗稱 CSS 變數）是瀏覽器原生功能，不需要 Sass。用 `--名稱` 定義、`var(--名稱, 預設值)` 讀取，而且**會繼承、可以在執行時改**，這是預處理器變數做不到的。

```css
:root {
  --bg: white;
  --text: #555;
}
[data-theme='dark'] {
  --bg: #111;
  --text: #eee;
}
main { background: var(--bg); color: var(--text); }
```

```js
document.documentElement.dataset.theme = 'dark' // 切換主題只要改一個屬性
```

<div class="demo-block theme-demo" :class="{ 'pink-theme': pink }">
  <p>CSS 變數主題範例</p>
  <button type="button" @click="pink = !pink">{{ pink ? '切回預設主題' : '切換為粉色主題' }}</button>
</div>

- **跟隨系統深淺色**：`@media (prefers-color-scheme: dark) { :root { … } }`；或宣告 `color-scheme: light dark` 後用 `light-dark(white, #111)` 一行寫兩種值（2024 起全面支援）。
- 主題存在 `localStorage`，在 `<head>` 裡用一小段同步 script 先設好 `data-theme`，避免載入時閃一下預設主題。

## 樣式隔離：CSS Modules 與替代方案 {#1-2-3-2}

**CSS Modules** 不是瀏覽器標準，而是建置工具的功能：編譯時把 class 名稱改成唯一名稱（例如 `.title` → `._title_x7f2a`），樣式就只作用在引用它的元件。

```css
/* Button.module.css */
.base { padding: 4px 12px; }
.primary { composes: base; background: teal; } /* composes：重複使用另一個 class */
```

```js
import styles from './Button.module.css'
button.className = styles.primary // 實際會套上 base 和 primary 兩個唯一名稱
```

Vite、Next.js 內建支援，檔名取 `*.module.css` 就會啟用，不用自己設定 webpack。

其他隔離方式：

| 方式 | 適合 |
| --- | --- |
| Vue `<style scoped>` | Vue 專案，編譯時加 `data-v-xxx` 屬性選擇器 |
| Tailwind 這類 utility class | 不寫自訂 class，樣式直接寫在 HTML，不會互相衝突 |
| Shadow DOM | Web Components，真正的瀏覽器層級隔離（見 [1-1-2](./1-1-2.md#1-1-2-3)） |
| `@layer`（2022 起全面支援） | 不改名稱，而是**控制優先順序**：`@layer reset, base, components, utilities;` 後面的層一定贏前面的層，不用再比選擇器權重或加 `!important` |

## 2023 年後可以直接用的新功能 {#1-2-3-3}

| 功能 | 取代了什麼 |
| --- | --- |
| 原生巢狀 `.card { & .title { … } }` | Sass 最常用的功能 |
| 容器查詢 `@container (min-width: 400px)` | 依「元件所在容器」的寬度調整，同一張卡片放側欄或主區都能自適應；媒體查詢只能看整個視窗 |
| `:has()` | 「父元素依子元素狀態改樣式」以前只能寫 JS，例如 `form:has(:invalid) button { opacity: .5 }` |
| `clamp(1rem, 2.5vw, 2rem)` | 字級隨視窗縮放但有上下限，不用寫一堆斷點 |
| `aspect-ratio: 16 / 9` | 用 `padding-top: 56.25%` 撐比例的技巧 |
| `gap`（Flex 也支援） | 用 margin 排間距再處理最後一個元素 |

## 響應式版面與單位 {#1-2-3-4}

現在的做法：**Flex／Grid 排版 + 相對單位 + 少量媒體查詢 + 元件用容器查詢**。

| 單位 | 相對於 | 用在 |
| --- | --- | --- |
| `em` | 元素自己的 `font-size`（用在 `font-size` 屬性上時，相對父元素的字級） | 跟著文字大小縮放的間距，例如按鈕 padding |
| `rem` | 根元素 `<html>` 的字級 | 字級、全站一致的間距 |
| `%` | 依屬性而不同，見下一節 | 寬度 |
| `vw`／`vh` | 視窗寬／高的 1% | 全螢幕區塊 |
| `dvh`／`svh`／`lvh` | 動態／最小／最大可視高度 | 手機上取代 `100vh`（網址列會吃掉高度） |
| `cqw`／`cqi` | 容器查詢的容器寬度 | 元件內部依容器縮放 |
| `ch` | 數字「0」的寬度 | 限制文字欄寬，例如 `max-width: 65ch` |

**行動版設定**：

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
```

- **不要加 `user-scalable=no`、`maximum-scale=1`**：會讓視力不好的使用者無法放大，違反無障礙規範；iOS Safari 10 起也直接忽略它。
- `viewport-fit=cover` 搭配 `env(safe-area-inset-bottom)` 處理瀏海和底部橫條。
- 淘寶 lib-flexible 用 JS 依螢幕寬度改 `<html>` 字級、全站用 `rem` 縮放的做法已經過時（作者自己也建議改用 `vw`）。設計稿等比縮放可以直接寫 `vw`，或用 `clamp()` 加上下限。
- 高解析螢幕的 1px 細線：現在 iOS、Android 都支援 `0.5px` 邊框，不必再用 JS 偵測加 class。

**偵測橫豎螢幕**：`window.orientation` 已廢除。CSS 用 `@media (orientation: portrait)`；JS 用 `matchMedia('(orientation: portrait)').matches` 或 `screen.orientation.type`。

**Flex 簡寫**：`flex: 0 0 25%` 是 `flex-grow: 0`（有空間也不放大）、`flex-shrink: 0`（空間不夠也不縮小）、`flex-basis: 25%`（初始佔 25%）。Bootstrap 的 `.col-sm-3` 就是這樣做出固定比例欄位。新專案的網格版面直接用 Grid：`grid-template-columns: repeat(auto-fill, minmax(200px, 1fr))` 一行就能自動決定欄數。

## 面試題：% 相對於誰 {#1-2-3-5}

| 屬性 | % 相對於 |
| --- | --- |
| `width`、`left`、`right`、`margin`、`padding`、`text-indent` | **包含區塊（containing block）的寬度**，連 `margin-top`、`padding-top` 也是看寬度 |
| `height`、`top`、`bottom` | 包含區塊的高度（父元素高度要是確定值，否則 `height: %` 無效） |
| 包含區塊是誰 | 一般元素和 `relative`：最近的區塊父元素；`absolute`：最近有定位（非 `static`）的祖先；`fixed`：視窗 |
| `transform: translate()` | 元素**自己**的寬高（所以 `translate(-50%, -50%)` 能置中） |
| `border-radius`、`background-size` | 元素自己的寬高 |
| `font-size` | 父元素的字級 |
| `line-height` | 元素自己的字級（建議寫無單位的 `1.5`，子元素會依自己的字級重新計算） |

常見錯誤：以為 `position: relative; left: 50%` 是移動「自己寬度的一半」，其實是移動父元素寬度的一半；要依自己的大小移動要用 `translate`。

## 版面效能 {#1-2-3-6}

Flex、Grid 比傳統 block 排版多一些計算，但對一般頁面沒有感覺得到的差距，不需要為了效能避開它們。真正影響效能的是：

- 要排版的元素數量（長列表用虛擬捲動，或 `content-visibility: auto` 讓畫面外的區塊延後排版）。
- **強制同步排版**：讀 `offsetHeight` 這類屬性之前剛改過樣式，瀏覽器只好馬上重新排版；在迴圈裡交替讀寫就是「版面抖動（layout thrashing）」。詳見 [1-5-3 渲染管線](./1-5-3.md)。
