## 9-1 變數宣告

**預設用 `const`，要重新賦值才用 `let`，不用 `var`。**

限制越多，程式越好推理：看到 `const` 就知道這個名稱之後不會指向別的東西，不必往下找它在哪裡被改掉。`let` 則明確告訴讀者「這個變數會變」（語法細節見 [2-6](./2-6.md)）。

`let` 多的時候，常常代表函式在做太多事。例如把 MB 換算成最大單位：

```js
// 一長串 if，每加一個單位就多一段幾乎一樣的程式
function prettySize(mb) {
  let value = mb
  let unit = 'MB'
  if (value >= 1024) { value /= 1024; unit = 'GB' }
  if (value >= 1024) { value /= 1024; unit = 'TB' }
  return `${value.toFixed(1)} ${unit}`
}
```

把「換算」和「顯示」分開，換算改成走訪單位清單，可變狀態就被侷限在一個小函式裡：

```js
const UNITS = ['MB', 'GB', 'TB', 'PB'] // 加新單位只要改這裡

function toLargestUnit(value, unit = UNITS[0]) {
  const next = UNITS[UNITS.indexOf(unit) + 1]
  return value >= 1024 && next ? toLargestUnit(value / 1024, next) : { value, unit }
}

const prettySize = (mb) => {
  const { value, unit } = toLargestUnit(mb)
  return `${value.toFixed(1)} ${unit}`
}
prettySize(1536) // '1.5 GB'
```

實際專案裡也可以直接用 `Intl.NumberFormat`：`new Intl.NumberFormat('zh-TW', { style: 'unit', unit: 'gigabyte', maximumFractionDigits: 1 })`。
