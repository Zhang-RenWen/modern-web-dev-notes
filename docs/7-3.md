# 7-3 字串和萬國碼

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡，字元叢集切割的「提案」已經是正式的 `Intl.Segmenter`；補上 ES2024 的 `isWellFormed`／`toWellFormed`。
:::

### 7-3-1 String#startsWith {#7-3-1}

```js
'ponyfoo'.startsWith('pony')    // true
'ponyfoo'.startsWith('foo', 4)  // true：從索引 4 開始比對
```

取代 `str.indexOf('pony') === 0`。

### 7-3-2 String#endsWith {#7-3-2}

```js
'ponyfoo'.endsWith('foo')     // true
'ponyfoo'.endsWith('pony', 4) // true：把字串當成只有前 4 個字元
```

### 7-3-3 String#includes {#7-3-3}

```js
'ponyfoo'.includes('ny')    // true，取代 indexOf(…) !== -1
'ponyfoo'.includes('ny', 3) // false：從索引 3 開始找
```

三個方法都區分大小寫，傳正規表達式會丟 `TypeError`。

### 7-3-4 String#repeat {#7-3-4}

```js
'ab'.repeat(3) // 'ababab'
'-'.repeat(20) // 分隔線
```

次數會被取整數，負數或 `Infinity` 會丟 `RangeError`。

### 7-3-5 補足與修整 {#7-3-5}

```js
'5'.padStart(3, '0')   // '005'（ES2017）
'abc'.padEnd(6, '.')   // 'abc...'
'  hi  '.trimStart()   // 'hi  '（ES2019）
'  hi  '.trimEnd()     // '  hi'
'abc'.at(-1)           // 'c'（ES2022）
'a-b-c'.replaceAll('-', '/') // 'a/b/c'（ES2021）
```

### 7-3-6 萬國碼與 UTF-16 {#7-3-6}

JS 字串是 **UTF-16 編碼單元**的序列。U+FFFF 以內的字元佔一個單元；超過的（emoji、部分罕用漢字）要用兩個單元組成的**代理對（surrogate pair）**。

```js
'🐎'.length         // 2：一個 emoji 佔兩個編碼單元
'\u{1F40E}'         // '🐎'：ES6 起可以用 \u{…} 直接寫超過 FFFF 的碼位
'🐎👱❤'.length      // 5
```

所以用 `length`、索引、`for (let i…)`、`split('')` 處理含 emoji 的字串都會切壞。

### 7-3-7 字串迭代器 {#7-3-7}

字串的迭代器以**碼位（code point）**為單位，代理對不會被拆開：

```js
[...'🐎👱❤'].length          // 3
for (const ch of '🐎👱❤') { } // 每次拿到一個完整的 emoji
```

但碼位仍然不等於「使用者看到的一個字」：組合字元（例如上劃線 `̅`）、膚色修飾、國旗、家庭 emoji 都由多個碼位組成。

### 7-3-8 字元叢集：Intl.Segmenter {#7-3-8}

使用者看到的「一個字」叫做**字形叢集（grapheme cluster）**，要用 `Intl.Segmenter` 切（2022 年進入 ECMA-402 標準，2024 年起各大瀏覽器都支援）：

```js
const seg = new Intl.Segmenter('zh-TW', { granularity: 'grapheme' })
const graphemes = [...seg.segment('👨‍👩‍👧é')].map((s) => s.segment)
graphemes.length // 2：家庭 emoji 算一個，e + 重音符號算一個
```

`granularity: 'word'` 還能做中文、日文這類沒有空白的語言的斷詞。計算輸入框字數、截斷文字時都應該用它。

### 7-3-9 String#codePointAt {#7-3-9}

取得某個位置的完整碼位（遇到代理對會把兩個單元合起來）：

```js
'🐎'.codePointAt(0)                 // 128014（0x1F40E）
'🐎'.charCodeAt(0)                  // 55357：只拿到代理對的前半
[...'🐎👱'].map((c) => c.codePointAt(0).toString(16)) // ['1f40e', '1f471']
```

### 7-3-10 String.fromCodePoint {#7-3-10}

`codePointAt` 的反向操作：`String.fromCodePoint(0x1F40E)` 是 `'🐎'`。舊的 `String.fromCharCode` 只能處理到 U+FFFF。

### 7-3-11 正確地反轉字串 {#7-3-11}

```js
'🐎👱'.split('').reverse().join('') // 亂碼：代理對被拆開反轉
[...'🐎👱'].reverse().join('')      // '👱🐎'：以碼位為單位
```

含組合字元或複合 emoji 時，要先用 `Intl.Segmenter` 切成字形叢集再反轉。

**檢查壞掉的字串（ES2024）**：只有一半的代理對（例如字串被從中間截斷）會讓 `encodeURIComponent` 丟錯。`str.isWellFormed()` 檢查，`str.toWellFormed()` 把孤立的半個代理對換成 `�`。

### 7-3-12 String#normalize {#7-3-12}

同一個字可能有不同的碼位組合：「é」可以是單一碼位 U+00E9，也可以是 `e` + 組合重音符 U+0301。看起來一樣，`===` 卻是 `false`。

```js
const a = 'é'
const b = 'é'
a === b                                   // false
a.normalize('NFC') === b.normalize('NFC') // true
```

比對、搜尋、當鍵值之前先正規化。`NFC`（合成）是預設也最常用；`NFKC` 還會把全形英數轉成半形（`'ＡＢＣ１'.normalize('NFKC')` 是 `'ABC1'`），適合處理使用者輸入，見 [1-8-3](./1-8-3.md)。
