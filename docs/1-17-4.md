## NVM（Node 版本管理） {#1-17-4-1}

```bash
# 安裝或修復
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
source ~/.zshrc && nvm --version

# ~/.zshrc 必須有
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"

# 安裝與預設版本
nvm install --lts      # 或 nvm install 22.12.0
nvm alias default 'lts/*'
nvm use default

# 專案固定版本
echo "22" > .nvmrc && nvm use
```

- `zsh: command not found: nvm` → 沒裝，或裝了但 `~/.zshrc` 沒載入。
- 新開 Terminal 又跳回舊版 → `which -a node` 看是誰在搶 PATH（`/usr/local/bin`、`/opt/homebrew/bin` vs `~/.nvm/versions/...`）。nvm 是 shell function，`cd` 不會自動切版本。

```bash

eval "$(/opt/homebrew/bin/brew shellenv)"
```

## ffmpeg 切割音檔（不重新編碼） {#1-17-4-3}

```bash
cd ~/Downloads
ffmpeg -ss 00:00:00 -to 00:29:59 -i 1.mp3 -c copy 1-1.mp3
ffmpeg -ss 00:29:59 -i 1.mp3 -c copy 1-2.mp3

# 切影片：從 1:30 到 2:10，或從第 90 秒起取 40 秒
ffmpeg -ss 00:01:30 -to 00:02:10 -i "input.mp4" -c copy "output.mp4"
ffmpeg -ss 90 -t 40 -i "input.mp4" -c copy "output.mp4"

# 要精準到每一幀就重新編碼（較慢）
ffmpeg -ss 00:01:30 -to 00:02:10 -i "input.mp4" -c:v libx264 -c:a aac "output.mp4"
```

- 安裝：Mac `brew install ffmpeg`；Windows `winget install ffmpeg` 後重開 PowerShell；`ffmpeg -version` 確認。
- `-c copy` 不重新編碼，速度快、音質不變，但影片切點會落在最近的 keyframe，不一定精準。
- `-to` 是結束時間點，`-t` 是長度，兩者同時出現時 `-t` 優先。
- 檔名有空白或中文一定要加雙引號。PowerShell 裡不要用 `$input` 當變數名（是內建自動變數）。

## Terminal / VS Code 快捷鍵 {#1-17-4-4}

- 清除目前輸入：`Ctrl+U`（Mac/Linux/Git Bash）、`Esc`（PowerShell）；清畫面：`clear` / `cls`、`Cmd+K`、`Ctrl+L`
- VS Code：`Ctrl+Shift+P` 指令面板、`Ctrl+P` 開檔、``Ctrl+` `` Terminal、`Ctrl+Shift+F` 全專案搜尋、`Ctrl+D` 選下一個相同字、`Alt+Click` 多游標、`F12` 跳定義、`Alt+F12` Peek。重點是串起 Terminal、Git、Debugger、Remote SSH、Dev Container 的工作流，不是背整張圖。

## 把 localhost 給外面看 {#1-17-4-5}

| 場景 | 工具 |
| --- | --- |
| 臨時 demo、手機測 localhost | VS Code Port Forwarding / Dev Tunnels（輕量版 ngrok） |
| Webhook 測試、要看 request | ngrok |
| 較正式的內網服務暴露 | Cloudflare Tunnel / Tailscale / Zero Trust |
| 正式上線 | 雲端主機 + Domain + HTTPS + Auth + WAF / Gateway |

::: warning
Tunnel 本質是把本機暴露到外網：不要公開沒登入的後台、DB 管理頁、有 token 的頁面；測完就關。
:::

## 工具與平台筆記 {#1-17-4-6}

- **Bruno**：API Client，collection 用 Git 管理、免費、不用登入帳號（Postman / Insomnia 強制登入、token 存雲端的顧慮）。介面陽春但基本功能齊全，適合推給團隊。替代：Hoppscotch、HTTPie。
- **API 文件**：Swagger / OpenAPI（Node 設定參考：[israynotarray](https://israynotarray.com/nodejs/20201229/1974873838/)）。
- **pnpm**：用硬連結共用套件，解決 node_modules 塞爆硬碟。
- **TTime**：開源劃詞翻譯，選取文字按快捷鍵直接翻，看英文文件不用來回貼 Google 翻譯。
- **Linux 桌面**：Ubuntu Desktop 照[官方教學](https://ubuntu.com/tutorials/install-ubuntu-desktop)安裝（備好空 USB、先備份資料），客製桌面搜「發行版 + Customize Desktop」；瀏覽器可試 Zen。
- **PaaS vs IaaS**：PaaS 簡單（Render）；IaaS 彈性但複雜（EC2、Akamai/Linode VPS）。
- **挑開源專案參與**：看 GitHub Trending / Explore，再看社群活躍度、Issue 處理速度、README 與 CONTRIBUTING 友善度。
