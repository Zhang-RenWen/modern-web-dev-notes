## NVM（Node 版本管理） {#1-17-4-1}

```bash
# 安裝或修復
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
source ~/.zshrc && nvm --version

# ~/.zshrc 必須有
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"

# 安裝與預設版本
nvm install --lts      # 或 nvm install 22.12.0
nvm alias default 'lts/*'
nvm use default

# 專案固定版本
echo "22" > .nvmrc && nvm use
```

- `zsh: command not found: nvm` → 沒裝，或裝了但 `~/.zshrc` 沒載入。
- 新開 Terminal 又跳回舊版 → `which -a node` 看是誰在搶 PATH（`/usr/local/bin`、`/opt/homebrew/bin` vs `~/.nvm/versions/...`）。nvm 是 shell function，`cd` 不會自動切版本。

## ffmpeg 切割音檔（不重新編碼） {#1-17-4-3}

```bash
cd ~/Downloads
ffmpeg -ss 00:00:00 -to 00:29:59 -i 1.mp3 -c copy 1-1.mp3
ffmpeg -ss 00:29:59 -i 1.mp3 -c copy 1-2.mp3

# 切影片：從 1:30 到 2:10，或從第 90 秒起取 40 秒
ffmpeg -ss 00:01:30 -to 00:02:10 -i "input.mp4" -c copy "output.mp4"
ffmpeg -ss 90 -t 40 -i "input.mp4" -c copy "output.mp4"

# 要精準到每一幀就重新編碼（較慢）
ffmpeg -ss 00:01:30 -to 00:02:10 -i "input.mp4" -c:v libx264 -c:a aac "output.mp4"
```

- 安裝：Mac `brew install ffmpeg`；Windows `winget install ffmpeg` 後重開 PowerShell；`ffmpeg -version` 確認。
- `-c copy` 不重新編碼，速度快、音質不變，但影片切點會落在最近的 keyframe，不一定精準。
- `-to` 是結束時間點，`-t` 是長度，兩者同時出現時 `-t` 優先。
- 檔名有空白或中文一定要加雙引號。PowerShell 裡不要用 `$input` 當變數名（是內建自動變數）。

## Terminal / VS Code 快捷鍵 {#1-17-4-4}

- 清除目前輸入：`Ctrl+U`（Mac/Linux/Git Bash）、`Esc`（PowerShell）；清畫面：`clear` / `cls`、`Cmd+K`、`Ctrl+L`
- VS Code：`Ctrl+Shift+P` 指令面板、`Ctrl+P` 開檔、``Ctrl+` `` Terminal、`Ctrl+Shift+F` 全專案搜尋、`Ctrl+D` 選下一個相同字、`Alt+Click` 多游標、`F12` 跳定義、`Alt+F12` Peek。重點是串起 Terminal、Git、Debugger、Remote SSH、Dev Container 的工作流，不是背整張圖。

## Python 本機環境 {#1-17-4-8}

:::

**安裝與套件管理**

```bash
brew install python                 # macOS 建議用 Homebrew 安裝，會一併帶 pip
python3 --version && python3 -m pip --version

# Homebrew 的 Python 遵循 PEP 668，不能直接全域 pip install，套件一律裝在虛擬環境
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install mysql-connector-python python-dotenv
pip freeze > requirements.txt       # 鎖定版本；新專案也可以用 uv 或 Poetry 管理
pipx install black                  # 全域 CLI 工具用 pipx 安裝，各自隔離
```

- 用 `python3 -m pip` 而不是直接打 `pip`，確保裝到的是「目前這個 Python」。
- macOS 12.3 起已不再內建 Python 2.7；若舊系統的 `python` 指向 2.7，可在 `~/.zshrc` 加 `alias python="python3"`。

**`ModuleNotFoundError: No module named 'xxx'` 的常見原因**

1. 套件根本沒裝（注意套件名與匯入名可能不同：裝 `mysql-connector-python`，匯入 `mysql.connector`）。
2. 裝到別的 Python 版本。
3. 裝在全域，但目前在虛擬環境（或反過來）。
4. IDE 選錯直譯器（VS Code：Python: Select Interpreter）。
5. 自己的檔案或變數取了和套件一樣的名字（例如 `mysql.py`），把官方模組遮住了。

**用 `.env` 管理密鑰**

```python
# settings.py
import os
from dotenv import load_dotenv

load_dotenv()                       # 讀取專案根目錄的 .env
DB_HOST = os.getenv("DB_HOST", "localhost")
DB_PASSWORD = os.environ["DB_PASSWORD"]   # 必填的值用 [] 取，缺少時立刻報錯
```

`.env` 加進 `.gitignore`；另外提交一份只有變數名稱、沒有值的 `.env.example`，讓其他人知道要設定哪些變數。

**連線 MySQL 的基本寫法**

```python
import mysql.connector
from settings import DB_HOST, DB_PASSWORD

conn = mysql.connector.connect(host=DB_HOST, user="app", password=DB_PASSWORD, database="demo")
cur = conn.cursor()

# 一律用參數化查詢（%s 由驅動處理跳脫），不要用 f-string 拼 SQL
cur.executemany(
    "INSERT INTO students (student_id, name, city) VALUES (%s, %s, %s)",
    [(1, "Enoch", "Los Angeles"), (2, "Alice", "Tokyo")],
)
conn.commit()

cur.execute("SELECT student_id, name FROM students WHERE city = %s", ("Tokyo",))
print(cur.fetchall())
conn.close()
```

表名、欄位名不能參數化，若要動態指定，必須先比對白名單（原始筆記用 `f"SELECT * FROM {table_name}"` 有 SQL Injection 風險）。實務上用 `with` 管理連線，或使用 SQLAlchemy 等 ORM。

**移除舊版 Python（macOS）**

```bash
which -a python3                                          # 先看有哪些 python3、各在哪裡
sudo rm -rf /Library/Frameworks/Python.framework/Versions/3.9   # python.org 安裝包裝的版本
sudo rm -rf "/Applications/Python 3.9"                    # 同時裝的 App
brew uninstall python@3.9                                 # Homebrew 裝的版本
brew cleanup -n && brew cleanup                           # 先預覽，再清掉舊的快取與連結
```

不要刪 `/usr/bin/python3`（系統的 Command Line Tools 提供）。多版本並存的需求用 pyenv 或 uv 管理，比手動安裝與刪除安全。

## 工具與平台筆記 {#1-17-4-6}

- **Bruno**：API Client，collection 用 Git 管理、免費、不用登入帳號（Postman / Insomnia 強制登入、token 存雲端的顧慮）。介面陽春但基本功能齊全，適合推給團隊。替代：Hoppscotch、HTTPie。
- **API 文件**：Swagger / OpenAPI（Node 設定參考：[israynotarray](https://israynotarray.com/nodejs/20201229/1974873838/)）。
- **pnpm**：用硬連結共用套件，解決 node_modules 塞爆硬碟。
- **TTime**：開源劃詞翻譯，選取文字按快捷鍵直接翻，看英文文件不用來回貼 Google 翻譯。
- **Linux 桌面**：Ubuntu Desktop 照[官方教學](https://ubuntu.com/tutorials/install-ubuntu-desktop)安裝（備好空 USB、先備份資料），客製桌面搜「發行版 + Customize Desktop」；瀏覽器可試 Zen。
- **PaaS vs IaaS**：PaaS 簡單（Render）；IaaS 彈性但複雜（EC2、Akamai/Linode VPS）。
- **挑開源專案參與**：看 GitHub Trending / Explore，再看社群活躍度、Issue 處理速度、README 與 CONTRIBUTING 友善度。
