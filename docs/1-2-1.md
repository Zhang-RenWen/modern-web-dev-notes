## BFC 是什麼 {#1-2-1-2}

**BFC（Block Formatting Context，區塊格式化上下文）** 是頁面上一塊獨立的排版區域：裡面的元素怎麼排，不會影響外面，外面的浮動也不會擠進來。可以把它想成 CSS 排版的「獨立作用域」。

在 BFC 裡，區塊元素由上往下一個接一個排列，相鄰元素的上下 margin 會合併（取較大值）。

## 什麼會建立 BFC {#1-2-1-3}

| 寫法 | 副作用 |
| --- | --- |
| `display: flow-root` | **沒有副作用，專門用來建立 BFC，首選** |
| `overflow: hidden`／`auto`（不是 `visible` 或 `clip`） | 超出的內容會被裁切或出現捲軸 |
| `float` 不是 `none` | 元素脫離一般排版 |
| `position: absolute`／`fixed` | 元素脫離一般排版 |
| `display: inline-block`、`table-cell`、`table-caption` | 變成行內或表格排版 |
| Flex／Grid 容器的**子元素** | 本來就各自是獨立的排版區域 |
| `contain: layout`、`content`、`paint` | 限制內容的排版範圍 |
| 根元素 `<html>`、多欄容器、`column-span: all` | — |

## BFC 解決的三個問題 {#1-2-1-4}

| 問題 | 原因 | 現在的做法 |
| --- | --- | --- |
| 父元素高度塌陷（子元素都浮動，父元素高度變 0） | 浮動元素不參與一般高度計算，但 BFC 會把浮動算進高度 | 父元素加 `display: flow-root` |
| margin 合併（兩段落上下各 40px，實際間距只有 40px） | 同一個 BFC 裡相鄰的垂直 margin 會合併；父子之間沒有 border／padding 時也會 | 用 Flex／Grid 的 `gap` 排間距，裡面不會合併；或把其中一個包進 `flow-root` |
| 文字環繞浮動元素 | 一般區塊會跑到浮動元素底下 | 旁邊的元素建立 BFC 就不會和浮動重疊；但兩欄版面直接用 Flex／Grid 更清楚 |

```html
<div class="demo-root">
  <div class="demo-float">float</div>
  <div class="demo-float">float</div>
</div>
<div class="demo-root demo-flow-root">
  <div class="demo-float">float</div>
  <div class="demo-float">float</div>
</div>
```

**兩欄版面（左側固定、右側填滿）** 以前靠「左邊浮動 + 右邊 `overflow: hidden`」，現在一行就好：

```css
.layout { display: grid; grid-template-columns: 80px 1fr; }
/* 或 */
.layout { display: flex; } .layout > .right { flex: 1; }
```

## IFC：行內格式化上下文 {#1-2-1-1}

多個行內（或行內區塊）元素排在一起時形成；中間插入區塊元素就會被切成多個 IFC。

- 元素水平排列，放不下就換行成多個行框（line box）。
- 水平方向的 margin、border、padding 有效；垂直方向的 margin 對行內元素無效。
- 垂直對齊用 `vertical-align`。常見問題是圖片下方多出幾 px 空隙（圖片預設對齊文字基線），用 `display: block` 或 `vertical-align: middle` 解決。

BFC 的面試問法見 [模擬面試 2 Q2](./interview-2.md#interview-2-2)。
