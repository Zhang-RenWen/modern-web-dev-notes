# 2-1 物件實字

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡並補上 ES2018 的物件展開與 ES2022 的 `Object.hasOwn`。
:::

### 2-1-1 屬性值簡寫 {#2-1-1}

變數名稱和屬性名稱相同時可以只寫一次：

```js
const listeners = {}
function run() {}

const events = { listeners, run } // 等同 { listeners: listeners, run: run }
```

### 2-1-2 計算屬性名稱 {#2-1-2}

屬性名稱可以用 `[運算式]` 動態決定：

```js
const grocery = { id: 'banana', name: 'Bananas', price: 10 }
const groceries = { [grocery.id]: grocery } // { banana: { … } }

const prefix = 'is'
const flags = { [`${prefix}Open`]: true } // { isOpen: true }
```

ES5 只能先建立物件，再用 `obj[key] = value` 加上去。

### 2-1-3 方法簡寫 {#2-1-3}

```js
const emitter = {
  events: {},
  on(type, fn) {          // 等同 on: function (type, fn) {…}
    (this.events[type] ??= []).push(fn)
  },
  emit(type, event) {
    this.events[type]?.forEach((fn) => fn(event))
  },
}
```

簡寫的方法可以用 `super` 呼叫原型上的方法，而且不能當建構函式（`new emitter.on()` 會報錯）。getter／setter 一樣可以寫在物件實字裡：`get total() { … }`。

### 2-1-4 物件展開（ES2018） {#2-1-4}

```js
const defaults = { theme: 'light', lang: 'zh-TW' }
const settings = { ...defaults, lang: 'en' } // 後面的覆蓋前面的：{ theme: 'light', lang: 'en' }
const { lang, ...rest } = settings           // rest：{ theme: 'light' }
```

只複製自己的、可列舉的屬性，而且是淺拷貝。
