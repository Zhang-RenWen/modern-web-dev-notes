## 分層與封裝 {#1-18-1-1}

```txt
Application  HTTP／HTTPS／DNS／WebSocket／MQTT／gRPC／SMTP
Transport    TCP／UDP／QUIC
Internet     IP／ICMP
Link         Ethernet／Wi-Fi／ARP

送出：Data → TCP Segment／UDP Datagram → IP Packet → Ethernet Frame → Bits
接收：反過來一層層拆 header（de-encapsulation）
```

- OSI 七層是教學模型；實務用 TCP/IP 四層理解即可。每層只做自己的事、加自己的 header。

## TCP／UDP／QUIC {#1-18-1-2}

| 協定 | 特性 | 用在哪 |
| --- | --- | --- |
| TCP | 連線導向、可靠、有序、流量與壅塞控制；三向交握 SYN → SYN-ACK → ACK | HTTP/1.1、HTTP/2、SSH、SMTP、DB 連線 |
| UDP | 無連線、不保證送達與順序、低延遲；request/response 由上層自己設計 | DNS、DHCP、NTP、語音視訊、遊戲、QUIC 底層 |
| QUIC | 建在 UDP 上，內建 TLS 1.3、多路串流、連線遷移、建連更快 | HTTP/3 |

- HTTP/1.1 → TCP；HTTP/2 → TCP＋multiplexing；HTTP/3 → QUIC → UDP。不要記成「HTTP/3＝UDP」。
