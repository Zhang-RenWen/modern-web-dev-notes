# 1-16-1 從電晶體到程式：電腦怎麼運作 {#1-16-1}

::: info 新增（2026-11）
整理自 Notion「計算機基礎」第 1 節。
:::

- **電晶體＝電控開關**，通／不通記成 1／0；數字、文字、圖片、聲音、指令最後全是二進位。
- **邏輯閘**：AND（串聯，兩者都要通）、OR（並聯，任一通）、NOT（反相），再組出 XOR、NAND、NOR、XNOR。YES gate 的正式名稱是 Buffer。
- **組合電路**：閘 → 比較器、選擇器（MUX）、正反器（記住 1 bit）、半加器（XOR 得個位、AND 得進位）→ 串成多位元加法器。乘除＝移位＋加減＋比較。
- **位元數決定範圍**：8 bit＝256 種（0–255）；64 bit＝2⁶⁴ 種。
- **CPU 三件套**：運算單元（ALU）＋控制單元（決定資料走哪條路、哪些電路工作）＋時脈（節拍器；3 GHz≈每秒 30 億週期；超頻不穩＝電路來不及穩定下一拍就到）。核心數＝可獨立執行工作的組數。GPU／AI 加速器＝大量簡單運算單元同時算。
- **CPU 永遠在做：取指令 → 執行 → 取下一條。**指令本身也是資料，換程式就換用途＝可程式化。
- **I/O 都是「現實 ↔ 數字」轉換**：螢幕＝像素 RGB 值；喇叭＝按固定時間間隔送振膜位置；鍵盤＝開關狀態改變。

> 一句話：不懂數學的開關 × 正確接法 × 正確指令＝電腦。
