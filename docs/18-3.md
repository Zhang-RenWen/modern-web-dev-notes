# 18-3 String.prototype.isWellFormed() / toWellFormed() {#18-3}

JavaScript 字串是 UTF-16 編碼。超出 BMP 的字元（例如 emoji）會用兩個碼元組成「代理對」（surrogate pair）。如果字串中出現**落單的代理碼元**（lone surrogate），就不是合法的 Unicode 字串，傳給 `encodeURI()`、`TextEncoder` 或 Web API 時會出錯或被替換。

- `isWellFormed()`：檢查字串是否沒有落單的代理碼元。
- `toWellFormed()`：回傳新字串，把落單的代理碼元換成替代字元 `U+FFFD`（�）。

```js
const good = 'ab😀'
const bad = 'ab\uD800' // 只有高位代理，缺少低位代理

good.isWellFormed() // true
bad.isWellFormed() // false

bad.toWellFormed() // 'ab�'，也就是 'ab�'
```

### 實際應用：避免 encodeURI() 拋出錯誤

```js
encodeURI('ab\uD800') // URIError: URI malformed

const safe = (str) => encodeURI(str.isWellFormed() ? str : str.toWellFormed())
safe('ab\uD800') // 'ab%EF%BF%BD'
```

落單的代理碼元常出現在用 `slice()` 或 `substring()` 依碼元切字串時，剛好切在 emoji 的中間：

```js
const text = '😀😀'
text.slice(0, 3).isWellFormed() // false，第二個 emoji 被切成一半
```
