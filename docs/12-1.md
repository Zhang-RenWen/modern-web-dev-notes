# 新標準 ES2018 (ES9)

## 12-1 Spread 展開運算子 / Rest 其餘參數 {#12-1}

前面章節 [2-4](./2-4.md) 有提到展開運算子。當時的特性是針對陣列和函式內傳入參數設計。 在 ES9 新標準中，也開始支援對物件的屬性做操作。案例如下：

```js
const obj1 = { foo: 'bar', x: 42 };
const obj2 = { foo: 'baz', y: 13 };

const clonedObj = { ...obj1 };
// Object { foo: 'bar', x: 42 }

const mergedObj = { ...obj1, ...obj2 };
// Object { foo: 'baz', x: 42, y: 13 }
```

針對函式傳入參數做處理。按序引入，並且將剩餘的參數合併成一個變數並裝有其餘參數的陣列。

```js
let obj1 = { foo: 'bar', x: 42 };
let obj2 = { foo: 'baz', y: 13 };
const merge = (...objects) => ({ ...objects });
const merge2 = (foo,...objects) => {
  console.log(foo)
  console.log(objects)
};

let mergedObj1 = merge(obj1, obj2);
// Object { 0: { foo: 'bar', x: 42 }, 1: { foo: 'baz', y: 13 } }

let mergedObj2 = merge({}, obj1, obj2);
// Object { 0: {}, 1: { foo: 'bar', x: 42 }, 2: { foo: 'baz', y: 13 } }

let merged2Obj1 = merge2(obj1, obj2);
// {foo: 'bar', x: 42}
// [{ foo: 'baz', y: 13 }]

let merged2Obj2 = merge2({}, obj1, obj2);
// {}
// [
//  {foo: 'bar', x: 42},
//  {foo: 'baz', y: 13}
// ]
```

物件操作不能跟陣列混用

```js
const obj = { key1: 'value1' };
const array = [...obj]; // TypeError: obj is not iterable
```

深淺拷貝測試 對照 Object.assign()

```js
let baseData = {
  test1:123,
  test2:'321'
}

Object.assign(baseData,{test3:'1234567'})
// {test1: 123, test2: '321', test3: '1234567'}

const lucy = Object.assign(
  {test4:'我們是快樂的好兒童(給我閉嘴！)'},
  baseData
)
// {test4: '我們是快樂的好兒童(給我閉嘴！)',
//  test1: 123,
//  test2: '321',
//  test3: '1234567'
// }

let merged = { ...baseData, ...lucy }
// {
//  test1: 123
//  test2: '321',
//  test3: '1234567',
//  test4: '我們是快樂的好兒童(給我閉嘴！)'
// }

merged.test1 = '321'

console.log(baseData)
// {test1: 123, test2: '321', test3: '1234567'} 沒有更動原本物件
```
