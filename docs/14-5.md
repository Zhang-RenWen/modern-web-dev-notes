# 14-5 動態 import {#14-5}

ES6 時候的 import 屬於靜態載入。ES11 以後可以實現按需載入。

```js
// hello.js
export function hello(){
  alert('Hello')
}

// app.js
// import * as m1 from "./hello.js" // 靜態加載  ;

const btn = document.getElementById('btn');
btn.onclick = function(){
  import('./hello.js').then(module => { // 懶加載
  module.hello(); // Hello
});
}
```

不要輸出命名為 then 的 function 。 這將造成跟靜態引入不同的結果。

::: danger 錯誤示範

```js
// my-module.js
export function then(resolve) {
  console.log("then() called");
  resolve(1);
}
```

:::

```js
// main.js
import * as mod from "/my-module.js";

import("/my-module.js").then((mod2) => {
  // Logs "then() called"
  console.log(mod === mod2); // false
});
```

### Side Effects

補充：以下範例當程式跑到 b.js 時 所印出的訊息就是所謂的 side effects 。代表沒有被輸出的函式也會跟著被執行

```js
//a.js
export function print1()
{
  console.log("export print1 is working");
}

function print2()
{
  console.log("non-export print2 is working");
}

print1();
print2(); // 沒有被輸出的函式也會跟著被執行

//b.js
import "a.js";
```

### 引入 ESM 模組

執行 package 以及匯入 package 所引用的依賴。

```js
(async () => {
  if (somethingIsTrue) {
    // import module for side effects
    await import("/modules/my-module.js");
  }
})();
```

### 給定模組執行回傳結果預設值

```js
(async () => {
  if (somethingIsTrue) {
    const {
      default: myDefault,
      foo,
      bar,
    } = await import("/modules/my-module.js");
  }
})();
```

### 根據使用這行為動態加載模組

```js
const main = document.querySelector("main");
for (const link of document.querySelectorAll("nav > a")) {
  link.addEventListener("click", (e) => {
    e.preventDefault();

    import("/modules/my-module.js")
      .then((module) => {
        module.loadPageInto(main);
      })
      .catch((err) => {
        main.textContent = err.message;
      });
  });
}
```

### 根據不同環境變數動態加載模組

```js
let myModule;

if (typeof window === "undefined") {
  myModule = await import("module-used-on-server");
} else {
  myModule = await import("module-used-in-browser");
}
```

### 可以使用字串樣板動態加載資源模組

```js
Promise.all(
  Array.from({ length: 10 }).map((_, index) =>
    import(`/modules/module-${index}.js`),
  ),
).then((modules) => modules.forEach((module) => module.load()));
```
