### 怎麼用這一章 {#21-1-1}

每題固定四段：

- **考點**：面試官想確認什麼。
- **解題思路**（點開）：先自己想，再對照拆解方式。
- **標準答案與過程**（點開）：可以直接講出口的版本，附程式碼。
- **相關筆記**：本站已有的完整說明，用來補細節。

建議練法：先蓋住答案、計時 2 分鐘口頭回答，再點開對照。回答骨架：**定義 → 實際案例 → 為什麼這樣選 → Trade-off → 什麼情況不用**。

### 從職缺讀出的重點 {#21-1-4}

1. **框架三分天下**：Vue、React、Angular 都有人要，金控與台達都有 Angular 缺。至少一個框架要講到原理，另外兩個要能說出對應概念（見 [21-7 Vue 開發者怎麼看 Angular](./21-7.md#21-7-6)）。
2. **「資深」看的不是 API 熟度**，而是架構、選型、驗收外包程式碼、訂標準、帶人、估時。國泰 I00026412 幾乎整篇都在講這些，對應 [21-13](./21-13.md)。
3. **全端化**：多數職缺要求能讀後端程式、設計 API、懂一個關聯式資料庫，以及 Docker 與 K8s 的基本操作。
4. **效能要能量化**：Core Web Vitals、SSR／ISR 策略、大量資料渲染，要能說出量測方法與前後數據。
5. **金融業加分**：凱基、元大、國泰都重視金融經驗；面試時把冪等、對帳、稽核、權限等觀念和前端工作連起來講。
