## 6-1 代理器初探

`new Proxy(target, handler)` 建立一個代理物件：對代理物件的操作（讀、寫、刪除、`in`、呼叫…）都會先經過 `handler` 裡對應的**機關（trap）**；沒有設定機關的操作，原封不動轉給 `target`。

```js
const target = {}
const proxy = new Proxy(target, {})
proxy.a = 1
target.a // 1：沒有任何機關時，代理就是單純轉送
```

**`Reflect` 是機關的好搭檔**：每個機關都有同名的 `Reflect` 方法，執行「原本的預設行為」。在機關裡做完自己的事，再呼叫 `Reflect.xxx(...arguments)`，就不用自己重寫預設邏輯，`receiver`（getter 裡的 `this`）也會正確傳遞。

### 6-1-1 get 機關 {#6-1-1}

```js
const logged = new Proxy(target, {
  get(target, key, receiver) {
    console.log(`讀取 ${String(key)}`)
    return Reflect.get(target, key, receiver)
  },
})
```

用途：記錄存取、預設值、負數索引：

```js
const arr = new Proxy([1, 2, 3], {
  get: (t, key, r) => Reflect.get(t, typeof key === 'string' && key < 0 ? t.length + Number(key) : key, r),
})
arr[-1] // 3（現在也可以直接用內建的 arr.at(-1)）
```

### 6-1-2 set 機關 {#6-1-2}

`set` 要回傳 `true` 表示成功，回傳 `false` 在嚴格模式下會丟 `TypeError`。

```js
// 禁止存取底線開頭的「私有」屬性
function conceal(original) {
  const guard = (key, action) => {
    if (typeof key === 'string' && key.startsWith('_')) throw new Error(`不能${action}私有屬性 ${key}`)
  }
  return new Proxy(original, {
    get(t, key, r) { guard(key, '讀取'); return Reflect.get(t, key, r) },
    set(t, key, value, r) { guard(key, '設定'); return Reflect.set(t, key, value, r) },
  })
}
```

使用端只能拿到代理，原始物件要完全藏起來，否則直接操作原始物件就繞過了所有檢查。（真正的私有現在用 class 的 `#` 欄位。）

### 6-1-3 驗證 {#6-1-3}

在寫入時檢查格式，不合法就拒絕：

```js
const person = new Proxy({}, {
  set(t, key, value, r) {
    if (key === 'age' && (!Number.isInteger(value) || value < 0)) {
      throw new TypeError('age 必須是非負整數')
    }
    return Reflect.set(t, key, value, r)
  },
})
person.age = 30   // OK
person.age = -1   // TypeError
```

### Proxy 實際用在哪 {#6-1-4}

| 用途 | 例子 |
| --- | --- |
| 響應式系統 | Vue 3 的 `reactive()`：`get` 收集依賴、`set` 觸發更新（見 [1-7-1](./1-7-1.md#1-7-1-3)）；MobX |
| 不可變資料的草稿 | Immer：讓你直接「改」草稿物件，代理記錄改了什麼，最後產生新物件 |
| 動態 API 用戶端 | `api.users.get(1)` 依屬性名稱動態組出請求路徑 |
| 測試替身、記錄 | 攔截所有呼叫並記錄 |

**代價**：每次操作都多一層函式呼叫，效能比直接存取慢；`===` 比較時代理和原物件不相等；有內部插槽的內建物件（`Map`、`Date`、DOM 節點）直接代理時，呼叫它的方法會出錯，要在 `get` 裡把方法 `bind` 回原物件。
