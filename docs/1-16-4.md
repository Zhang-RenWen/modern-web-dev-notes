# 1-16-4 Linux 發行版與 CLI {#1-16-4}

::: info 新增（2026-11）
整理自 Notion「計算機基礎」第 4 節。常用指令見 [1-17-1 Linux 指令與排查](./1-17-1.md)。
:::

- **Kernel ≠ 作業系統**：Kernel 管 CPU／記憶體／裝置驅動，提供 syscall。發行版（Distribution）＝Kernel＋Shell 與基本指令＋套件管理＋驅動整合＋（選配）桌面＋安全更新。只裝 Kernel＝能開機但什麼都做不了；自己從零組裝＝Linux From Scratch，學習價值高但不實用。比喻：Kernel 是引擎，Ubuntu 是整台車。

| 家族 | 套件管理 | 定位 |
| --- | --- | --- |
| Debian／Ubuntu（Kali 等） | APT（.deb） | 最萬用；**Ubuntu LTS 是預設首選**（桌面、伺服器、雲端、CUDA／Docker 支援最先到、社群最大） |
| Red Hat／RHEL、AlmaLinux、Rocky、Fedora | DNF／YUM（.rpm） | 企業伺服器主力（金融業常見）；Fedora 偏前沿 |
| Arch／Manjaro | pacman＋AUR | 滾動更新、適合學底層 |
| Gentoo | Portage（原始碼編譯） | 高度客製、硬核 |
| Slackware | 多靠手動 | 歷史最久、少魔改 |

- 各家功能約 70–80% 重疊，差在：套件管理、穩定 vs 新穎、預設場景。會 `ls`、`cd`、`grep`、`systemctl`，換發行版幾乎不用重學。
- Ubuntu Desktop 預設 GNOME 桌面（GUI）；Ubuntu Server 預設只有 CLI，因為伺服器不需要 GUI 吃資源。
- **CLI 的價值**：可寫 script 自動化、遠端（SSH）只能靠 CLI、省資源、熟練後比滑鼠快。
