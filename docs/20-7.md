# 20-7 Map.prototype.getOrInsert()（Upsert） {#20-7}

「如果 key 存在就取值，不存在就先設定預設值再取值」是非常常見的操作。ES2026 為 `Map` 和 `WeakMap` 新增兩個方法：

- `getOrInsert(key, defaultValue)`：key 不存在時，存入 `defaultValue` 並回傳。
- `getOrInsertComputed(key, callback)`：key 不存在時，才呼叫 `callback(key)` 計算預設值。適合預設值建立成本較高，或每次都要是新物件的情況。

```js
// 以前的寫法
if (!map.has(key)) map.set(key, [])
map.get(key).push(value)

// ES2026
map.getOrInsertComputed(key, () => []).push(value)
```

### 實際應用：計數

```js
const counts = new Map()

for (const word of ['apple', 'banana', 'apple']) {
  counts.set(word, counts.getOrInsert(word, 0) + 1)
}

console.log(counts) // Map { 'apple' => 2, 'banana' => 1 }
```

### 實際應用：分組

```js
const groups = new Map()

for (const { type, name } of [
  { type: 'fruit', name: 'apple' },
  { type: 'vegetable', name: 'carrot' },
  { type: 'fruit', name: 'banana' },
]) {
  groups.getOrInsertComputed(type, () => []).push(name)
}

console.log(groups) // Map { 'fruit' => ['apple', 'banana'], 'vegetable' => ['carrot'] }
```

### 為什麼需要 getOrInsertComputed()

`getOrInsert()` 的預設值在呼叫前就會先被建立。如果寫成 `map.getOrInsert(key, [])`，即使 key 已存在，每次也都會白白建立一個新陣列；預設值的計算成本很高時更浪費。`getOrInsertComputed()` 只在 key 不存在時才執行 callback。
