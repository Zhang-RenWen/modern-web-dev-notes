## 20-1 Array.fromAsync() {#20-1}

`Array.from()` 的非同步版本：從非同步可迭代物件（例如非同步產生器、Node.js 的串流），或包含 Promise 的可迭代物件建立陣列。回傳的是 Promise。

```js
async function* fetchPages() {
  yield 'page 1'
  yield 'page 2'
  yield 'page 3'
}

// 以前的寫法
const pagesOld = []
for await (const page of fetchPages()) pagesOld.push(page)

// ES2026
const pages = await Array.fromAsync(fetchPages())
console.log(pages) // ['page 1', 'page 2', 'page 3']
```

也可以傳入對應函式（mapper），回傳值同樣會被 `await`：

```js
await Array.fromAsync(fetchPages(), (page) => page.toUpperCase())
// ['PAGE 1', 'PAGE 2', 'PAGE 3']

await Array.fromAsync([Promise.resolve(1), 2, Promise.resolve(3)])
// [1, 2, 3]
```

### 和 Promise.all() 的差別

`Array.fromAsync()` 會**依序**等待每個值，前一個完成才處理下一個；`Promise.all()` 則是同時等待所有 Promise。如果手上已經是一個 Promise 陣列、想並行處理，用 `Promise.all()` 比較快；`Array.fromAsync()` 適合本來就要逐一產生值的非同步迭代器。
