# 20-2 Error.isError() {#20-2}

判斷一個值是否為真正的錯誤物件。

```js
Error.isError(new Error('oops')) // true
Error.isError(new TypeError('oops')) // true
Error.isError({ name: 'Error', message: 'oops' }) // false，只是長得像
```

### 為什麼不用 instanceof

`instanceof Error` 有兩個問題：

1. **跨 realm 會失效**：iframe、Node.js 的 `vm` 模組或 Worker 中建立的錯誤，繼承的是另一個環境的 `Error.prototype`，`instanceof` 會回傳 `false`。
2. **可以被偽造**：只要原型鏈上有 `Error.prototype`，`instanceof` 就會回傳 `true`。

```js
// 1. 跨 realm
const iframe = document.createElement('iframe')
document.body.append(iframe)
const err = new iframe.contentWindow.Error('oops')

err instanceof Error // false
Error.isError(err) // true

// 2. 偽造
const fake = Object.create(Error.prototype)

fake instanceof Error // true
Error.isError(fake) // false
```

`Error.isError()` 檢查的是物件是否擁有錯誤物件專屬的內部欄位，因此不受原型鏈影響。適合用在錯誤記錄、序列化等需要可靠判斷錯誤的地方。
