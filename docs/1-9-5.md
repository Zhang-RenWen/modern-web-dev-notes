## Vite {#1-9-5-1}

- **環境變數**：用 `import.meta.env` 讀，不要用 `process.env`；只有 `VITE_` 開頭的變數會被打包進前端，任何人都看得到，不能放機密。`.env.production` 裡不要設 `NODE_ENV`。
- **dev server**：proxy 只在本機有效，`secure: false` 只能在本機用。`allowedHosts` 用環境變數放行，不要把網域寫死。透過反向代理開發時，代理要支援 WebSocket，HMR 才會動。
- **為什麼快**：開發時用瀏覽器原生 ESM 按需編譯，第三方套件再用 esbuild 預打包；正式建置才打包。
- **lazy loading 失效**：同一個路由頁面如果既被靜態 import 又被動態 import，就不會拆出獨立 chunk。重型套件要真正按需載入（實例中首屏從 1.42MB 降到 218KB）。

```ts
// ❌ 其他地方又 import 了 Dashboard，這行的 lazy loading 就沒有作用
import Dashboard from './views/Dashboard.vue'
const routes = [{ path: '/', component: () => import('./views/Dashboard.vue') }]
```

## 打包時移除不該公開的程式 {#1-9-5-2}

- 判斷條件要用 bundler `define` 注入的布林字面值（例如 `__DEMO__`），打包時才能整段刪掉（dead code elimination）。
- 不想公開的邏輯不能靠 CSS 隱藏，要讓它根本不被打包、不產 sourcemap；模糊圖要存成像素圖（不是 CSS blur 的原圖）。
- 發佈前 grep bundle 驗證沒有殘留。

```ts
// vite.config.ts
export default defineConfig({ define: { __DEMO__: JSON.stringify(process.env.DEMO === '1') } })

// 原始碼：DEMO build 時這整段會被刪掉
if (!__DEMO__) {
  registerTradingSignals()
}
```

## 唯讀 Demo 與靜態發佈 {#1-9-5-3}

- **唯讀 Demo 只在 HTTP 層換資料來源**：GET 讀快照 JSON，寫入一律回唯讀錯誤，頁面元件完全不用改。
- **用 headless 瀏覽器擷取 API 回應做快照**：要等回應內容讀完、全部存好才換頁；只等到 HTTP 標頭就換頁，大型回應會被瀏覽器丟掉。擷取期間不要改原始碼或切分支，Vite 偵測到檔案變動會整頁重載（`ERR_ABORTED`）。
- **SPA 放在 GitHub Pages 子路徑**：設 build `base` 和 router basename，複製一份 `index.html` 當 `404.html`（讓深層網址重新整理不會 404），並加上 `.nojekyll`。免費方案只支援 public repo，所以私有主程式和公開產物要分兩個 repo。
- **純靜態站本機預覽**要用 `python3 -m http.server` 之類的伺服器；用 `file://` 開時 `fetch` 讀 JSON 會失敗。
- **嵌 GA** 時 script src 的 id 與 `gtag('config', …)` 的 id 必須是同一個 `G-` 開頭的評估 ID，上線後用 GA 即時報表確認。

## 周邊整合 {#1-9-5-4}

- 客製 IdP（如 Keycloak）登入頁時，只覆寫 CSS 和品牌 token，不要複製官方模板；改完用 headless 瀏覽器實際截桌機和手機畫面檢查。
- 設計稿的色彩變數從網站實際用的 token 產生，同一份 token 同時驅動網站和設計稿。
