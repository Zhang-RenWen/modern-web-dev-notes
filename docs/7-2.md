# 7-2 Math 物件

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017），已精簡成一覽表。ES2016 起可以用 `**` 取代 `Math.pow`。
:::

ES6 為 `Math` 加了 17 個方法，大多是補齊其他語言早就有的數學函式。

### 7-2-1 Math.sign {#7-2-1}

回傳正負號：`Math.sign(-3)` 是 `-1`，`Math.sign(0)` 是 `0`，`Math.sign(5)` 是 `1`（還有 `-0`、`NaN` 兩種特殊結果）。

### 7-2-2 Math.trunc {#7-2-2}

直接去掉小數部分：`Math.trunc(-4.7)` 是 `-4`。和 `Math.floor` 的差別在負數：`Math.floor(-4.7)` 是 `-5`。不要用 `~~x` 或 `x | 0` 代替，超過 32 位元的數字會出錯。

### 7-2-3 Math.cbrt {#7-2-3}

立方根：`Math.cbrt(27)` 是 `3`，負數也可以：`Math.cbrt(-8)` 是 `-2`（`(-8) ** (1/3)` 會得到 `NaN`）。

### 7-2-4 Math.expm1 {#7-2-4}

計算 eˣ − 1。x 非常接近 0 時，`Math.exp(x) - 1` 會因為浮點誤差失去精度，`Math.expm1(x)` 不會。

### 7-2-5 Math.log1p {#7-2-5}

計算 ln(1 + x)，同樣是為了 x 很接近 0 時的精度。

### 7-2-6 Math.log10 {#7-2-6}

以 10 為底的對數：`Math.log10(1000)` 是 `3`。可以用來算數字有幾位：`Math.floor(Math.log10(n)) + 1`。

### 7-2-7 Math.log2 {#7-2-7}

以 2 為底：`Math.log2(1024)` 是 `10`。

### 7-2-8 三角函數 {#7-2-8}

雙曲函數與反雙曲函數：`sinh`、`cosh`、`tanh`、`asinh`、`acosh`、`atanh`。

### 7-2-9 Math.hypot {#7-2-9}

所有參數平方和的平方根，也就是兩點距離：

```js
Math.hypot(3, 4)                     // 5
Math.hypot(x2 - x1, y2 - y1)         // 平面距離
Math.hypot(dx, dy, dz)               // 3D 距離
```

比自己寫 `Math.sqrt(a*a + b*b)` 好，不會在中間計算時溢位。

### 7-2-10 位元運算輔助 {#7-2-10}

| 方法 | 作用 |
| --- | --- |
| `Math.clz32(x)` | 32 位元表示中，前面有幾個 0（count leading zeros）：`Math.clz32(1)` 是 `31` |
| `Math.imul(a, b)` | 32 位元整數乘法，結果和 C 語言一樣會溢位；給編譯成 JS 的程式（asm.js、Emscripten）用 |
| `Math.fround(x)` | 轉成最接近的 32 位元浮點數：`Math.fround(5.5)` 是 `5.5`，`Math.fround(5.05)` 是 `5.050000190734863` |

ES2025 另外加了 `Math.f16round`（16 位元浮點），ES2026 的 `Math.sumPrecise` 見 [20-3](./20-3.md)。
