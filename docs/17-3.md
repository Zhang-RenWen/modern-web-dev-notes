# 17-3 Array.prototype.with {#17-3}

`Array` 實例的 `with()` 方法是使用括號表示法更改給定索引值的複製版本。它回傳一個新陣列，其中給定索引處的元素替換為給定值。

### 語法

```js
arrayInstance.with(index, value)
```

### Parameters 傳入參數

<dl v-pre><dt id="index"><code>index</code></dt><dd><p>Zero-based index at which to change the array, converted to an integer .</p><p>更改陣列從零開始的索引的值為整數。</p><ul><li>Negative index counts back from the end of the array — if <code>index &lt; 0</code> , <code>index + array.length</code> is used. 假如索引值為負數，索引值就會位於 <code>index + array.length</code> 。</li><li>If the index after normalization is out of bounds, a <code>RangeError</code> is thrown. 假如索引值超出標準化範圍，程式會出現 <code>RangeError</code> 。</li></ul></dd><dt id="value"><code>value</code></dt><dd><p>Any value to be assigned to the given index.</p><p>參數數值會被寫入的位置位於傳入參數給定的的指定索引值。</p></dd></dl>

### Return value 回傳值

一個新陣列，索引處的元素替換為值。

### Exceptions 例外

<dl v-pre><dt id="rangeerror"><code>RangeError</code></dt><dd><p>Thrown if <code>index &gt;= array.length</code> or <code>index &lt; -array.length</code> .</p></dd></dl>

### 說明

`with()` 方法更改陣列中給定索引的值，回傳一個新陣列，其中給定索引處的元素替換為給定值。原始陣列沒有被修改。這允許您在進行操作時鏈接陣列方法。

`with()` 方法永遠不會生成稀疏陣列。如果源陣列是稀疏陣列，則空槽將在新陣列中替換為 undefined。

`with()` 方法是通用的。它只期望 this 值具有長度屬性和整數鍵控屬性。

### 範例

### Creating a new array with a single element changed 創建一個更改了單個元素的新陣列

```js
const arr = [1, 2, 3, 4, 5];
console.log(arr.with(2, 6)); // [1, 2, 6, 4, 5]
console.log(arr); // [1, 2, 3, 4, 5]
```

### Chaining array methods 鏈式操作

使用 `with()` 方法，您可以更新陣列中的單個元素，然後應用其他陣列方法。

```js
const arr = [1, 2, 3, 4, 5];
console.log(arr.with(2, 6).map((x) => x ** 2)); // [1, 4, 36, 16, 25]
```

### Using with() on sparse arrays 將 with() 用在稀疏陣列

with() 方法總是創建一個密集陣列。

```js
const arr = [1, , 3, 4, , 6];
console.log(arr.with(0, 2)); // [2, undefined, 3, 4, undefined, 6]
```

### Calling with() on non-array objects 在類陣列物件中使用 with()

`with()` 方法創建並回傳一個新陣列。它讀取該屬性的 length 屬性，然後訪問其鍵為小於 length 的非負整數的每個屬性。當訪問該屬性的每個屬性時，索引等於該屬性鍵的陣列元素將被設置為該屬性的值。最後，將索引處的陣列值設置為 value。

```js
const arrayLike = {
  length: 3,
  unrelated: "foo",
  0: 5,
  2: 4,
  3: 3, // ignored by with() since length is 3
};
console.log(Array.prototype.with.call(arrayLike, 0, 1));
// [ 1, undefined, 4 ]
```
