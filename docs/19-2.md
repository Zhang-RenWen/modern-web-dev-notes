# 19-2 Set 新方法 {#19-2}

`Set` 新增 7 個集合運算方法，不必再自己用 `filter()` 或展開運算子實作。

```js
const a = new Set([1, 2, 3, 4])
const b = new Set([3, 4, 5])
```

### 回傳新 Set 的方法

| 方法 | 意義 | 結果 |
| --- | --- | --- |
| `a.union(b)` | 聯集：A 或 B | `Set {1, 2, 3, 4, 5}` |
| `a.intersection(b)` | 交集：A 且 B | `Set {3, 4}` |
| `a.difference(b)` | 差集：在 A 但不在 B | `Set {1, 2}` |
| `a.symmetricDifference(b)` | 對稱差集：只在其中一個 | `Set {1, 2, 5}` |

```js
// 以前的寫法
const intersectionOld = new Set([...a].filter((x) => b.has(x)))

// ES2025
const intersection = a.intersection(b)
```

### 回傳布林值的方法

```js
new Set([3, 4]).isSubsetOf(a) // true，{3, 4} 是 a 的子集
a.isSupersetOf(new Set([1, 2])) // true，a 包含 {1, 2}
a.isDisjointFrom(new Set([7, 8])) // true，兩者沒有交集
```

### 參數可以是「類 Set」物件

參數不一定要是 `Set`，只要有 `size` 屬性和 `has()`、`keys()` 方法即可，例如 `Map`（以 key 進行比較）：

```js
const permissions = new Map([
  ['read', true],
  ['write', true],
])

new Set(['read', 'delete']).difference(permissions) // Set {'delete'}
```

陣列沒有 `size` 和 `has()`，不能直接當參數，要先轉成 `Set`。
