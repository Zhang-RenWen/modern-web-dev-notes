# 18-6 Atomics.waitAsync() {#18-6}

`Atomics.wait()` 會**同步阻塞**執行緒，直到共享記憶體中的值被改變並收到通知，因此在瀏覽器主執行緒上不允許使用。`Atomics.waitAsync()` 是它的非同步版本：不阻塞，而是回傳一個 Promise，主執行緒也能使用。

```js
const sab = new SharedArrayBuffer(16)
const int32 = new Int32Array(sab)

// 等待 int32[0] 不再是 0，最多等 1000 毫秒
const result = Atomics.waitAsync(int32, 0, 0, 1000)

if (result.async) {
  result.value.then((status) => console.log(status)) // 'ok' 或 'timed-out'
} else {
  console.log(result.value) // 'not-equal' 或 'timed-out'
}

// 在其他 Worker（或稍後在同一個執行緒）改值並通知
Atomics.store(int32, 0, 1)
Atomics.notify(int32, 0)
```

回傳值是 `{ async, value }`：

| 情況 | `async` | `value` |
| --- | --- | --- |
| 目前的值和預期值不同 | `false` | `'not-equal'` |
| 逾時設為 0，且值相同 | `false` | `'timed-out'` |
| 開始等待 | `true` | Promise，之後 resolve 為 `'ok'` 或 `'timed-out'` |

::: info 使用 SharedArrayBuffer 的前提
瀏覽器中要使用 `SharedArrayBuffer`，頁面必須處於跨來源隔離（cross-origin isolated）狀態，也就是回應標頭要設定 `Cross-Origin-Opener-Policy: same-origin` 與 `Cross-Origin-Embedder-Policy: require-corp`。可用 `self.crossOriginIsolated` 檢查。
:::
