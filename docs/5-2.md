# Chapter 5 運用 ECMAScript 集合

## 5-2 瞭解並運用弱映射

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡，補上 ES2023 起「未註冊的 Symbol 也能當鍵」，以及 ES2021 的 `WeakRef`。
:::

`WeakMap` 和 `Map` 一樣是「鍵 → 值」，差別在**對鍵是弱參考**：只要鍵物件在別的地方都沒人用了，它就能被垃圾回收，對應的值也跟著消失。

### 5-2-1 弱映射是一個糟糕的映射？ {#5-2-1}

為了做到弱參考，`WeakMap` 少了一些功能：

| | `Map` | `WeakMap` |
| --- | --- | --- |
| 鍵 | 任何值 | 物件，或沒有用 `Symbol.for` 註冊的 Symbol（ES2023） |
| 方法 | `get`、`set`、`has`、`delete`、`clear`、`size` | 只有 `get`、`set`、`has`、`delete` |
| 走訪 | 可以 | **不行**：沒有 `keys`、`forEach`、`size`，因為內容隨時可能被回收，結果不確定 |
| 鍵被其他地方釋放後 | 仍然留在 Map 裡（記憶體洩漏） | 自動移除 |

```js
const meta = new WeakMap()
meta.set(Symbol(), 1)   // OK（ES2023 起）
meta.set('id', 1)       // TypeError：字串不能當鍵
```

所以它不是比較差的 `Map`，而是專門用在「**替別人的物件附加資料，又不想影響它的生命週期**」：

| 情境 | 例子 |
| --- | --- |
| DOM 元素的附加資料 | 元件實例、事件處理狀態；元素移除後自動清掉 |
| 快取計算結果 | `memoize` 以物件參數為鍵，物件沒人用時快取也一起釋放 |
| 私有資料 | class 的 `#` 欄位出現前，用模組層的 `WeakMap` 存每個實例的私有狀態 |
| 深拷貝處理循環參考 | 記錄「已經複製過的物件 → 它的副本」 |

```js
const widgets = new WeakMap()
function getWidget(el) {
  let w = widgets.get(el)
  if (!w) widgets.set(el, (w = createWidget(el)))
  return w
}
```

**`WeakRef`（ES2021）**：直接對一個物件持有弱參考，`ref.deref()` 拿到物件或 `undefined`（已被回收）；`FinalizationRegistry` 可以在物件被回收後收到通知。回收時機無法預測，只適合當快取這類「沒有也沒關係」的最佳化，不要拿來寫程式邏輯。
