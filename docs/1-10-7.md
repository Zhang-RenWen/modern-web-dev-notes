# 1-10-7 傳統機器學習模型地圖 {#1-10-7}

::: info 新增（2026-11）
整理自 Notion「計算機基礎」第 11 節〈傳統 ML 地圖〉。
:::

| 模型 | 核心 | 現代定位 |
| --- | --- | --- |
| Linear Regression | 預測連續數值（房價、營收、風險分數） | 可解釋性高，金融風控、A/B test 仍常用，沒過時 |
| Logistic Regression | 名為 regression 實為分類，輸出 P(y=1 \| x) 再用門檻分類 | 違約、流失、詐欺、點擊預測；可延伸多分類 |
| KNN | 看最近 K 個鄰居投票或平均，不假設資料分佈 | 幾乎沒有訓練、預測很慢、高維失效；**使用前必須 normalize／standardize** |
| SVM | maximum margin、support vectors、kernel trick | 經典觀念重要，但大資料主流度下降 |
| AdaBoost | 後面的模型提高「前面分錯樣本」的權重（不是專注 feature），弱模型組成強模型 | boosting 入門；表格資料實務主流是 XGBoost／LightGBM／CatBoost |

- 完整地圖：統計可解釋（Linear／Logistic）→ 距離型（KNN）→ 最大間隔（SVM）→ 樹（Decision Tree、Random Forest）→ Boosting（AdaBoost、GBDT、XGBoost、LightGBM、CatBoost）→ 非監督（K-Means、PCA）→ 深度學習（CNN、RNN／LSTM、Transformer）。
