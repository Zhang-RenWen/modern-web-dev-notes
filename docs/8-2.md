# 8-2 JavaScript 模組

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017），已精簡；動態 `import()` 已在 ES2020 成為標準。
:::

### 8-2-1 嚴格模式 {#8-2-1}

ES Module 自動是嚴格模式，不需要寫 `'use strict'`：未宣告就賦值會報錯、頂層 `this` 是 `undefined`、不能用 `with`。每個模組有自己的頂層作用域，頂層宣告的變數不會變成全域變數。

### 8-2-2 export {#8-2-2}

```js
export const pi = 3.14           // 具名匯出
export function area(r) { return pi * r * r }

const a = 1, b = 2
export { a, b as two }           // 匯出清單，可以改名

export default class Circle {}  // 預設匯出：每個模組最多一個

export { sum } from './math.js'  // 轉匯出（不會在這個模組建立區域變數）
export * from './utils.js'       // 轉匯出全部具名匯出（不含 default）
export * as utils from './utils.js' // ES2020：包成一個命名空間匯出
```

**匯出的是綁定，不是值**：模組內部改了變數，匯入方讀到的也會更新（見 [1-9-1](./1-9-1.md#1-9-1-2)）；但匯入方不能對匯入的變數重新賦值。

建議多用具名匯出：名稱固定，比較好搜尋與自動匯入，tree shaking 也比較有效。

### 8-2-3 import {#8-2-3}

```js
import Circle from './circle.js'                // 預設匯出，名稱自己取
import { pi, area as circleArea } from './circle.js' // 具名匯入，可以改名
import Circle2, { pi as PI } from './circle.js' // 兩種一起
import * as geometry from './circle.js'         // 命名空間物件：geometry.pi、geometry.default
import './polyfills.js'                         // 只執行，不取任何東西
import data from './data.json' with { type: 'json' } // ES2025：匯入屬性
```

- `import` 會被提升，而且只能寫在模組頂層，路徑必須是字串常數。
- 瀏覽器裡路徑要寫完整（含 `./` 和副檔名），或靠 import map 對應套件名稱；打包工具與 Node.js 則有自己的解析規則。
- 同一個模組被匯入多次，只會執行一次。
- 循環匯入不會報錯，但在對方還沒執行完時讀取它的匯出會碰到 TDZ 錯誤，要避免互相依賴。

### 8-2-4 動態 import() {#8-2-4}

`import(路徑)` 回傳 Promise，可以寫在任何地方、路徑可以是變數（ES2020，詳見 [14-4](./14-4.md)）：

```js
button.addEventListener('click', async () => {
  const { openEditor } = await import('./editor.js') // 點了才載入，打包工具會切成獨立檔案
  openEditor()
})

const messages = await import(`./locales/${lang}.js`) // 依語系載入
```

- 用途：路由層級的程式碼分割、很少用到的大功能（編輯器、圖表）、依條件載入的 polyfill。
- 路徑完全動態時，打包工具無法分析，會把符合樣式的所有檔案都打包，或乾脆無法處理；盡量讓路徑有固定的前綴與副檔名。
- 載入失敗（網路、部署後舊檔被刪）會 reject，要 `catch` 起來提示使用者重新整理。
