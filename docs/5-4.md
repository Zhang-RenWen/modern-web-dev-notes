# Chapter 5 運用 ECMAScript 集合

## 5-4 的弱集合

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡並修正原筆記把方法寫成 `.set` 的錯誤（`WeakSet` 是 `.add`）。
:::

`WeakSet` 之於 `Set`，就像 `WeakMap` 之於 `Map`：只能放物件（或未註冊的 Symbol），**弱參考**，不能走訪，只有 `add`、`has`、`delete`。

適合「只需要標記某個物件有沒有被處理過」，又不想阻止它被回收的情況。

**偵測循環參考**：走訪物件樹時記住已經看過的物件，遇到就跳過。

```js
function listOwnProperties(input, seen = new WeakSet()) {
  if (input === null || typeof input !== 'object' || seen.has(input)) return []
  seen.add(input)
  return Object.entries(input).flatMap(([key, value]) => [key, ...listOwnProperties(value, seen)])
}

const circle = { r: 15 }
circle.self = circle // 循環參考
listOwnProperties(circle) // ['r', 'self']：不會無限遞迴
```

**標記 DOM 元素的狀態**：例如記錄哪些元素已經初始化過，不必在元素上加屬性或 class，元素被移除後也不會殘留。

```js
const initialized = new WeakSet()
function init(el) {
  if (initialized.has(el)) return
  initialized.add(el)
  // …
}
```

**限制方法只能由自己建立的實例呼叫**：

```js
const cars = new WeakSet()
class Car {
  constructor() { cars.add(this) }
  drive() {
    if (!cars.has(this)) throw new TypeError('drive 只能由 Car 實例呼叫')
  }
}
```

現在這個需求也可以用私有欄位寫：`static isCar(x) { return #brand in x }`。
