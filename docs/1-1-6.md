## WCAG 2.1 AA（POUR） {#1-1-6-1}

- **可感知**：圖片要有 `alt`、影片要有字幕。
- **可操作**：全功能可用鍵盤操作、避免引發癲癇的閃爍。
- **可理解**：色彩對比足夠、表單錯誤提示明確。
- **穩定**：相容各瀏覽器與螢幕閱讀器。
- AA 是多數企業與政府（含台灣數位發展部）的合規基準。

## 高價值 HTML {#1-1-6-2}

- 語意標籤：header、nav、main（一頁一個）、section、article、aside、footer；標題階層 h1–h3 照內容層級，不為字體大小跳級。
- head 重點：charset、viewport、description、title（比 meta keywords 重要得多）。
- 表單：label、name/value、fieldset + legend、required / pattern / min / max / autocomplete；`disabled` 不會送出、`readonly` 會送出；`accept` 只是提示，不是安全驗證。
- 圖片：`srcset` + `sizes` 讓瀏覽器挑合適尺寸；寫 width/height 預留空間。
- 原生互動：`details` / `summary`（FAQ）、`dialog` + `showModal()`（Modal）。
- 影片 `poster`、連結 `download`（跨網域不保證有效）、`tel:` / `mailto:`、`#id` 錨點。
- `contenteditable` 不等於編輯器：要處理 XSS、貼上 HTML、IME、Undo。

## 常見錯誤修正 {#1-1-6-3}

- `alt` 是替代文字（載入失敗、螢幕閱讀器），不是 hover 提示。
- `option` 裡的文字是使用者看到的，`value` 是送出的值。
- `del` 是被刪除的內容；`s` 是不再正確的內容；淘汰 tt、strike、acronym、`a name`、img align/border。
- `script type="text/javascript"`、`style type="text/css"` 不必寫；ES module 才寫 `type="module"`。
- table 只用來呈現表格資料，不拿來排版。
