# 6-2 可廢止的代理器

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017），已精簡。
:::

`Proxy.revocable(target, handler)` 建立一個可以「撤銷」的代理，回傳 `{ proxy, revoke }`。呼叫 `revoke()` 之後，對 `proxy` 的**任何操作**都會丟 `TypeError`，而且無法恢復。

```js
const { proxy, revoke } = Proxy.revocable({ secret: 42 }, {})
proxy.secret // 42
revoke()
proxy.secret // TypeError: Cannot perform 'get' on a proxy that has been revoked
```

用途：**限時授權**。把物件交給第三方程式（外掛、另一個模組）時，給的是可撤銷的代理；用完或權限到期就 `revoke()`，對方手上的參考立刻失效，原物件也能被回收。

```js
function lend(resource, ms) {
  const { proxy, revoke } = Proxy.revocable(resource, {})
  setTimeout(revoke, ms)
  return proxy
}
```
