# Chapter 7 ES6 內建功能優化

## 7-1 數值

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡成「每個 API 一句話 + 例子 + 陷阱」，補上數字分隔符（ES2021）與 BigInt（ES2020）的連結。
:::

### 7-1-1 二進位和八進位實字 {#7-1-1}

```js
0b1010   // 10：二進位
0o17     // 15：八進位（舊的 017 寫法在嚴格模式下是語法錯誤）
0xff     // 255：十六進位
1_000_000 // 數字分隔符（ES2021），只是為了好讀
Number('0b101') // 5：字串也能轉
(10).toString(2) // '1010'：轉成其他進位的字串
```

### 7-1-2 Number.isNaN {#7-1-2}

只有值**真的是** `NaN` 才回傳 `true`：

```js
isNaN('abc')        // true：全域的 isNaN 會先轉型，'abc' 轉成 NaN
Number.isNaN('abc') // false：不轉型
Number.isNaN(NaN)   // true
```

`NaN` 是唯一不等於自己的值，也可以用 `x !== x` 或 `Object.is(x, NaN)` 判斷。

### 7-1-3 Number.isFinite {#7-1-3}

```js
isFinite('10')        // true：全域版會轉型
Number.isFinite('10') // false
Number.isFinite(Infinity) // false
```

### 7-1-4 Number.parseInt {#7-1-4}

和全域的 `parseInt` 是同一個函式，只是掛到 `Number` 底下，減少全域函式。**一定要傳第二個參數（進位）**：`parseInt('08', 10)`。

`parseInt` 會從頭讀到不是數字為止：`parseInt('12px')` 是 `12`；要整個字串都是數字才算數時用 `Number('12px')`（得到 `NaN`）。

### 7-1-5 Number.parseFloat {#7-1-5}

同上，等於全域的 `parseFloat`：`Number.parseFloat('3.14abc')` 是 `3.14`。

### 7-1-6 Number.isInteger {#7-1-6}

```js
Number.isInteger(5)    // true
Number.isInteger(5.0)  // true：JS 裡 5.0 和 5 是同一個數字
Number.isInteger('5')  // false：不轉型
```

### 7-1-7 Number.EPSILON {#7-1-7}

浮點數無法精確表示很多小數：`0.1 + 0.2 === 0.3` 是 `false`（結果是 `0.30000000000000004`）。`Number.EPSILON`（約 2.2e-16）是 1 和下一個可表示的數之間的差距，可以當容許誤差：

```js
const almostEqual = (a, b) => Math.abs(a - b) < Number.EPSILON * Math.max(1, Math.abs(a), Math.abs(b))
almostEqual(0.1 + 0.2, 0.3) // true
```

金額不要用浮點數計算：換成最小單位的整數（分、元）計算，或用 decimal 函式庫。

### 7-1-8 Number.MAX_SAFE_INTEGER 和 Number.MIN_SAFE_INTEGER {#7-1-8}

`Number` 是 64 位元浮點數，只有 ±(2⁵³ − 1)（約 9 千兆）以內的整數能精確表示：

```js
Number.MAX_SAFE_INTEGER        // 9007199254740991
Number.MAX_SAFE_INTEGER + 2    // 9007199254740992：錯了，應該是 …993
```

超過這個範圍的整數用 [BigInt](./14-5.md)（`9007199254740993n`）。後端傳來的 64 位元 ID 要用**字串**傳，否則 `JSON.parse` 後就失真了。

### 7-1-9 Number.isSafeInteger {#7-1-9}

```js
Number.isSafeInteger(2 ** 53 - 1) // true
Number.isSafeInteger(2 ** 53)     // false
```

做整數運算時，**輸入和結果**都要在安全範圍內，結果才可信。
