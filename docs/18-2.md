# 18-2 Promise.withResolvers() {#18-2}

一次取得 Promise 本身和它的 `resolve`、`reject` 函式。適合在「建立 Promise 的地方」和「決定結果的地方」不同時使用，例如包裝事件或回呼。

```js
// 以前的寫法：要把 resolve / reject 存到外層變數
let resolve, reject
const promise = new Promise((res, rej) => {
  resolve = res
  reject = rej
})

// ES2024
const { promise, resolve, reject } = Promise.withResolvers()
```

### 實際應用：等待一次性事件

```js
function waitForEvent(target, type) {
  const { promise, resolve } = Promise.withResolvers()
  target.addEventListener(type, resolve, { once: true })
  return promise
}

const event = await waitForEvent(document.querySelector('button'), 'click')
console.log('按鈕被點擊了', event)
```

### 實際應用：把串流轉成 Promise

```js
function readAll(stream) {
  const { promise, resolve, reject } = Promise.withResolvers()
  const chunks = []
  stream.on('data', (chunk) => chunks.push(chunk))
  stream.on('end', () => resolve(Buffer.concat(chunks)))
  stream.on('error', reject)
  return promise
}
```

`resolve` 和 `reject` 的行為與 `new Promise()` 執行器中拿到的完全相同：只有第一次呼叫有效，之後的呼叫會被忽略。
