# 1-17-2 Cron 排程 {#1-17-2}

::: info 新增（2026-11）
整理自 Notion「開發工具與 DevOps」第 6 節。
:::

```txt
* * * * * command
分 時 日 月 星期(0=Sun)

0 * * * *      每小時
*/15 * * * *   每 15 分鐘
0 */2 * * *    每 2 小時
30 2 * * *     每天 02:30
0 0 * * 0      每週日 00:00
0 0 1 * *      每月 1 號
@reboot        開機後（container / 雲端排程不一定支援）
```

**實務坑**：

- cron 不吃你的 shell 環境 → 寫完整路徑 `/usr/bin/node /app/job.js`
- 一定要留 log：`… >> /var/log/job.log 2>&1`
- 時區：伺服器多半是 UTC（VPS、container、GitHub Actions schedule 都要注意）
- 任務重疊：每 5 分鐘觸發但跑 10 分鐘 → 需要 lock、idempotency、timeout
- **Cron 只負責「何時啟動」，不負責可靠性**（重試、超時、告警、多機誰跑）。

| 場景 | 工具 |
| --- | --- |
| 簡單腳本 | cron |
| 服務級排程（要依賴、重啟、log） | systemd timer |
| 容器環境 | Kubernetes CronJob |
| AWS | EventBridge Scheduler |
| 企業批次 / 資料流程 | Airflow、Jenkins、Control-M |
