## 自適應判斷 {#1-2-5-1}

- **導覽列要不要收進選單，不要寫死斷點**：改用 `scrollWidth` 和可用寬度實際比對，搭配 `ResizeObserver` 和 `useLayoutEffect`（在畫面繪製前量尺寸，避免閃爍），因為不同語系的文字長度可以差 20% 以上。
- **media query 看的是 viewport，不是元素寬度**；要依容器寬度變化就用 Container Query。手機要匯出桌機版截圖時，暫時把 meta viewport 改成 `width=1280`，還原時先鎖 `scale=1`。

```js
// 依實際內容寬度決定是否收合，而不是寫死 768px
const ro = new ResizeObserver(() => {
  setCollapsed(nav.scrollWidth > nav.clientWidth)
})
ro.observe(nav)
```

## Grid／Flex／斷行 {#1-2-5-2}

- Grid 的 `1fr` 最小值等於內容寬度，會讓圖表撐爆版面，要改成 `minmax(0, 1fr)`；flex 子項要加 `min-width: 0`。
- 檢查手機溢出時，用固定寬度（例如 390px）比對，不要用 `innerWidth`。
- 寬圖表在手機上照桌機版面畫，再整張等比縮小。SVG 設了 `touch-action: pan-y` 時，水平滑動會被吃掉。
- `overflow-wrap: anywhere` 會從單字中間斷開，一般情況用 `break-word`；改共用樣式前先 grep 影響範圍。

## CSS 小修法 {#1-2-5-3}

- macOS 原生 `select` 的箭頭不吃 padding：用 `appearance: none` 加自繪箭頭，並用較高權重的選擇器排除已有自訂樣式的元件。
- 圓形按鈕在 flex 裡變橢圓：子項加 `flex: none`、`padding: 0`。
- 字元圖示（×）改用 SVG 才會真正置中。

## 相容性 {#1-2-5-4}

- iOS 的 `100vh` 包含網址列，改用 `dvh`／`svh`；iOS 上輸入框字型小於 16px 會在聚焦時自動放大。
- 支援的瀏覽器寫在 `browserslist`；iOS 上所有瀏覽器都是 WebKit，一律用 Safari 測。Safari 的 Date 解析坑見 JS 面試核心與語法陷阱。
- 要匯出「文字可選取」的 PDF，走瀏覽器列印加 `@media print`；Canvas 或 html-to-image 輸出的 PNG 會失去文字。

## 驗證方式：「寬度 × 語系」矩陣 {#1-2-5-5}

- 版面修改要在真實瀏覽器跑矩陣量測與截圖：375／768／1280／1440／1920 × 每個語系。
- 在 production／preview build 上量（`vite preview`），不要量 dev server 的熱更新狀態。
- 英文、日文標籤常比中文寬 1.2～1.5 倍，自動收合可能只在某個語系觸發。
- 改共用樣式前先查繼承與影響範圍，用前後數字證明修好。
