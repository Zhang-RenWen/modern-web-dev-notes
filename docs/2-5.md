# 2-5 字串樣板

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。修正 `new Date.toLocaleTimeString()` 的語法錯誤；原本「用正規表達式移除 iframe 來防 XSS」的範例是錯誤示範，改成跳脫特殊字元。
:::

用反引號 `` ` `` 包住的字串，裡面的單雙引號不用跳脫。

### 2-5-1 字串插值 {#2-5-1}

`${}` 裡可以放任何運算式，結果會轉成字串：

```js
const name = 'Shannon'
`Hello, ${name}`                                  // 'Hello, Shannon'
`現在時間 ${new Date().toLocaleTimeString()}`      // 呼叫函式
`2 + 3 = ${2 + 3}`                                 // '2 + 3 = 5'
`${isVip ? 'VIP' : '一般'}會員`                     // 條件
```

### 2-5-2 多行字串 {#2-5-2}

換行會原樣保留，不用再寫 `\n` 或用陣列 `join('\n')`：

```js
const html = `
  <ul>
    ${items.map((item) => `<li>${item}</li>`).join('')}
  </ul>
`
```

程式碼縮排也會被當成字串內容。在意的話自己去掉共同縮排（或用 `dedent` 套件），HTML 通常不在意。

### 2-5-3 標籤樣板 {#2-5-3}

在樣板前面放一個函式，它會收到「固定文字的陣列」和「各個插值」，自己決定怎麼組合：

```js
function tag(strings, ...values) {
  // strings：['Hello, ', '. I am ', ' to meet you!']（永遠比 values 多一個）
  // values：['Maurice', 'thrilled']
  return strings.reduce((out, str, i) => out + values[i - 1] + str)
}
tag`Hello, ${'Maurice'}. I am ${'thrilled'} to meet you!`
```

**`String.raw`**：內建的標籤，不處理跳脫字元，寫正規表達式字串或 Windows 路徑很方便。

```js
String.raw`C:\new\table` // 'C:\\new\\table'（\n、\t 不會變成換行和 Tab）
```

**防 XSS：跳脫插值，不要用正規表達式刪標籤**。刪 `<iframe>` 擋不住 `<img onerror>`、`<svg onload>` 等無數變形；正確做法是把插值裡的特殊字元全部跳脫：

```js
const escape = (s) =>
  String(s).replace(/[&<>"']/g, (c) => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' })[c])

function html(strings, ...values) {
  return strings.reduce((out, str, i) => out + escape(values[i - 1]) + str)
}
html`<div>${userComment}</div>` // 使用者輸入的 <script> 會變成純文字
```

標籤樣板的實際應用：`styled-components` 的 `` styled.div`…` ``、`lit` 的 `` html`…` ``、GraphQL 的 `` gql`…` ``、SQL 函式庫用它把插值安全地轉成參數化查詢。標籤函式還可以從 `strings.raw` 拿到未處理跳脫的原始字串。
