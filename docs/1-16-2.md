# 1-16-2 記憶體與儲存 {#1-16-2}

::: info 新增（2026-11）
整理自 Notion「計算機基礎」第 2 節。
:::

```txt
Register → L1/L2/L3 Cache（SRAM）→ RAM（DRAM）→ SSD → HDD／網路儲存
越左：越快、越貴、越小、越靠近 CPU
越右：越慢、越便宜、越大、適合長期保存
```

| 類型 | 特性 | 用在哪 |
| --- | --- | --- |
| SRAM | 快、貴、容量小、不需 refresh | CPU L1／L2／L3 Cache |
| DRAM（DDR4／DDR5） | 主記憶體主線，便宜、容量大、需 refresh、斷電消失 | 一般電腦、伺服器 |
| ECC RAM | 可偵錯並更正位元錯誤 | 伺服器、金融等可靠性場景 |
| LPDDR | 低功耗 | 手機、筆電 |
| GDDR／HBM | 超高頻寬 | 顯示卡、AI／GPU 運算 |
| ROM／EEPROM／Flash ROM | 非揮發，斷電保留 | 韌體、BIOS／UEFI、嵌入式 |
| SSD（NAND Flash）／HDD／USB／SD | 這是 **Storage**，不是 Memory | 長期保存資料 |

- **日常現象解釋**：程式開太多 → RAM 滿 → 系統把資料暫放到磁碟（swap）→ 明顯變慢；重開機變順＝RAM 被清空。RAM 存取約奈秒級、SSD 約微秒級，所以 OS 會先把要執行的資料從 SSD 搬進 RAM。
- 歷史名詞知道即可：RDRAM、PROM、EPROM；舊教材的「External Memory」現代改叫 Storage。
