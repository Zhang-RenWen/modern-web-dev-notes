## AI／Agentic 瀏覽器 {#1-5-8-1}

瀏覽器正從「顯示網頁的工具」變成「替你操作網頁的代理人」。技術上多半是：在 Chromium 殼上加一個能讀取 DOM、無障礙樹（Accessibility Tree）或截圖的 AI，再透過模擬點擊、輸入來執行多步驟任務。

- **Chrome + Gemini**：2026 年 1 月把 Gemini 3 直接整合進 Chrome，加上常駐側欄與代理功能 Auto Browse。
- **ChatGPT Atlas**：OpenAI 在 2025 年 10 月推出、基於 Chromium，始終只有 macOS 版，最後被收回併入 ChatGPT 本體，2026 年 8 月停止服務。
- **Perplexity Comet**：反向策略，基礎瀏覽器免費，並推出 Android 版。
- **擴充功能路線**：Claude for Chrome 等以擴充功能形式存在的代理，在 2026 年快速成長。
- **Firefox**：148 版（2026 年 2 月）推出 AI Controls，讓使用者能集中管理 AI 功能。

**觀察**：幾乎所有 AI 瀏覽器都是 Chromium 殼，所以這波浪潮**加深而非打破** Blink 的主導地位。新的工程問題是：代理的提示注入（prompt injection）防護、代理如何標示身分（User-Agent）、網站如何區分人與代理，目前業界尚無統一標準。附帶好處：無障礙做得好的網站，AI 代理也操作得比較順。

## 新的獨立引擎：Ladybird {#1-5-8-2}

- 完全從零開始，不含 Blink、WebKit、Gecko 任何程式碼，由非營利組織 Ladybird Browser Initiative 開發，創辦人為 Andreas Kling 與 GitHub 共同創辦人 Chris Wanstrath。
- 規劃 2026 年推出 Linux／macOS 的 alpha，2027 年 beta、2028 年穩定版。
- 堅持不收預設搜尋引擎分潤或任何使用者變現收入。
- 意義：引擎多樣性是 Web 標準能維持「標準」而不是「某家實作」的前提。

## 其他持續中的方向 {#1-5-8-3}

- **記憶體安全語言**：各家持續把高風險元件（解析器、字型、圖片解碼）改寫成 Rust 等語言，因為瀏覽器高危漏洞大多是記憶體安全問題。
- **Interop 專案**：Apple、Google、Microsoft、Mozilla 等每年共同挑選重點 Web 功能，目標是讓各引擎行為一致，Web Platform Tests（WPT）是共同的考卷。
- **WebGPU**：取代 WebGL 的現代 GPU API，讓瀏覽器內能跑通用運算與本地 AI 推論。
- **View Transitions、Popover、Anchor Positioning、Container Queries** 等，讓原本需要大量 JS 的 UI 改由瀏覽器原生處理（見現代 CSS 特色）。

## 名詞剖析 {#1-5-8-4}

| 名詞 | 意思 |
| --- | --- |
| Agentic Browser | 內建 AI 代理、能替使用者自動操作網頁的瀏覽器 |
| Accessibility Tree | 瀏覽器從 DOM 算出、只留角色、名稱、狀態的簡化樹 |
| Prompt injection | 網頁內容裡藏指令，誘導 AI 代理做使用者沒要求的事 |
| User-Agent | 瀏覽器在請求中表明身分的字串 |
| Interop／WPT | 各家共同挑重點功能對齊行為的年度專案／跨瀏覽器的共用測試套件 |
| WebGPU | 新一代瀏覽器 GPU API，支援繪圖與通用運算 |
| View Transitions | 瀏覽器原生的頁面／狀態切換動畫 |
| Popover／Anchor Positioning | 原生彈出層／讓元素用 CSS 定位在另一個元素旁邊 |
| Container Queries | 依容器而非視窗大小套用樣式 |
