## ESP32 {#1-16-6-1}

- **ESP32**＝便宜、低功耗的 MCU 晶片／開發平台，內建 CPU、RAM、Wi-Fi、BLE、GPIO、ADC、PWM、UART／SPI／I²C。通常不跑完整 Linux，直接執行燒錄進去的程式（這點跟 Raspberry Pi 不同）。
- Arduino 是開發生態，ESP32 是晶片系列；ESP32 可用 Arduino IDE／framework 開發，入門門檻低。
- **在工程地圖的位置**：Web Frontend → Backend → System／Network → IoT → **Firmware（ESP32）** → Embedded → Driver → Hardware → IC Design。是軟體與電子工程的交界點。
- 韌體會碰到：C／C++、pointer 與記憶體配置、GPIO、interrupt、timer、FreeRTOS（task／queue／semaphore）、driver、watchdog、bootloader、OTA 更新。Web 是 `await fetch()`；韌體是 Sensor → I²C Driver → Interrupt → RTOS Task → Queue → Network Task → TCP/IP → Wi-Fi。
- **目標專案（不必轉職韌體，能串成一條就夠）**：

```txt
溫度感測器 → ESP32 → Wi-Fi → MQTT → Backend（Fastify／Java）→ PostgreSQL → Vue Dashboard
```

- 下一步：分清 MCU、韌體、嵌入式系統、RTOS、Embedded Linux 五個詞。

## 學習資源與案例 {#1-16-6-2}

- **OS Kernel**（被推為寫程式的「九陽真經」，程式執行時棘手問題的解法大全，會大幅提升系統設計能力）：恐龍書先讀一輪 → 曹孝櫟教授、黃敬群（jserv）的公開課；一定要自己實作，課程每年會調整。
- **網路**：《趣味網絡圖解：從基礎到應用》，問題導向＋Wireshark 抓包（含定位 timeout 問題），[1-18-18](./1-18-18.md) 的自我檢測題整理自此書目錄。
- **影片**：[12分鐘略懂電腦內部原理](https://www.youtube.com/watch?v=02aPuDeTfyE)、[線性代數又名人工智慧數學基礎](https://www.youtube.com/watch?v=ayKL0wbyP9Q)、[漫士：遊戲背後的數學](https://www.youtube.com/watch?v=je0x_JpLSWE)
- **案例：Linus Torvalds 退回 Google RISC-V 的 PR（Linux 6.17 merge window）**：既遲交，又把非 RISC-V 專屬的東西塞進通用 header。教訓：遵守期限；真的遲交，品質至少要好；改動不要超出自己負責的範圍、不要污染共用檔案。公司 code review 一樣適用。
- 量子計算只留一句：想做這塊，先把 Python 練到能自己建虛擬環境、處理 dependency、寫 class（Qiskit 0.4x 到 1.0 的差異就能卡住研究）。
