## 19-1 Iterator helpers {#19-1}

迭代器（iterator）終於有了類似陣列的 `map`、`filter` 等方法。與陣列方法最大的不同是：迭代器方法是**惰性求值**（lazy），每次只處理一個值，不會先建立中間陣列，因此也能處理無限序列。

新增在 `Iterator.prototype` 上的方法：

| 回傳新的迭代器 | 消耗迭代器並回傳結果 |
| --- | --- |
| `map()`、`filter()`、`take()`、`drop()`、`flatMap()` | `reduce()`、`toArray()`、`forEach()`、`some()`、`every()`、`find()` |

```js
function* naturals() {
  let n = 0
  while (true) yield n++
}

// 無限序列：取前 5 個偶數的平方
const result = naturals()
  .filter((n) => n % 2 === 0)
  .map((n) => n * n)
  .take(5)
  .toArray()

console.log(result) // [0, 4, 16, 36, 64]

naturals().drop(3).take(2).toArray() // [3, 4]
```

如果改用陣列，就得先產生完整的陣列，對無限序列來說根本做不到。

### 搭配 Map、Set 使用

`Map`、`Set` 的 `keys()`、`values()`、`entries()` 都回傳迭代器，可以直接串接，不必先轉成陣列：

```js
const scores = new Map([
  ['Alice', 92],
  ['Bob', 58],
  ['Carol', 75],
])

const passed = scores
  .entries()
  .filter(([, score]) => score >= 60)
  .map(([name]) => name)
  .toArray()

console.log(passed) // ['Alice', 'Carol']
```

### Iterator.from()

把任何可迭代物件，或只有 `next()` 方法的物件，包裝成擁有這些輔助方法的迭代器：

```js
const counter = {
  i: 0,
  next() {
    return this.i < 3 ? { value: this.i++, done: false } : { value: undefined, done: true }
  },
}

Iterator.from(counter).map((x) => x * 10).toArray() // [0, 10, 20]
```

::: tip 陣列與迭代器的差別
`[1, 2, 3].map()` 是陣列方法，會立即建立新陣列；`[1, 2, 3].values().map()` 是迭代器方法，回傳的是迭代器，要呼叫 `toArray()` 或用 `for...of` 才會真正執行。
:::
