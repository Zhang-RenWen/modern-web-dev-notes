# 3-2 符號

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡並修正範例中的大小寫錯誤（`getOwnPropertyNames`、`Symbol.toPrimitive`），補上 `description` 屬性（ES2019）。
:::

`Symbol` 是 ES2015 加入的原始型別：**每次建立都是獨一無二的值**，主要用途是當作不會和別人撞名的屬性鍵。

### 3-2-1 建立與特性 {#3-2-1}

```js
const s = Symbol('weapon')    // 參數只是描述，方便除錯
Symbol('a') === Symbol('a')   // false：描述相同也是不同的符號
typeof s                      // 'symbol'
s.description                 // 'weapon'（ES2019）
new Symbol()                  // TypeError：不能用 new
```

當屬性鍵使用時，一般的列舉方式**都看不到**：

```js
const character = { name: 'Penguin', [s]: 'umbrella' }
character[s]                          // 'umbrella'
Object.keys(character)                // ['name']
JSON.stringify(character)             // '{"name":"Penguin"}'
Object.getOwnPropertySymbols(character) // [Symbol(weapon)]
Reflect.ownKeys(character)            // ['name', Symbol(weapon)]：全部的鍵
```

它不是真正的私有（`getOwnPropertySymbols` 拿得到），只是不會被意外存取或覆蓋。真正的私有用 class 的 `#` 欄位。

### 3-2-2 使用情境 {#3-2-2}

**在別人的物件上掛資料，不怕撞名**：例如在 DOM 元素上記住已經初始化過的元件實例。

```js
const instance = Symbol('calendar')
function createCalendar(el) {
  if (el[instance]) return el[instance] // 避免重複初始化
  return (el[instance] = { /* 日曆 API */ })
}
```

這種「物件 → 附加資料」的對應，用 `WeakMap` 更乾淨：不會改到元素本身，元素被移除後資料也能被回收。

**定義協定**：函式庫用自己的符號定義「物件可以自訂某個行為」，因為是符號，不會和使用者的屬性名稱衝突。例如 `toJSON` 是一般字串屬性，物件剛好有個叫 `toJSON` 的資料欄位就會出錯；用符號就沒有這個風險。

### 3-2-3 全域符號註冊表 {#3-2-3}

`Symbol.for(key)` 依字串 key 在**整個執行環境（含 iframe、Worker 以外的同一個 realm 群組）共用**的註冊表裡找符號，沒有就建立：

```js
Symbol.for('app.id') === Symbol.for('app.id') // true
Symbol.keyFor(Symbol.for('app.id'))           // 'app.id'
Symbol.keyFor(Symbol('app.id'))               // undefined：一般符號不在註冊表裡
```

跨 iframe 也拿得到同一個符號。因為是全域的，key 要加上命名空間（例如 `'mylib.cache'`），避免和其他函式庫撞名。

### 3-2-4 內建符號 {#3-2-4}

語言本身用一組內建符號開放「自訂物件行為」的入口：

| 符號 | 讓你自訂 |
| --- | --- |
| `Symbol.iterator` | `for...of`、展開、解構怎麼走訪這個物件（見 [4-2](./4-2.md)） |
| `Symbol.asyncIterator` | `for await...of` |
| `Symbol.toPrimitive` | 轉成原始值時的結果 |
| `Symbol.toStringTag` | `Object.prototype.toString` 顯示的名稱 |
| `Symbol.hasInstance` | `instanceof` 的判斷方式 |

```js
const money = {
  [Symbol.toPrimitive](hint) {
    return hint === 'number' ? 100 : 'NT$100' // hint：'number'、'string'、'default'
  },
}
+money          // 100
`${money}`      // 'NT$100'
```

內建符號在所有 realm 之間是共用的，所以 iframe 裡建立的陣列一樣有正確的 `Symbol.iterator`。
