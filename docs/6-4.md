# 6-4 進階的代理器機關

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017），已精簡；原文 6-4-4 與 6-4-5 標題重複，修正為 `getPrototypeOf` 與 `setPrototypeOf`。
:::

Proxy 一共有 13 個機關，對應 `Reflect` 的 13 個方法。前兩頁介紹了 `get`、`set`、`has`、`deleteProperty`、`defineProperty`、`ownKeys`，這頁是其餘的。

### 6-4-1 getOwnPropertyDescriptor {#6-4-1}

攔截 `Object.getOwnPropertyDescriptor`、`hasOwnProperty`、`Object.hasOwn`。要讓屬性徹底隱藏，也要攔這個：

```js
handler.getOwnPropertyDescriptor = (t, key) =>
  hidden(key) ? undefined : Reflect.getOwnPropertyDescriptor(t, key)
```

### 6-4-2 apply：攔截函式呼叫 {#6-4-2}

目標是函式時才有作用，攔截一般呼叫、`call`、`apply`：

```js
const traced = (fn) =>
  new Proxy(fn, {
    apply(target, thisArg, args) {
      const start = performance.now()
      const result = Reflect.apply(target, thisArg, args)
      console.log(`${target.name} 花了 ${performance.now() - start}ms`)
      return result
    },
  })
const slowSum = traced((a, b) => a + b)
```

用途：計時、記錄、快取結果、在呼叫前檢查參數、自動 `bind`。

### 6-4-3 construct：攔截 new {#6-4-3}

```js
const Singleton = (Cls) => {
  let instance
  return new Proxy(Cls, {
    construct(target, args, newTarget) {
      return (instance ??= Reflect.construct(target, args, newTarget))
    },
  })
}
const Config = Singleton(class {})
new Config() === new Config() // true
```

`construct` 必須回傳物件。也可以用來強制建構參數的格式，或回傳另一個類別的實例。

### 6-4-4 getPrototypeOf {#6-4-4}

攔截 `Object.getPrototypeOf`、`__proto__`、`instanceof`、`isPrototypeOf`。例如讓代理在 `instanceof` 檢查時偽裝成別的類別（測試替身會用到）。

### 6-4-5 setPrototypeOf {#6-4-5}

攔截 `Object.setPrototypeOf`。最常見的用法是禁止修改原型，避免原型污染：

```js
handler.setPrototypeOf = () => false // 回傳 false：Object.setPrototypeOf 會丟 TypeError
```

### 6-4-6 preventExtensions {#6-4-6}

攔截 `Object.preventExtensions`（以及 `Object.seal`、`Object.freeze`）。可以拒絕讓物件被凍結：回傳 `false` 時呼叫端會收到 `TypeError`。

### 6-4-7 isExtensible {#6-4-7}

攔截 `Object.isExtensible`。受不變條件限制：回傳值必須和目標物件實際的狀態一致，否則丟 `TypeError`，所以只能用來記錄或在回報前做額外的事，不能說謊。

### 全部 13 個機關 {#6-4-8}

| 機關 | 攔截 |
| --- | --- |
| `get`、`set` | 讀、寫屬性 |
| `has` | `in` |
| `deleteProperty` | `delete` |
| `defineProperty` | `Object.defineProperty` |
| `getOwnPropertyDescriptor` | `Object.getOwnPropertyDescriptor`、`hasOwn` |
| `ownKeys` | `Object.keys`、`for...in`、展開 |
| `apply` | 函式呼叫 |
| `construct` | `new` |
| `getPrototypeOf`、`setPrototypeOf` | 讀取、設定原型 |
| `preventExtensions`、`isExtensible` | 禁止擴充、查詢能否擴充 |
