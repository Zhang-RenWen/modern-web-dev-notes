# 7-4 正規表示式

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017），當時命名群組、後行斷言、`/s`、`matchAll` 都還是提案，現在全部是標準（ES2018～ES2020）。已精簡，並補上 ES2024 的 `/v` 旗標與 ES2025 的 `RegExp.escape`。日常會用到的寫法見 [1-3-9 通用正則表達式](./1-3-9.md)。
:::

### 7-4-1 黏著模式 /y {#7-4-1}

`/y` 只在 `lastIndex` 那個位置嘗試比對，不會往後找；`/g` 則會往後找到下一個符合的地方。

```js
const sticky = /ha/y
sticky.lastIndex = 0
sticky.test('haha hah') // true，lastIndex 變 2
sticky.test('haha hah') // true，lastIndex 變 4
sticky.test('haha hah') // false：位置 4 是空白，不會跳到後面的 ha
```

用途：寫詞法分析器（tokenizer），保證每個 token 緊接著上一個，不會跳過中間無法辨識的內容。

### 7-4-2 Unicode 模式 /u {#7-4-2}

- 正確處理超過 U+FFFF 的字元：`/^.$/u.test('🐎')` 是 `true`（沒有 `u` 時 `.` 只吃半個代理對）。
- 支援 `\u{1F40E}` 寫法。
- 更嚴格：不必要的跳脫（`/\a/u`）是語法錯誤，能提早發現打錯字。

處理使用者輸入、多語系文字時一律加 `u`。ES2024 的 **`/v`** 是更新版：支援字元集合的交集與差集（`/[\p{L}--[a-z]]/v`）、多碼位的字串（例如複合 emoji）。

### 7-4-3 命名群組 {#7-4-3}

```js
const { groups } = /(?<key>\w+)=(?<value>\w+)/.exec('strong=true')
groups.key   // 'strong'
groups.value // 'true'

'2026-11-14'.replace(/(?<y>\d+)-(?<m>\d+)-(?<d>\d+)/, '$<d>/$<m>/$<y>') // '14/11/2026'
/(?<q>['"]).*?\k<q>/ // \k<name>：反向參考同名群組（引號前後要一致）
```

比 `match[1]`、`match[2]` 好讀，群組順序改了也不會壞。ES2025 起不同分支可以用同名群組：`/(?<year>\d{4})-\d\d|\d\d\/(?<year>\d{4})/`。

### 7-4-4 Unicode 屬性 {#7-4-4}

加 `u` 旗標後，可以用 `\p{…}` 依 Unicode 屬性比對：

```js
/\p{Script=Han}/u.test('漢')              // 中日韓漢字
/^\p{Lu}/u.test('Élan')                   // 大寫字母（含非英文）
/\p{Emoji_Presentation}/u.test('🐎')      // emoji
/[\p{L}\p{N}]+/u                          // 任何語言的字母與數字，比 \w 更完整
```

`\P{…}`（大寫 P）是反向。

### 7-4-5 後行斷言 {#7-4-5}

只在前面（或後面）是某個模式時比對，但斷言的部分不會被包含在結果裡：

| 寫法 | 名稱 | 例子 |
| --- | --- | --- |
| `(?=…)` | 先行斷言 | `/\d+(?=元)/` 比對後面接「元」的數字 |
| `(?!…)` | 否定先行斷言 | `/\d+(?!元)/` |
| `(?<=…)` | 後行斷言（ES2018） | `/(?<=\$)\d+/` 比對前面是 `$` 的數字 |
| `(?<!…)` | 否定後行斷言 | `/(?<!\$)\d+/` |

```js
'$10 20元'.match(/(?<=\$)\d+/)[0] // '10'
```

Safari 在 16.4（2023）才支援後行斷言，要支援更舊的 iOS 時要注意。

### 7-4-6 dotAll 模式 /s {#7-4-6}

`.` 預設不比對換行字元，加 `/s` 之後連換行也比對：

```js
/a.b/.test('a\nb')  // false
/a.b/s.test('a\nb') // true
```

以前的寫法是 `[\s\S]` 或 `[^]`。

### 7-4-7 String#matchAll {#7-4-7}

一次取得所有比對結果，每一個都有群組與位置（ES2020）：

```js
const text = 'a=1, b=2'
for (const m of text.matchAll(/(?<k>\w)=(?<v>\d)/g)) {
  console.log(m.groups.k, m.groups.v, m.index)
}
```

- 正規表達式一定要有 `g` 旗標，否則丟 `TypeError`。
- 以前要用 `while ((m = re.exec(text)))` 迴圈，還要小心 `lastIndex` 狀態。

**把使用者輸入放進正規表達式**：ES2025 的 `RegExp.escape(str)` 會跳脫所有特殊字元，取代自己寫 `str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`。
