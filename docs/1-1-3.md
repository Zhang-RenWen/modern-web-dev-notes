# 1-1-3 實現置中 {#1-1-3}

首先看以下範例

```html
<div>
  <div class="wp">
    <div class="box fixed-size">text</div>
  </div>
</div>
```

```css
.wp {
  border: 1px solid red;
  width: 300px;
  height: 300px;
}
.box {
  background: green;
}
.box.fixed-size {
  width: 100px;
  height: 100px;
}
```

<div class="demo-block" v-pre><div><div class="wp"><div class="box fixed-size">text</div></div></div></div>

按照子元素是否固定長寬分成2種情境：置中元素固定長寬、置中元素不固定長寬。兩者對應不同的置中辦法如下：

### 置中元素固定長寬

在置中元素定長寬的情況下，有以下3種實現置中顯示的方法。

#### 1\. absolute + 負 margin

```html
<div>
  <div class="wp wp-type1">
    <div class="box fixed-size box-type1">text</div>
  </div>
</div>
```

```css
.wp-type1 {
  position: relative;
}
.box-type1 {
  position: absolute;
  top: 50%;
  left: 50%;
  margin-left: -50px;
  margin-top: -50px;
}
```

<div class="demo-block" v-pre><div><div class="wp wp-type1"><div class="box fixed-size box-type1">text</div></div></div></div>

#### 2\. absolute + margin auto

```html
<div>
  <div class="wp wp-type2">
    <div class="box fixed-size box-type2">text</div>
  </div>
</div>
```

```css
.wp-type2 {
  position: relative;
}
.box-type2 {
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
}
```

<div class="demo-block" v-pre><div><div class="wp wp-type2"><div class="box fixed-size box-type2">text</div></div></div></div>

#### 3\. absolute + calc

```html
<div>
  <div class="wp wp-type3">
    <div class="box fixed-size box-type3">text</div>
  </div>
</div>
```

```css
.wp-type3 {
  position: relative;
}
.box-type3 {
  position: absolute;
  top: calc(50% - 50px);
  left: calc(50% - 50px);
}
```

<div class="demo-block" v-pre><div><div class="wp wp-type3"><div class="box fixed-size box-type3">text</div></div></div></div>

### 置中元素不固定長寬

先來一個基本素材：

```html
<div>
  <div class="wp-type4">
    <div class="box-type4">text</div>
  </div>
</div>
```

```css
.wp-type4 {
  border: 1px solid red;
  width: 300px;
  height: 300px;
}
.box-type4 {
  background: green;
}
```

<div class="demo-block" v-pre><div><div class="wp-type4"><div class="box-type4">text</div></div></div></div>

對於置中元素不定長寬的情況，依然有很多方法可以實現置中。

#### 1\. absolute + transform

長寬不定時，可以利用 CSS3 新增的 transform,transform 的 translate 屬性也可以用來設定百分比，這個百分比是以本身的寬和高為基礎計算出來的，因此可以將 translate 設定為-50%，程式如下。

```html
<div>
  <div class="wp wp-type5">
    <div class="box box-type5">text</div>
  </div>
</div>
```

```css
.wp-type5 {
  position: relative;
}
.box-type5 {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

<div class="demo-block" v-pre><div><div class="wp wp-type5"><div class="box box-type5">text</div></div></div></div>

#### 2\. lineheight

把box設定為行內元素，可以透過 text-align 實現水平置中，同時透過 vertical-align實現垂直方向上的置中，程式如下。

```html
<div class="wp wp-type6">
  <div class="box box-type6">text</div>
</div>
```

```css
.wp-type6 {
  line-height: 300px;
  text-align: center;
  font-size: 0px;
}
.box-type6 {
  font-size: 16px;
  display: inline-block;
  vertical-align: middle;
  line-height: initial;
  text-align: left; /*修正文字*/
}
```

<div class="demo-block" v-pre><div class="wp wp-type6"><div class="box box-type6">text</div></div></div>

#### 3\. Table

這個方法充分利用了行內/區塊級元素的特點。 其寶，歷史上的 table 經常被用來做頁面設定，這麼做的缺點是會增加很多见餘碼，並且效能也不人性化。不過處理置中問題，它可是能手。把版面配置 當作一個表格來做的程式如下。

```html
<table>
  <tbody>
    <tr>
      <td class="wp">
        <div class="box">text</div>
      </td>
    </tr>
  </tbody>
</table>
```

```css
.wp-type7 {
  text-align: center;
}
.box-type7 {
  display: inline-block;
}
```

<div class="demo-block" v-pre><table><tbody><tr><td class="wp wp-type7"><div class="box box-type7">text</div></td></tr></tbody></table></div>

#### 4\. css-table

如何使用 table 版面配置的特性效果，但是不採用 table 元素呢？答案是使css-table，程式如下。

```html
<div class="wp wp-type8">
  <div class="box box-type8">text</div>
</div>
```

```css
.wp-type8 {
  display: table-cell;
  text-align: center;
  vertical-align: middle;
}
.box-type8 {
  display: inline-block;
}
```

<div class="demo-block" v-pre><div class="wp wp-type8"><div class="box box-type8">text</div></div></div>

#### 5\. flex (首選)

flex 是非常現代的版面配置方案，可以透過幾行程式優雅地實現置中，程式如下

```html
<div class="wp wp-type9">
  <div class="box">text</div>
</div>
```

```css
.wp-type9 {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

<div class="demo-block" v-pre><div class="wp wp-type9"><div class="box">text</div></div></div>

#### 6\. grid

grid 版面配置非常超前，雖然相容性不好，但是能力超強。使用它實現置中的程式如下。

```html
<div class="wp wp-type10">
  <div class="box box-type10">text</div>
</div>
```

```css
.wp-type10 {
  display: grid;
}
.box-type10 {
  align-self: center;
  justify-self: center;
}
```

<div class="demo-block" v-pre><div class="wp wp-type10"><div class="box box-type10">text</div></div></div>

在學習了以上幾種版面配置方法後，我們來簡單歸納一下。

- PC端有相容性要求，長寬固定，推薦使用「absolute +負 margin」的方法實現置中。
- PC端有相容性要求，長寬不固定，推薦使用 css-table 寶現置中。
- PC端無相容性要求，推薦使用 flex 實現置中。
- 行動端推薦使用 flex 實現置中。
