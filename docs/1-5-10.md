# 1-5-10 window 物件 {#1-5-10}

::: info 改寫（2026-11）
修正兩個範例：開子視窗的「有些網站關不掉」其實是 COOP 造成的，清理時機改用 `pagehide`；複製事件原本讀的是剪貼簿的舊內容，改成用 `clipboardData` 改寫。
:::

在瀏覽器裡，`window` 是全域物件；ES2020 起也可以用 [`globalThis`](./14-6.md)，在瀏覽器、Node、Worker 都指向各自的全域物件。

## 開子視窗，主視窗關閉時一起關 {#1-5-10-1}

```js
const children = []

function openChild(url) {
  const win = window.open(url, '_blank')
  if (win) children.push(win) // 被彈窗攔截或用了 noopener 時會是 null
}

// pagehide 比 beforeunload 可靠：手機切走、頁面進 bfcache 時也會觸發
window.addEventListener('pagehide', () => {
  for (const win of children) if (!win.closed) win.close()
})
```

- `window.open` 打開的視窗，原則上都能用 `close()` 關掉。
- **但有些網站關不掉**（例如 Google）：對方回應了 `Cross-Origin-Opener-Policy` 標頭，瀏覽器會切斷兩個視窗的關係，你手上的參考會變成 `closed === true`，`close()` 沒有作用。這是防止跨站視窗互相操控的安全機制，無法繞過。
- 用 `noopener` 開的視窗也拿不到參考。

## 改寫或禁止複製內容 {#1-5-10-2}

例如使用者從表格複製時，想把多餘的 Tab 和空白去掉：

```js
document.addEventListener('copy', (e) => {
  const text = window.getSelection().toString().replace(/\t/g, '').trim()
  e.clipboardData.setData('text/plain', text) // 改寫要寫進剪貼簿的內容
  e.preventDefault() // 不加這行，瀏覽器會用原本的選取內容覆蓋
})
```

- 在 `copy` 事件裡改 `e.clipboardData` 不需要任何權限。
- 不要在 `copy` 事件裡用 `navigator.clipboard.readText()`：讀到的是**複製之前**的舊內容，而且會跳出權限詢問。
- 只呼叫 `e.preventDefault()`、不 `setData`，就是禁止複製。但使用者還是能用開發者工具或截圖取得內容，不能當作保護機制。

瀏覽器 API 能做到哪些事、有哪些限制，見 [1-5-11 JavaScript 的能力邊界](./1-5-11.md)。
