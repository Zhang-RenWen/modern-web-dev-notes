### 2-3-1 物件解構 {#2-3-1}

```js
const character = {
  name: 'Bruce',
  pseudonym: 'Batman',
  metadata: { age: 34, gender: 'male' },
}

const { pseudonym, name } = character      // 'Batman'、'Bruce'
const { pseudonym: alias } = character     // 改名：alias = 'Batman'
const { metadata: { gender } } = character // 巢狀：gender = 'male'（metadata 本身不會建立變數）
const { boots = { size: 10 } } = character // 預設值：屬性是 undefined 時才使用
const { name: n, ...others } = character   // 其餘屬性（ES2018）
```

- 不存在的屬性解構出來是 `undefined`。
- **從 `null`／`undefined` 解構會報錯**：`const { a } = null`、`const { boots: { size } } = character`（boots 不存在）都會丟 `TypeError`。可以先給預設值 `{ boots: { size } = {} }`，或改用 `character.boots?.size`。

### 2-3-2 陣列解構 {#2-3-2}

```js
const [x, y] = [12, -7]
const [first, , last] = ['James', 'L.', 'Htt']     // 用空位跳過不要的元素
const [a = 'John', , c = 'Doe'] = ['James', 'L.']  // a = 'James'（有值就不用預設），c = 'Doe'
const [head, ...tail] = [1, 2, 3]                  // tail = [2, 3]

let left = 5
let right = 7;
[left, right] = [right, left] // 交換。前一行沒有分號時，這行的 [ 會被接到上一行
```

陣列解構其實是走**迭代器**，所以字串、`Map`、`Set`、generator 都能解構：`const [k, v] = map.entries().next().value`。

### 2-3-3 函式參數預設值 {#2-3-3}

```js
function powerOf(base, exponent = 2) {
  return base ** exponent
}
function sumOf(a = 1, b = 2, c = 3) {
  return a + b + c
}
sumOf(undefined, undefined, 4) // 7：傳 undefined 會用預設值，傳 null 不會
```

預設值在**每次呼叫時**才計算，可以引用前面的參數：`function f(a, b = a * 2) {}`。

### 2-3-4 解構參數 {#2-3-4}

用一個物件傳選項，比一長串位置參數清楚，也不怕順序搞錯：

```js
function carFactory({ brand = 'Volkswagen', make = 1999 } = {}) {
  console.log(brand, make)
}
carFactory({ make: 2000 }) // Volkswagen 2000
carFactory()               // Volkswagen 1999：後面的 = {} 讓不傳參數時也不會報錯
```

如果寫成 `function carFactory(options = { brand: 'Volkswagen', make: 1999 })`，只要傳了物件，整個預設物件就不會被使用，`carFactory({ make: 2000 })` 的 `brand` 會是 `undefined`。

只用到物件的一部分時，直接在參數解構：

```js
const getSku = ({ brand, make, model }) => `${brand}:${make}:${model}`
```

### 2-3-5 使用情境 {#2-3-5}

**直接取出回傳物件的欄位**，不用中間變數：

```js
const { x, y } = getCoordinates()
const { data, error } = await supabase.from('items').select()
```

**選項參數加預設值**：

```js
function random({ min = 1, max = 10 } = {}) {
  return Math.floor(Math.random() * (max - min)) + min
}
random()            // 1～9
random({ max: 24 }) // 1～23
```

**正規表達式的分組結果**：

```js
const match = /(\d{4})\D?(\d{2})\D?(\d{2})/.exec('2015-11-06')
if (match) {
  const [, year, month, day] = match // 第一個元素是整段比對結果，跳過
}
// 也可以用具名群組：/(?<year>\d{4})-(?<month>\d{2})/ → const { year, month } = match.groups
```

比對失敗時 `exec` 回傳 `null`，直接解構會報錯，要先判斷。
