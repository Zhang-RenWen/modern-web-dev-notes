# 7-5 陣列

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡，並補上 ES2016 之後陸續加入的常用方法（`includes`、`flat`、`at`、`findLast`、不改原陣列的 `toSorted` 等）。
:::

### 7-5-1 Array.from {#7-5-1}

把**可迭代物件**或**類陣列物件**（有 `length` 和數字索引）轉成真正的陣列，可以順便做 map：

```js
Array.from(document.querySelectorAll('div'))     // NodeList → 陣列
Array.from({ length: 3 }, (_, i) => i * 2)       // [0, 2, 4]：產生序列
Array.from(new Set([1, 1, 2]))                   // [1, 2]
Array.from('🐎👱')                                // ['🐎', '👱']：依碼位切
```

和展開 `[...x]` 的差別：展開只吃可迭代物件，`Array.from` 連沒有實作迭代器的類陣列物件也能轉。只要一部分時再接 `.slice(1)`。

ES2024 的 `Array.fromAsync` 可以收集非同步可迭代物件。

### 7-5-2 Array.of {#7-5-2}

`Array` 建構函式只傳一個數字時，會被當成長度：

```js
new Array(3)    // [ <3 empty items> ]
new Array(3, 4) // [3, 4]
Array.of(3)     // [3]：一律把參數當成元素
```

平常直接寫陣列字面值 `[3]` 就好；`Array.of` 主要給「拿到一個建構函式、要用參數建立實例」的通用程式用。

### 7-5-3 Array#copyWithin {#7-5-3}

在同一個陣列內，把某段元素複製到另一個位置（會改原陣列）：

```js
[1, 2, 3, 4, 5].copyWithin(0, 3)    // [4, 5, 3, 4, 5]：把索引 3 開始的元素複製到索引 0
```

主要給 TypedArray 操作二進位資料用，一般程式很少用到。

### 7-5-4 Array#fill {#7-5-4}

```js
new Array(3).fill(0)               // [0, 0, 0]
[1, 2, 3, 4].fill(9, 1, 3)         // [1, 9, 9, 4]：從索引 1 填到 3（不含）
new Array(3).fill([])              // 陷阱：三個元素都是同一個陣列參考
Array.from({ length: 3 }, () => []) // 正確：每個元素各自一個新陣列
```

### 7-5-5 find 與 findIndex {#7-5-5}

```js
const users = [{ id: 1 }, { id: 2 }]
users.find((u) => u.id === 2)      // { id: 2 }，找不到是 undefined
users.findIndex((u) => u.id === 2) // 1，找不到是 -1
users.findLast((u) => u.id > 0)    // 從尾端找（ES2023）
```

只是要知道「有沒有」：`includes`（ES2016，能找到 `NaN`）或 `some`。

### 7-5-6 Array#keys {#7-5-6}

回傳索引的迭代器：`[...['a', 'b'].keys()]` 是 `[0, 1]`。稀疏陣列的空位也會列出。

### 7-5-7 Array#values {#7-5-7}

回傳元素的迭代器，和 `arr[Symbol.iterator]` 是同一個函式。

### 7-5-8 Array#entries {#7-5-8}

回傳 `[索引, 元素]` 的迭代器，需要索引的 `for...of` 這樣寫：

```js
for (const [i, item] of items.entries()) console.log(i, item)
```

### 7-5-9 Array.prototype[Symbol.iterator] {#7-5-9}

陣列可以用在 `for...of`、展開、解構，就是因為有這個方法（見 [4-2](./4-2.md)）。

### 後來加入的常用方法 {#7-5-10}

| 方法 | 版本 | 說明 |
| --- | --- | --- |
| `includes(x)` | ES2016 | 是否包含 |
| `flat(depth)`、`flatMap(fn)` | ES2019 | 攤平巢狀陣列；map 後攤平一層 |
| `at(-1)` | ES2022 | 支援負數索引，取最後一個 |
| `findLast`、`findLastIndex` | ES2023 | 從尾端找 |
| `toSorted`、`toReversed`、`toSpliced`、`with(i, x)` | ES2023 | **不改原陣列**的版本，React 狀態更新特別好用 |
| `Object.groupBy(arr, fn)` | ES2024 | 分組（見 [3-3](./3-3.md#3-3-4)） |
