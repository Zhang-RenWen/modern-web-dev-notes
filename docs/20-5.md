# 20-5 Iterator.concat() {#20-5}

把多個可迭代物件依序串接成一個迭代器。和 [19-1 Iterator helpers](./19-1.md) 一樣是**惰性求值**，不會先把所有內容複製到新陣列。

```js
const it = Iterator.concat([1, 2], new Set([3, 4]), [5])

console.log([...it]) // [1, 2, 3, 4, 5]
```

以前要串接不同型別的可迭代物件，通常得先展開成陣列 `[...a, ...b]`，或自己寫產生器：

```js
// 以前的寫法
function* concat(...iterables) {
  for (const iterable of iterables) yield* iterable
}
```

### 搭配 Iterator helpers

```js
function* range(start, end) {
  for (let i = start; i < end; i++) yield i
}

Iterator.concat(range(0, 3), range(10, 13))
  .map((n) => n * 2)
  .toArray() // [0, 2, 4, 20, 22, 24]
```

### 合併多個 Map

```js
const defaults = new Map([['theme', 'light'], ['lang', 'en']])
const userSettings = new Map([['lang', 'zh-TW']])

const settings = new Map(Iterator.concat(defaults, userSettings))
// Map { 'theme' => 'light', 'lang' => 'zh-TW' }，後面的值會覆蓋前面的
```

參數必須是可迭代的**物件**，傳入字串會拋出 `TypeError`。
