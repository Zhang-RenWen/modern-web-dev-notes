# 2-2 箭頭函式

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。修正原筆記的錯誤：箭頭函式**有**自己的作用域，也**會**形成閉包；它沒有的是自己的 `this`、`arguments`、`super`、`new.target`。
:::

### 2-2-1 沒有自己的 this 與 arguments {#2-2-1}

箭頭函式裡的 `this`、`arguments` 取自**定義時**的外層函式，之後怎麼呼叫都改不了（`call`、`bind` 也一樣）。

```js
function outer() {
  return () => console.log(arguments) // 外層 outer 的 arguments
}
outer('a', 'b')(1, 2) // ['a', 'b']

const obj = {
  normal() { console.log(this) },     // 誰呼叫就是誰
  arrow: () => console.log(this),     // 外層（模組或全域）的 this
}
obj.normal() // obj
obj.arrow()  // undefined（ES module）或 window（一般腳本）
```

所以**物件的方法、需要 `this` 的事件處理函式不要用箭頭函式**；callback 裡要沿用外層 `this` 時才用（例如 class 方法裡的 `setTimeout(() => this.tick())`）。完整規則見 [1-3-1 this](./1-3-1.md)。

需要不定數量的參數時，箭頭函式用其餘參數 `(...args) => {}`，它根本沒有 `arguments`。

### 2-2-2 簡寫 {#2-2-2}

```js
const add = (a, b) => a + b       // 單一運算式：省略 {} 和 return
const square = (n) => n * n       // 單一參數可以省略括號，但建議都加（格式化工具預設會加）
const toObj = (id) => ({ id })    // 回傳物件要包一層 ()，否則 {} 會被當成函式本體
```

### 2-2-3 不能當建構函式 {#2-2-3}

```js
const Arrow = () => {}
Arrow.prototype // undefined
new Arrow()     // TypeError: Arrow is not a constructor
```

箭頭函式也沒有 `super`、`new.target`，不能當 generator（不能用 `yield`）。

箭頭函式和其他函式寫法怎麼選，見 [9-5](./9-5.md)。
