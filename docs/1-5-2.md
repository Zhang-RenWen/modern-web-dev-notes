# 1-5-2 導航與網路：從輸入 URL 到收到回應 {#1-5-2}

::: info 新增（2026-11）
整理自 Notion「2026 全新瀏覽器原理」02。伺服器端那段（CDN、WAF、Load Balancer、TCP／TLS 細節）不在本站範圍。

## 導航流程 {#1-5-2-1}

```txt
使用者輸入 → Browser 判斷是搜尋還是 URL
          → （可選）Service Worker 攔截
          → Network：DNS 解析 → 連線（TCP + TLS 或 QUIC）→ 送出 HTTP 請求
          → 收到回應標頭：判斷 Content-Type、重新導向、安全標頭
          → 選擇／建立對應站點的 Renderer 進程
          → Commit Navigation：把回應串流交給 Renderer
          → Renderer 邊收邊解析、邊渲染（Streaming），見渲染管線
          → 觸發 DOMContentLoaded → load
```

面試「從輸入網址到畫面出現發生了什麼」的標準答法：DNS → TCP + TLS（或 QUIC）→ HTTP 請求／回應（可能命中快取）→ 選進程、commit → 渲染管線七個階段。

## 網路層重點 {#1-5-2-2}

- **DNS**：OS 快取 → 瀏覽器快取 → 遞迴解析器；可選 DoH（DNS over HTTPS）避免被中間人看見查詢。
- **連線**：HTTP/1.1、HTTP/2 跑在 TCP + TLS 上；**HTTP/3 跑在 QUIC（UDP）上**，把 TLS 1.3 握手整合進傳輸層，0-RTT／1-RTT 建連，而且單一串流掉包不會卡住其他串流（解決 TCP 的 head-of-line blocking）。
- **預先動作**：`dns-prefetch`、`preconnect`、`preload`、Speculation Rules（預取／預渲染下一頁），都是在使用者還沒點之前先做事。
- **快取層級**：記憶體快取 → HTTP 磁碟快取（看 `Cache-Control`、`ETag`）→ Service Worker 的 Cache Storage → 網路。強快取與協商快取的細節見快取政策一頁。

## 回應之後的決策 {#1-5-2-3}

- 看 `Content-Type` 決定是 HTML、下載、還是交給 PDF 檢視器。
- 讀安全相關標頭：`Content-Security-Policy`、`Cross-Origin-Opener-Policy`、`Strict-Transport-Security` 等，影響後續的進程分配與執行權限（見安全模型與儲存）。
- **bfcache（往返快取）**：按上一頁時直接把整個凍結的頁面狀態還原，幾乎瞬間顯示。頁面用了 `unload` 事件或某些 API 會無法進入 bfcache，改用 `pagehide`。

## 頁面載入事件 {#1-5-2-4}

| 事件 | 觸發時機 |
| --- | --- |
| `DOMContentLoaded` | HTML 解析完成、`defer` 腳本執行完；不等圖片、iframe |
| `load` | 所有資源（圖片、樣式表、iframe）都載完 |
| First Contentful Paint（FCP） | 第一次畫出文字或圖片（效能指標，不是 DOM 事件） |
| `pagehide`／`pageshow` | 離開／回到頁面（含從 bfcache 還原），取代 `unload` |

## 名詞剖析 {#1-5-2-5}

| 名詞 | 意思 |
| --- | --- |
| DoH | DNS over HTTPS：用加密的 HTTPS 傳 DNS 查詢 |
| QUIC | Google 提出、後來標準化的 UDP 傳輸協定，內建加密與多工 |
| 0-RTT／1-RTT | 建立加密連線需要的來回次數；0-RTT 是重連時不用等握手就能送資料 |
| Head-of-line blocking | 前面一個封包掉了，後面全部得等它重傳 |
| preconnect／preload | 先建好連線／先下載一個確定會用到的資源 |
| Speculation Rules | 用 JSON 宣告哪些連結可以預取或在背景預先渲染 |
| ETag | 資源版本指紋，瀏覽器帶著它問「有沒有更新」，沒有就回 304 |
| Commit Navigation | Browser 進程確定導航、把回應交給 Renderer 的那一刻 |
| bfcache | Back/forward cache，把整頁凍結在記憶體裡，按上一頁時直接還原 |
