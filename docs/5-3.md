# Chapter 5 運用 ECMAScript 集合

## 5-3 ES6 的集合

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡，補上 ES2025 的集合運算方法（`union`、`intersection`…），以前要自己用 `filter` 寫。
:::

`Set` 是**不重複的值**的集合，用法和 `Map` 類似，但只有值、沒有鍵。

```js
const set = new Set(['a', 'b', 'b', 'c']) // 重複的會被忽略
set.size        // 3
set.add('d')    // 回傳 set 本身，可以串接
set.has('a')    // true：查詢比陣列的 includes 快（平均 O(1)）
set.delete('a')
set.clear()

[...new Set(arr)] // 陣列去重最簡單的寫法
```

- 判斷是否重複用的是 SameValueZero：`NaN` 等於 `NaN`；物件比較參考。
- 保持插入順序，可以走訪：`for (const v of set)`、`[...set]`、`set.forEach(…)`。
- 沒有 `get`（已經有值了，不需要用值去查值）；`entries()` 會回傳 `[value, value]`，只是為了和 `Map` 的介面一致。

**集合運算（ES2025，2024 年起各大瀏覽器支援）**：

```js
const a = new Set([1, 2, 3])
const b = new Set([2, 3, 4])
a.union(b)               // {1, 2, 3, 4}
a.intersection(b)        // {2, 3}
a.difference(b)          // {1}
a.symmetricDifference(b) // {1, 4}
a.isSubsetOf(b)          // false
a.isDisjointFrom(new Set([9])) // true
```

常見用途：去重、記錄「已處理過的」項目（避免重複處理）、標籤或權限的比對。
