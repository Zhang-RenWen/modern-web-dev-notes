# 4-2 迭代器協議和可迭代協議

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡，自己寫的 `take`、`range` 補上 ES2025 內建的迭代器輔助方法（`Iterator.prototype.take`、`filter`、`map`…），播放清單範例濃縮成重點。
:::

### 4-2-1 兩個協議 {#4-2-1}

| 協議 | 規定 |
| --- | --- |
| **可迭代**（iterable） | 物件有 `[Symbol.iterator]()` 方法，回傳一個迭代器 |
| **迭代器**（iterator） | 物件有 `next()` 方法，每次回傳 `{ value, done }`；`done: true` 代表結束 |

只要符合可迭代協議，就能用在 `for...of`、展開 `[...x]`、解構、`Array.from`、`new Map(x)`、`Promise.all(x)`。陣列、字串、`Map`、`Set`、`NodeList`、`arguments` 都已經實作好了。

```js
const sequence = {
  items: ['a', 'b', 'c'],
  [Symbol.iterator]() {
    let i = 0
    return {
      next: () => (i < this.items.length ? { value: this.items[i++], done: false } : { value: undefined, done: true }),
    }
  },
}
for (const x of sequence) console.log(x) // a b c
[...sequence]                            // ['a', 'b', 'c']
```

用 generator 寫最省事（見 [4-3](./4-3.md)）：

```js
const sequence = {
  items: ['a', 'b', 'c'],
  *[Symbol.iterator]() { yield* this.items },
}
```

注意 `Array.from` 還能接受**類陣列**（有 `length` 和數字索引的物件），不一定要可迭代：`Array.from({ 0: 'a', length: 1 })`。

### 4-2-2 無限序列與延遲計算 {#4-2-2}

迭代器是**用到才計算**的，所以可以表示無限長的序列：

```js
const random = {
  [Symbol.iterator]: () => ({ next: () => ({ value: Math.random(), done: false }) }),
}
const [a, b] = random // 解構只取需要的數量：安全
// [...random]、Array.from(random) 永遠不會結束，程式會卡死
```

從無限序列取一部分，ES2025 起可以直接用迭代器輔助方法（Chrome 122、Firefox 131、Safari 18.4 起支援）：

```js
Iterator.from(random).filter((n) => n < 0.8).take(3).toArray()
```

以前要自己寫 generator：

```js
function* take(iterable, n) {
  for (const x of iterable) {
    if (n-- <= 0) return
    yield x
  }
}
[...take(random, 2)]
```

迭代器本身不知道序列是不是無限的，呼叫端要自己確保有結束條件。

### 4-2-3 讓一般物件可以迭代 {#4-2-3}

物件預設不可迭代（`for...of` 會報錯）。取鍵值對直接用 `Object.entries`：

```js
const colors = { green: '#0e0', orange: '#f50' }
for (const [name, hex] of Object.entries(colors)) console.log(name, hex)
```

需要「鍵值對、保持插入順序、鍵可以是任何型別」的結構，直接用 `Map`，它本身就可迭代（見 [5-1](./5-1.md)）。不要為了迭代去改物件本身的 `[Symbol.iterator]`，會把資料和走訪方式混在一起。

### 4-2-4 迭代器的實際用途 {#4-2-4}

自訂迭代器適合「走訪方式本身有邏輯」的情況，例如音樂播放器的播放清單：

```js
function* playlist(songs, { repeat = false, shuffle = false } = {}) {
  do {
    const order = shuffle ? [...songs].sort(() => Math.random() - 0.5) : songs
    yield* order
  } while (repeat) // 重複播放時無限循環，由呼叫端決定什麼時候停
}

const player = playlist(songs, { repeat: true })
player.next().value // 下一首
```

使用端只管「要下一首」，不必知道是不是隨機、要不要重複。（`sort` 加隨機比較函式洗牌並不均勻，正式用途改用 Fisher–Yates 演算法。）
