# 20-4 Uint8Array 與 Base64 / Hex 互轉 {#20-4}

`Uint8Array` 新增直接轉換 Base64 與十六進位字串的方法。

| 方法 | 說明 |
| --- | --- |
| `bytes.toBase64(options?)` | 轉成 Base64 字串 |
| `bytes.toHex()` | 轉成十六進位字串 |
| `Uint8Array.fromBase64(str, options?)` | 從 Base64 字串建立 |
| `Uint8Array.fromHex(str)` | 從十六進位字串建立 |
| `bytes.setFromBase64(str)` / `setFromHex(str)` | 寫入既有的 Uint8Array，回傳 `{ read, written }` |

```js
const bytes = new TextEncoder().encode('Hello')

bytes.toBase64() // 'SGVsbG8='
bytes.toHex() // '48656c6c6f'

Uint8Array.fromBase64('SGVsbG8=') // Uint8Array [72, 101, 108, 108, 111]
Uint8Array.fromHex('48656c6c6f') // Uint8Array [72, 101, 108, 108, 111]
```

### Base64URL 與省略補位

```js
bytes.toBase64({ alphabet: 'base64url', omitPadding: true }) // 'SGVsbG8'

Uint8Array.fromBase64('SGVsbG8', { alphabet: 'base64url' })
```

`base64url` 會用 `-`、`_` 取代 `+`、`/`，常用於 URL 與 JWT。

### 為什麼不用 btoa() / atob()

`btoa()` 只能處理每個字元都在 Latin-1 範圍內的「字串」，不能直接處理二進位資料，遇到中文還會拋出錯誤：

```js
btoa('你好') // InvalidCharacterError

// 以前要先轉成「二進位字串」才能編碼
const binary = String.fromCharCode(...new TextEncoder().encode('你好'))
btoa(binary) // '5L2g5aW9'

// ES2026
new TextEncoder().encode('你好').toBase64() // '5L2g5aW9'
```
