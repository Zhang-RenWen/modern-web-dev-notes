## JS 單執行緒的真相 {#1-2-8-1}

- Runtime（瀏覽器／Node）本身是多執行緒，只有 V8 跑在 main thread。非同步工作交給 Runtime API，完成後 callback 進 Microtask／Task Queue；Call Stack 清空時，Event Loop 先清 Microtask 再清 Task。

- 進階：[從 React 中學習 JavaScript 底層運作](https://github.com/aszx87410/blog/issues/153)（XSS 修補、Fiber 排程從 requestIdleCallback → MessageChannel → Scheduler API、V8 的 Smi／Heap number／shape）

## 面試四題（一句原理 ＋ 一個案例 ＋ 如何避免） {#1-2-8-2}

- **Memory Leak**：物件沒用但仍被引用，GC 無法回收。常見：listener 未移除、timer 未清、全域 cache 只增不減。→ 元件卸載時 cleanup；暫存資料用 WeakMap／WeakSet。
- **記憶體管理**：GC 看的是「是否仍可被存取」，不是有沒有設成 null。
- **Closure**：函式記住建立時的外層作用域。用途：私有狀態、debounce／throttle、hooks。釋放＝移除所有引用（設 null、removeEventListener、clearInterval），或提供 `dispose()` 清掉大型資料。
- **Async**：`log(1); setTimeout(2); Promise.then(3); log(4)` → 輸出 1 → 4 → 3 → 2。實務用 async/await + try/catch，彼此獨立的請求用 `Promise.all`。
- **進階追問「怎麼確認真的 leak」**：重複操作頁面，比對多次 Heap Snapshot，從 Retainers 找引用鏈（listener／timer／closure／cache／detached DOM）。重點是找出誰在引用、該引用的生命週期是否合理。排查 SOP 見 [1-6-12](./1-6-12.md)。
- 金融面試補一句實務：「Vue 元件卸載時會移除監聽、取消計時器」「debounce 用閉包保存 timer」。

## 常見語法陷阱 {#1-2-8-3}

- `?` 三種用法：三元運算、可選鏈 `a?.b`、空值合併 `??`（只有 null/undefined 才取預設，`0`、`''` 會保留；`||` 會誤判）。
- 不改原陣列：map／filter／slice／concat／toSorted／toSpliced／with；會改原陣列：push／pop／splice／sort／reverse。框架狀態更新用 `arr.slice(0, -1)`，不用 `pop()`。
- `const` 物件內容仍可改；`0.1 + 0.2 !== 0.3`，金額用整數分單位或 decimal library。
- Unicode：emoji 等補充平面字元 `length` 為 2；計字數／反轉用 `[...str]`，比對前 `normalize('NFC')`，regex 加 `u` flag。測試字串放一個 💩 看會不會壞。

## TypeScript 真正要深挖的 {#1-2-8-4}

- strict mode 一定開；`明確型別 > unknown > any`。
- union + narrowing、generics + constraint（`T extends { id: number }`）、template literal type（`/api/${string}`、CSS 單位）、discriminated union、`satisfies`、utility types。
- 斷言用 `as`，不要用 `<T>value`（與 JSX 衝突）；能 narrowing 就不要斷言。
- type vs interface：object shape 兩者皆可；union／tuple／mapped／conditional 用 type。

## React 現代主線 {#1-2-8-5}

- useEffect 只放副作用（訂閱、DOM、timer）並寫 cleanup；server state 交給 TanStack Query／SWR；Context 只放低頻全域設定（theme、auth、語系）；複雜表單用 React Hook Form + Zod；不要到處包 useMemo／useCallback。

## 學習方法 {#1-2-8-6}

- 不用把《JavaScript 大全》或 Node／React／TS 厚書從頭啃，當字典查。流程：高頻題清單 → 用自己的話回答 → 查 MDN／官方文件補洞。
- 資深要展現的是原理、邊界與 trade-off，不是背 API。
- 保留原則：核心心智模型 > 每天用的語法 > 實務 API > 工具速查 > 冷門技巧（jQuery AJAX、XHR、JSLint、IIFE 已降級）。
