# 9-2 字串樣板

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017），已精簡；原文對 Babel 轉譯效能的擔憂已不適用（現在的建置目標都原生支援樣板字串）。
:::

**需要插值或換行時用樣板字串；其他時候用一般字串也可以，團隊統一就好。**

```js
'Hello, ' + name + '!'  // 舊寫法：引號和加號一多就難讀
`Hello, ${name}!`       // 樣板字串
`Alfred's cat suit is "slick".` // 單雙引號都不用跳脫
```

有些人主張「全部用反引號」，好處是之後要加插值不用改引號；缺點是有幾個地方**不能用樣板字串**：

| 地方 | 原因 |
| --- | --- |
| JSON | JSON 只認雙引號：`JSON.parse('{"a":`x`}')` 會報錯 |
| `import ... from '路徑'` | 模組路徑必須是一般字串常數 |
| 物件的鍵 `{ 'a-b': 1 }` | 要用計算屬性 `` { [`a-b`]: 1 } `` 才行 |
| `'use strict'` 指令 | 必須是一般字串才會生效 |

實務上交給格式化工具決定：Prettier 預設統一用一種引號，沒有插值的樣板字串由 ESLint 的 `quotes` 規則（`allowTemplateLiterals`）決定要不要允許。

效能不是考量：現代引擎對樣板字串和字串串接的效能差異可以忽略。

組大量 HTML 時，插值的內容一定要跳脫，見 [2-5](./2-5.md#2-5-3)。
