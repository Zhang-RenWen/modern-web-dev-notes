## HTML5 是什麼 {#1-1-2-1}

W3C 在 2014 年把 HTML5 定為正式標準。2019 年起，W3C 和 WHATWG 協議只維護一份標準：**HTML Living Standard**，沒有版本號，持續更新。所以現在說「HTML5」，通常是泛指新一代的 HTML、CSS、JavaScript 技術。

HTML5 帶來的主要能力：

- 語意標籤：`header`、`nav`、`main`、`article`、`section`、`aside`、`footer`（見 [1-1-1](./1-1-1.md)）
- 多媒體：`<video>`、`<audio>`、`<canvas>`
- 表單：`type="email"`、`url`、`search`、`date`、`time`、`color`、`range`，以及 `required`、`pattern` 這類原生驗證
- 儲存與 API：`localStorage`、`sessionStorage`、History API、拖放、Geolocation

## 不用 JavaScript 的原生元件 {#1-1-2-2}

以前要寫 JS 或裝套件才做得到的效果，很多現在一個標籤就有，而且鍵盤操作和無障礙都內建。

| 需求 | 原生寫法 | 支援 |
| --- | --- | --- |
| 展開／收合 | `<details>` + `<summary>` | 全面；加同樣的 `name` 屬性就是「一次只開一個」的手風琴（2024） |
| 對話框 | `<dialog>` + `showModal()` | 2022 起全面；內建焦點鎖定、Esc 關閉、`::backdrop` |
| 浮層、下拉選單、提示 | `popover` 屬性 + `popovertarget` | 2024 起全面；點外面自動關閉，顯示在最上層 |
| 進度條、量表 | `<progress>`、`<meter>` | 全面 |
| 注音、拼音 | `<ruby>` + `<rt>` | 全面 |

```html
<details name="faq">
  <summary>運費怎麼算？</summary>
  滿 500 元免運。
</details>
<details name="faq">
  <summary>可以退貨嗎？</summary>
  7 天內可退。
</details>

<button popovertarget="menu">選單</button>
<div id="menu" popover>點外面會自動關閉</div>

<progress value="22" max="100"></progress>
<ruby>漢<rt>ㄏㄢˋ</rt></ruby>
```

<div class="demo-block" v-pre><details name="faq"><summary>運費怎麼算？</summary>滿 500 元免運。</details><details name="faq"><summary>可以退貨嗎？</summary>7 天內可退。</details><br><button popovertarget="demo-menu">選單</button><div id="demo-menu" popover>點外面會自動關閉</div><br><br><progress value="22" max="100"></progress>　<ruby>漢<rt>ㄏㄢˋ</rt></ruby></div>

`<details>` 展開時會自動加上 `open` 屬性，CSS 可以用 `details[open]` 改樣式。

<style>
.vp-doc .demo-block button[popovertarget] { padding: 2px 12px; border: 1px solid var(--vp-c-divider); border-radius: 4px; }
.vp-doc .demo-block [popover] { padding: 8px 12px; border: 1px solid var(--vp-c-divider); border-radius: 6px; }
</style>

## Web Components {#1-1-2-3}

瀏覽器原生的元件機制，由三個標準組成：Custom Elements（自訂標籤與生命週期）、Shadow DOM（樣式與 DOM 隔離）、`<template>`／`<slot>`（模板與插槽）。2024 年起連「伺服器端輸出 Shadow DOM」（Declarative Shadow DOM）也全面支援。

```js
class HelloCard extends HTMLElement {
  connectedCallback() {
    const root = this.attachShadow({ mode: 'open' })
    root.innerHTML = `<style>p { color: teal }</style><p>Hello, <slot></slot></p>`
  }
}
customElements.define('hello-card', HelloCard)
// <hello-card>Ren</hello-card>
```

| 適合 | 不適合 |
| --- | --- |
| 跨框架共用的設計系統（同一套按鈕給 React、Vue、純 HTML 用）、嵌入第三方網站的小工具 | 取代整個應用框架：狀態管理、資料綁定、SSR 還是框架比較成熟 |

## 行動版注意事項 {#1-1-2-4}

**撥號、簡訊、寄信連結**

```html
<a href="tel:+886212345678">撥打電話</a>
<a href="sms:+886912345678">傳簡訊</a>
<a href="mailto:a@example.com,b@example.com?cc=c@example.com&bcc=d@example.com&subject=%E8%A9%A2%E5%95%8F&body=%E4%BD%A0%E5%A5%BD">寄信</a>
```

- 多個收件人用逗號分隔；`subject`、`body` 的中文和空白要 URL 編碼（用 `encodeURIComponent`）。
- 電話號碼寫國際格式（`+886…`），在國外漫遊也撥得通。

**影片自動播放與行內播放**

```html
<video src="intro.mp4" autoplay muted playsinline loop></video>
```

- 瀏覽器只允許**靜音**的影片自動播放；有聲音的要等使用者點擊後才能 `play()`。
- iOS 沒加 `playsinline` 會自動跳全螢幕。舊寫法 `webkit-playsinline`、`x-webkit-airplay` 已經不需要。
- `video.play()` 回傳 Promise，被擋時會 reject，要 `catch` 起來顯示播放按鈕。

**觸控相關**

| 問題 | 做法 |
| --- | --- |
| 點擊時出現灰色底色 | `-webkit-tap-highlight-color: transparent` |
| 長按連結、圖片跳出系統選單（iOS） | `-webkit-touch-callout: none` |
| 不讓使用者選取文字 | `user-select: none`（Safari 仍需要 `-webkit-user-select`） |
| 輸入英文時自動大寫、自動修正 | `<input autocapitalize="off" autocorrect="off">`（`autocorrect` 主要是 Safari） |
| 雙擊縮放造成點擊延遲 | 加 `<meta name="viewport" content="width=device-width">` 就沒有 300ms 延遲；個別元素可以用 `touch-action: manipulation` |

**版面與效能**

- **鍵盤彈出時 `fixed` 元素跑位、`100vh` 被網址列吃掉**：改用 `100dvh`（隨網址列伸縮）或 `100svh`（最小可視高度）；需要精準位置時用 `visualViewport` API 監聽可視區域變化。
- **動畫卡頓**：只對 `transform`、`opacity` 做動畫，它們本來就在合成層處理。舊的 `translate3d(0,0,0)` 強制開圖層是 hack，要提示瀏覽器改用 `will-change: transform`，而且只加在真的會動的元素上，加太多反而吃記憶體。
- **小於 12px 的字**：Chrome 118（2023）起中日韓文不再預設限制最小字級，直接寫 `font-size: 10px` 即可。
