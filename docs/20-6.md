# 20-6 JSON.parse() 取得原始文字 {#20-6}

`JSON.parse()` 的 reviver 函式新增第三個參數 `context`，其中的 `context.source` 是該值在 JSON 中的**原始文字**。另外新增 `JSON.rawJSON()`，讓 `JSON.stringify()` 可以輸出原始文字。

最主要的用途是處理超過 `Number.MAX_SAFE_INTEGER` 的大數字。

### 問題：大數字在解析時就失去精度

```js
const json = '{"id": 12345678901234567890}'

JSON.parse(json).id // 12345678901234567000，最後幾位已經錯了
```

### 用 context.source 取得原始文字

```js
const data = JSON.parse(json, (key, value, context) =>
  key === 'id' ? BigInt(context.source) : value,
)

data.id // 12345678901234567890n
```

`context.source` 只會出現在數字、字串、布林值、`null` 等原始值上；物件和陣列沒有。

### 用 JSON.rawJSON() 輸出原始文字

`JSON.stringify()` 遇到 BigInt 會拋出 `TypeError`。用 `JSON.rawJSON()` 包起來，就能把數字原樣輸出：

```js
JSON.stringify({ id: 12345678901234567890n }) // TypeError: Do not know how to serialize a BigInt

JSON.stringify({ id: JSON.rawJSON('12345678901234567890') })
// '{"id":12345678901234567890}'

JSON.isRawJSON(JSON.rawJSON('1')) // true
```

`JSON.rawJSON()` 只接受原始值的 JSON 文字，傳入物件或陣列（例如 `'{}'`）會拋出 `SyntaxError`。
