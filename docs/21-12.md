### Q1. 實作 debounce <Badge type="tip" text="高頻" /> {#21-12-1}

::: details 解題思路
用閉包保存 timer；每次呼叫先清掉上一個 timer 再重設。注意保留 `this` 與參數，進階題會要 `immediate` 與 `cancel`。
:::

::: details 標準答案與過程
```js
function debounce(fn, wait = 300, { immediate = false } = {}) {
  let timer = null

  function debounced(...args) {
    const callNow = immediate && !timer
    clearTimeout(timer)
    timer = setTimeout(() => {
      timer = null
      if (!immediate) fn.apply(this, args)
    }, wait)
    if (callNow) fn.apply(this, args)
  }

  debounced.cancel = () => { clearTimeout(timer); timer = null }
  return debounced
}

// 使用
const onSearch = debounce((q) => console.log('search', q), 300)
input.addEventListener('input', (e) => onSearch(e.target.value))
```

延伸：元件卸載時要呼叫 `cancel()`，否則延遲的 callback 可能在卸載後執行。
:::

### Q2. 實作 throttle <Badge type="tip" text="高頻" /> {#21-12-2}

::: details 標準答案與過程
時間戳版（第一次立即執行）＋ 尾端補一次（確保最後一次觸發不會遺失）：

```js
function throttle(fn, wait = 200) {
  let last = 0
  let timer = null

  return function (...args) {
    const now = Date.now()
    const remaining = wait - (now - last)

    if (remaining <= 0) {
      clearTimeout(timer)
      timer = null
      last = now
      fn.apply(this, args)
    } else if (!timer) {
      timer = setTimeout(() => {
        last = Date.now()
        timer = null
        fn.apply(this, args)
      }, remaining)
    }
  }
}
```
:::

### Q3. 實作深拷貝（處理循環參考） <Badge type="tip" text="高頻" /> {#21-12-3}

::: details 解題思路
1. 原始型別直接回傳。
2. 用 WeakMap 記錄「原物件 → 拷貝」，遇到已拷貝過的直接回傳，解決循環參考。
3. 特殊型別（Date、RegExp、Map、Set）分開處理。
4. 保留原型，複製 Symbol key。
:::

::: details 標準答案與過程
```js
function deepClone(value, seen = new WeakMap()) {
  if (value === null || typeof value !== 'object') return value
  if (seen.has(value)) return seen.get(value)

  if (value instanceof Date) return new Date(value)
  if (value instanceof RegExp) return new RegExp(value.source, value.flags)

  if (value instanceof Map) {
    const result = new Map()
    seen.set(value, result)
    value.forEach((v, k) => result.set(deepClone(k, seen), deepClone(v, seen)))
    return result
  }

  if (value instanceof Set) {
    const result = new Set()
    seen.set(value, result)
    value.forEach(v => result.add(deepClone(v, seen)))
    return result
  }

  const result = Array.isArray(value) ? [] : Object.create(Object.getPrototypeOf(value))
  seen.set(value, result)
  for (const key of Reflect.ownKeys(value)) {   // 包含 Symbol key
    result[key] = deepClone(value[key], seen)
  }
  return result
}

const a = { name: 'x', date: new Date() }
a.self = a
const b = deepClone(a)
b.self === b // true
```

實務上直接用 `structuredClone`，手寫是為了展示對型別、遞迴與 WeakMap 的理解。
:::

### Q4. 實作 Promise.all <Badge type="tip" text="高頻" /> {#21-12-4}

::: details 解題思路
重點：結果順序要和輸入一致（不是完成順序）；任一 reject 就 reject；空陣列直接 resolve；輸入可能不是 Promise（用 `Promise.resolve` 包）。
:::

::: details 標準答案與過程
```js
function promiseAll(iterable) {
  return new Promise((resolve, reject) => {
    const items = Array.from(iterable)
    const results = new Array(items.length)
    let done = 0

    if (items.length === 0) return resolve(results)

    items.forEach((item, i) => {
      Promise.resolve(item).then(
        (value) => {
          results[i] = value          // 依索引放，保持順序
          if (++done === items.length) resolve(results)
        },
        reject,                        // 第一個失敗就 reject，之後的呼叫無效
      )
    })
  })
}

function promiseAllSettled(iterable) {
  return promiseAll(Array.from(iterable, (p) =>
    Promise.resolve(p).then(
      (value) => ({ status: 'fulfilled', value }),
      (reason) => ({ status: 'rejected', reason }),
    ),
  ))
}
```
:::

### Q5. 實作並發數量限制的請求池 <Badge type="tip" text="高頻" /> {#21-12-5}

**題目**：有 100 個上傳任務，同時最多執行 3 個，全部完成後回傳結果（順序與輸入一致）。

::: details 解題思路
開 `limit` 個 worker，每個 worker 不斷從共用索引取下一個任務執行，直到取完。比「每完成一個就補一個」的寫法更簡潔。
:::

::: details 標準答案與過程
```js
async function runWithLimit(tasks, limit = 3) {
  const results = new Array(tasks.length)
  let next = 0

  async function worker() {
    while (next < tasks.length) {
      const i = next++                 // 單執行緒，取號不會衝突
      try {
        results[i] = { status: 'fulfilled', value: await tasks[i]() }
      } catch (reason) {
        results[i] = { status: 'rejected', reason }
      }
    }
  }

  await Promise.all(Array.from({ length: Math.min(limit, tasks.length) }, worker))
  return results
}

// tasks 是「回傳 Promise 的函式」，不是 Promise 本身，否則一建立就全部開始執行
const tasks = files.map((f) => () => upload(f))
const results = await runWithLimit(tasks, 3)
```
:::

### Q6. 實作 call、apply、bind <Badge type="tip" text="高頻" /> {#21-12-6}

::: details 標準答案與過程
```js
Function.prototype.myCall = function (ctx, ...args) {
  ctx = ctx == null ? globalThis : Object(ctx)
  const key = Symbol('fn')               // 避免覆蓋原有屬性
  ctx[key] = this
  try {
    return ctx[key](...args)
  } finally {
    delete ctx[key]
  }
}

Function.prototype.myApply = function (ctx, args = []) {
  return this.myCall(ctx, ...args)
}

Function.prototype.myBind = function (ctx, ...preset) {
  const fn = this
  function bound(...args) {
    // 被 new 呼叫時，this 應該是新物件，忽略綁定的 ctx
    return this instanceof bound
      ? new fn(...preset, ...args)
      : fn.apply(ctx, [...preset, ...args])
  }
  bound.prototype = Object.create(fn.prototype)
  return bound
}
```
:::

### Q7. 實作 EventEmitter <Badge type="tip" text="高頻" /> {#21-12-7}

::: details 標準答案與過程
```js
class EventEmitter {
  #events = new Map()

  on(name, listener) {
    if (!this.#events.has(name)) this.#events.set(name, new Set())
    this.#events.get(name).add(listener)
    return () => this.off(name, listener)   // 回傳取消訂閱函式
  }

  once(name, listener) {
    const wrapper = (...args) => {
      this.off(name, wrapper)
      listener.apply(this, args)
    }
    return this.on(name, wrapper)
  }

  off(name, listener) {
    this.#events.get(name)?.delete(listener)
  }

  emit(name, ...args) {
    // 複製一份再執行，避免執行中有人 off 造成跳過
    ;[...(this.#events.get(name) ?? [])].forEach(fn => fn.apply(this, args))
  }
}
```

這就是發布／訂閱模式，也是 Vue 2 Event Bus、Node.js `EventEmitter` 的核心。
:::

### Q8. 實作 curry <Badge type="tip" text="基礎" /> {#21-12-8}

::: details 標準答案與過程
```js
function curry(fn) {
  return function curried(...args) {
    return args.length >= fn.length
      ? fn.apply(this, args)
      : (...rest) => curried.apply(this, [...args, ...rest])
  }
}

const add = (a, b, c) => a + b + c
const curriedAdd = curry(add)
curriedAdd(1)(2)(3) // 6
curriedAdd(1, 2)(3) // 6
```

限制：依賴 `fn.length`，有預設參數或其餘參數的函式 length 不準。

### Q9. 陣列扁平化 <Badge type="tip" text="基礎" /> {#21-12-9}

::: details 標準答案與過程
```js
// 原生
[1, [2, [3, [4]]]].flat(Infinity) // [1, 2, 3, 4]

// 遞迴（可指定深度）
function flatten(arr, depth = Infinity) {
  return depth > 0
    ? arr.reduce((acc, x) => acc.concat(Array.isArray(x) ? flatten(x, depth - 1) : x), [])
    : arr.slice()
}

// 迭代（避免深層遞迴爆堆疊）
function flattenIter(arr) {
  const stack = [...arr]
  const result = []
  while (stack.length) {
    const x = stack.pop()
    Array.isArray(x) ? stack.push(...x) : result.push(x)
  }
  return result.reverse()
}
```

### Q10. 實作 LRU Cache <Badge type="warning" text="進階" /> {#21-12-10}

**題目**：容量固定，`get` 和 `put` 都要 O(1)，超過容量時淘汰最久沒用的。

::: details 解題思路
`Map` 會保持插入順序：讀取時刪掉再重新插入，最新的就在尾端；淘汰時刪除第一個 key。
:::

::: details 標準答案與過程
```js
class LRUCache {
  constructor(capacity) {
    this.capacity = capacity
    this.map = new Map()
  }

  get(key) {
    if (!this.map.has(key)) return -1
    const value = this.map.get(key)
    this.map.delete(key)
    this.map.set(key, value)          // 移到最新
    return value
  }

  put(key, value) {
    if (this.map.has(key)) this.map.delete(key)
    this.map.set(key, value)
    if (this.map.size > this.capacity) {
      this.map.delete(this.map.keys().next().value) // 最舊的
    }
  }
}
```

傳統解法是「HashMap + 雙向鏈結串列」，面試官可能追問：用 Map 的版本依賴了插入順序的語言特性。前端應用：API 快取、Vue `KeepAlive` 的 `max`。
:::

### Q11. 扁平陣列轉成樹（選單、組織架構） <Badge type="tip" text="高頻" /> {#21-12-11}

**題目**：後端回傳 `{ id, parentId, name }` 的扁平陣列，轉成巢狀的選單樹，要求 O(n)。

::: details 解題思路
雙層迴圈找子節點是 O(n²)。改用 Map 建立 `id → 節點` 索引，走一次就能把每個節點掛到父節點上。
:::

::: details 標準答案與過程
```js
function listToTree(list, rootId = null) {
  const map = new Map(list.map(item => [item.id, { ...item, children: [] }]))
  const roots = []

  for (const node of map.values()) {
    const parent = map.get(node.parentId)
    if (node.parentId === rootId || !parent) roots.push(node) // 找不到父節點視為根
    else parent.children.push(node)
  }
  return roots
}

const menus = [
  { id: 1, parentId: null, name: '保單管理' },
  { id: 2, parentId: 1, name: '新契約' },
  { id: 3, parentId: 1, name: '保全變更' },
  { id: 4, parentId: null, name: '理賠' },
]
listToTree(menus)
// [{ id: 1, name: '保單管理', children: [{ id: 2 }, { id: 3 }] }, { id: 4, children: [] }]
```

延伸：反過來「樹轉扁平」用 DFS；依權限過濾樹時，子節點有權限就要保留父節點。
:::

### Q12. LazyMan（鏈式呼叫 + 任務佇列） <Badge type="warning" text="進階" /> {#21-12-12}

::: details 解題思路
每個方法只把任務放進佇列並回傳 `this`；建構時用 `setTimeout` 延後啟動，等鏈式呼叫全部登記完再依序執行。`sleepFirst` 插到佇列最前面。
:::

::: details 標準答案與過程
```js
class LazyManClass {
  #queue = []
  constructor(name) {
    this.#queue.push(() => { console.log(`Hi! This is ${name}!`); this.#next() })
    setTimeout(() => this.#next(), 0)
  }
  #next() { this.#queue.shift()?.() }
  #wait(s) {
    return () => setTimeout(() => { console.log(`Wake up after ${s}`); this.#next() }, s * 1000)
  }
  eat(food) {
    this.#queue.push(() => { console.log(`Eat ${food}~`); this.#next() })
    return this
  }
  sleep(s) { this.#queue.push(this.#wait(s)); return this }
  sleepFirst(s) { this.#queue.unshift(this.#wait(s)); return this }
}
const LazyMan = (name) => new LazyManClass(name)

LazyMan('Hank').sleepFirst(5).eat('supper')
// 等 5 秒 → Wake up after 5 → Hi! This is Hank! → Eat supper~
```
:::

### Q13. 帶指數退避的重試 <Badge type="tip" text="基礎" /> {#21-12-13}

::: details 標準答案與過程
```js
async function retry(fn, { retries = 3, base = 300, shouldRetry = () => true } = {}) {
  for (let attempt = 0; ; attempt++) {
    try {
      return await fn()
    } catch (err) {
      if (attempt >= retries || !shouldRetry(err)) throw err
      const delay = base * 2 ** attempt + Math.random() * base  // 退避 + 隨機抖動，避免大家同時重試
      await new Promise(r => setTimeout(r, delay))
    }
  }
}

await retry(() => fetchQuote(symbol), {
  shouldRetry: (e) => e.status >= 500 || e.name === 'TypeError', // 4xx 不重試
})
```

注意：只重試冪等的請求；非冪等請求（下單、付款）要帶 Idempotency-Key。
:::
