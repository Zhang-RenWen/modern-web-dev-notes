# 18-4 RegExp v 旗標 {#18-4}

`v` 旗標（unicodeSets 模式）是 `u` 旗標的升級版，讓字元類別（`[...]`）支援集合運算，以及比對由多個碼位組成的「字串屬性」。

- `v` 包含 `u` 的所有功能，兩者**不能同時使用**（`/x/uv` 會拋出 `SyntaxError`）。
- 可用 `regex.unicodeSets` 檢查是否啟用。

### 差集 `--`

```js
// 所有希臘字母，但排除 α、β、γ
const re = /[\p{Script=Greek}--[α-γ]]/v

re.test('δ') // true
re.test('α') // false
```

### 交集 `&&`

```js
// 同時是「字母」又是「ASCII」的字元
const asciiLetter = /^[\p{L}&&\p{ASCII}]$/v

asciiLetter.test('a') // true
asciiLetter.test('é') // false，é 是字母但不是 ASCII
asciiLetter.test('1') // false，1 是 ASCII 但不是字母
```

### 字串屬性：比對多碼位的 emoji

很多 emoji 其實由多個碼位組成，例如家庭 emoji 👨‍👩‍👧 是「男人＋ZWJ＋女人＋ZWJ＋女孩」。`\p{Emoji}` 一次只比對一個碼位，`v` 模式新增的 `\p{RGI_Emoji}` 則能把整個序列當成一個單位：

```js
const family = '👨‍👩‍👧'

/^\p{Emoji}$/u.test(family) // false
/^\p{RGI_Emoji}$/v.test(family) // true
```

### 字元類別中的字串 `\q{}`

```js
// 比對單一字元 a、b，或整個字串 "xyz"
const re = /^[ab\q{xyz}]$/v

re.test('a') // true
re.test('xyz') // true
re.test('x') // false
```

::: warning 語法差異
`v` 模式對字元類別的語法比較嚴格，部分在 `u` 模式中合法的寫法（例如在 `[]` 中未跳脫的 `(`、`)`、`[`、`{`、`}`、`/`、`-`、`|`）在 `v` 模式中必須跳脫，否則會拋出 `SyntaxError`。
:::
