# 1-2-2 實現置中 {#1-2-2}

::: info 改寫（2026-11）
原內容整理自 2019 年前的書籍，當時要顧及舊版 IE，所以列了很多 table、line-height 的技巧。現在 Flex 和 Grid 所有瀏覽器都支援，已改成「先選現代寫法，舊寫法看得懂就好」。
:::

## 先選這幾種 {#1-2-2-1}

| 情境 | 寫法 | 說明 |
| --- | --- | --- |
| 子元素在容器裡水平＋垂直置中 | `display: grid; place-items: center;` | 最短，子元素大小不用固定 |
| 同上，或有多個子元素要排成一列 | `display: flex; justify-content: center; align-items: center;` | 最常見 |
| 一般區塊容器，不想改成 Flex／Grid | `align-content: center;` | 2024 年起區塊容器也支援垂直置中 |
| 浮在其他內容上方（彈窗、遮罩上的 loading） | `position: absolute; inset: 0; margin: auto;` | 子元素要有寬高，或設 `width: fit-content` |
| 同上，但大小不固定 | `position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%);` | 尺寸是奇數 px 時文字可能模糊 |
| 只要水平置中一個區塊 | `margin-inline: auto;`（要有寬度） | |
| 行內內容（文字、圖片、按鈕） | 容器加 `text-align: center;` | |

```css
.wp { display: grid; place-items: center; }
```

## 舊寫法（看得懂就好） {#1-2-2-2}

維護舊專案時可能會遇到：

| 寫法 | 原理 | 為什麼不用了 |
| --- | --- | --- |
| `absolute` + `top: 50%` + 負 `margin`（寬高一半） | 先把左上角移到中心，再往回拉一半 | 要知道寬高，改尺寸就要改 margin |
| `absolute` + `calc(50% - 50px)` | 同上，用 `calc` 算 | 同上 |
| 容器 `line-height` 等於高度 + 子元素 `inline-block` + `vertical-align: middle` | 利用行內排版的垂直對齊 | 要寫死高度，還得把 `font-size` 設 0 消除空隙 |
| `<table>` 或 `display: table-cell` + `vertical-align: middle` | 表格儲存格天生能垂直置中 | 為了置中改變語意或排版模式，Flex 出現後就沒必要 |
