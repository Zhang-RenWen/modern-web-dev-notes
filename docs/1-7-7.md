# 1-7-7 前端架構類別庫之間的比較 {#1-7-7}

::: info 改寫（2026-11）
原內容整理自 2019 年前的書籍，比較的是 React 16 與 Vue 2（Vuex、`PureComponent`），並把 Vue 3 當成「即將發佈」。已更新為 React 19 與 Vue 3 的現況，加入 Svelte、Solid、Angular，濃縮成比較表。Vue 3 編譯期最佳化的細節移到 [1-7-5](./1-7-5.md#1-7-5-4)。
:::

## React 與 Vue {#1-7-7-1}

| 面向 | React | Vue 3 |
| --- | --- | --- |
| 怎麼知道要更新 | `setState` 後重新執行元件，比對虛擬 DOM | 響應式：渲染時自動收集依賴，資料變了只更新用到它的元件 |
| 資料 | 不可變：產生新物件才會觸發更新 | 可變：直接改 `state.count++` |
| 視圖寫法 | JSX（就是 JavaScript，彈性大） | 模板（編譯器能做靜態分析），也支援 JSX |
| 預設的更新範圍 | 父元件渲染時，子元件跟著渲染，要靠 `memo` 或 React Compiler 避開 | 依賴追蹤精準到元件，通常不需要手動最佳化 |
| 邏輯共用 | 自訂 Hooks | Composables（Composition API） |
| 父子溝通 | props 往下、callback 往上 | props 往下、`emit` 事件往上 |
| 跨層傳值 | Context | `provide`／`inject` |
| 雙向綁定 | 沒有，受控元件自己寫 `value` + `onChange` | `v-model` 語法糖（底層仍是單向資料流加事件） |
| 狀態管理 | 社群方案多：Redux Toolkit、Zustand、Jotai | 官方 Pinia（取代 Vuex） |
| 路由與周邊 | 社群：React Router、TanStack Router | 官方：Vue Router |
| 全端框架 | Next.js、React Router 7 | Nuxt |
| 伺服器端 | Server Components | SSR／SSG；Vapor Mode（不用虛擬 DOM 的編譯模式）開發中 |

**雙向綁定和單向資料流是不同層次的事**：雙向綁定說的是「資料 ↔ 輸入框」之間；單向資料流說的是「元件之間」資料只從父到子。Vue 兩個都有，React 只有後者。

## 其他框架 {#1-7-7-2}

| 框架 | 特色 |
| --- | --- |
| Angular | 完整框架（路由、表單、HTTP、DI 全內建）、TypeScript 優先；v16 起改用 Signals，逐步拿掉 Zone.js |
| Svelte | 編譯器框架，沒有虛擬 DOM；Svelte 5 改用 runes（Signals） |
| Solid | 寫法像 React 的 JSX，但用 Signals 精準更新 DOM，元件函式只執行一次 |
| Qwik | 「可恢復」（resumability）：不做 hydration，互動時才載入對應的程式碼 |

近年的共同方向：**Signals**（細粒度響應式）、**更多事情交給編譯器**、**伺服器端優先**（Server Components、Islands）。

## 怎麼選 {#1-7-7-3}

- 團隊已經熟的那個，通常就是最好的選擇；框架之間的效能差距對大多數產品不是瓶頸。
- 需要大量第三方套件、招募容易、要做 React Native：React。
- 想要官方一條龍（路由、狀態管理、建置工具都由同一團隊維護）、模板對設計師友善：Vue。
- 大型企業內部系統、團隊習慣強型別與嚴格結構：Angular。
- 內容網站：Astro（可以混用各框架的元件）。

## 看新版本要看什麼 {#1-7-7-4}

讀框架的 changelog 和 RFC，不只是學新 API，而是問「為什麼要改」：

- Vue 3 改用 Proxy：因為 `defineProperty` 偵測不到新增屬性和陣列索引（見 [1-7-1](./1-7-1.md#1-7-1-2)）。
- Vue 3 把動態節點和靜態節點分開：讓更新成本只跟動態內容的數量有關。
- React 從 class 走向 Hooks：因為生命週期把同一件事拆散在好幾個方法裡。
- React 推出 Compiler：因為手寫 `useMemo`／`useCallback` 太容易漏掉或寫錯。

能回答這些「為什麼」，靠的是基礎：`this` 綁定、閉包、原型、事件迴圈、瀏覽器渲染（第 1-3、1-5 節）。
