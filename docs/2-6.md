# 2-6 let 和 const 敘述

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。已精簡，並修正原筆記把「重新賦值 const 會被忽略」寫成正常輸出的錯誤：實際上會丟出 `TypeError`。
:::

`var` 是**函式作用域**而且會提升：在 `if` 區塊裡宣告的變數，整個函式都看得到。

```js
function isItTwo(value) {
  if (value === 2) {
    var two = true
  }
  return two // 不會報錯：var 被提升到函式開頭，值是 undefined
}
isItTwo('two') // undefined
```

## 2-6-1 區塊作用域與 let {#2-6-1}

`let`、`const` 只在所在的 `{}` 區塊（`if`、`for`、`while`、單純的 `{}`）裡有效：

```js
{
  let inner = 1
}
console.log(inner) // ReferenceError: inner is not defined
```

在 `for` 迴圈裡，`let` 每一輪都會建立新的變數，所以非同步的 callback 拿到的是當輪的值：

```js
for (var i = 0; i < 3; i++) setTimeout(() => console.log(i)) // 3 3 3：共用同一個 i
for (let j = 0; j < 3; j++) setTimeout(() => console.log(j)) // 0 1 2：每輪各自一個 j
```

詳細解釋與動畫見 [1-3-2 閉包](./1-3-2.md#1-3-2-4)。

## 2-6-2 暫時性死區 {#2-6-2}

`let`、`const` 也會提升，但在宣告那一行執行之前不能使用，這段區間叫**暫時性死區（TDZ）**，讀取會丟 `ReferenceError`。

```js
function readName() {
  return name // 函式定義時不檢查，呼叫時才看 name 初始化了沒
}
readName()  // ReferenceError：此時還在 TDZ
let name = 'Stephen Hawking'
readName()  // 'Stephen Hawking'
```

TDZ 讓「宣告前誤用」直接報錯，而不是像 `var` 一樣默默得到 `undefined`。

## 2-6-3 const {#2-6-3}

和 `let` 一樣是區塊作用域、有 TDZ，另外：

- **宣告時一定要給值**：`const e` 是語法錯誤。
- **不能重新賦值**：`people = []` 會丟 `TypeError: Assignment to constant variable`。

::: warning const 鎖的是「綁定」，不是內容
```js
const people = ['Tesla', 'Musk']
people.push('Berners-Lee') // 可以：陣列本身沒有被凍結
people = []                // TypeError
```

要讓內容也不能改，用 `Object.freeze`（只凍結一層，巢狀物件要遞迴凍結）：

```js
const frozen = Object.freeze(['Ice', 'Icicle'])
frozen.push('Water') // TypeError: Cannot add property 2, object is not extensible
```
:::

## 2-6-4 怎麼選 {#2-6-4}

**預設用 `const`，需要重新賦值才用 `let`，不用 `var`。**

- 看到 `const` 就知道這個變數之後不會指向別的東西，讀程式時少一件要追蹤的事；不小心重新賦值會直接報錯。
- `let` 明確表示「這個變數會變」，例如計數器、累加值。
- `var` 的函式作用域與提升讓變數可以在宣告前使用、在區塊外存取，容易出錯；全域的 `var` 還會變成 `window` 的屬性。

```js
const items = ['a', 'b', 'c']
const todo = checklist(items)
items = ['d', 'e'] // 用 const 宣告，這行直接報錯，不會讓 todo 和 items 悄悄指向不同的陣列
```
