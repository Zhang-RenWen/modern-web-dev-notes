## 把抽象概念變成視覺 {#1-15-2-1}

- 轉譯鏈：**概念/情緒 → 視覺隱喻 → 幾何語言 → 動態語言 → 渲染技術**。例：資金流向科技業 → 粒子沿曲線流動、節點膨脹、科技業形成 attractor → Canvas particle system。
- 拆解作品：**Reference → Principle → Parameter → Implementation**，不要只收藏圖片。
- 視覺詞彙四維度：背景（Grid、Noise、Gradient、Particle）× 主體（Sphere、Node、Line、Typography）× Motion（Float、Pulse、Flow、Distort）× Effect（Glow、Glass、Refraction、Trail）。
- 靈感來源：自然物理、數學（Perlin noise、Voronoi、vector field）、工業儀表（HUD、雷達、金融 Terminal）、攝影構圖、設計風格（Swiss、Brutalism、Y2K）。
- Creative Coding = 設計語言 × 數學/物理 × 程式 × Rendering。

## 建立自己的 visual-lab（收藏「可重用效果」而不是素材檔） {#1-15-2-2}

```txt
visual-library/
  svg/      morph/ filters/ masks/ patterns/
  d3/       charts/ financial/(yield-curve, spread, correlation, anomaly)
            interactions/(zoom, brush, tooltip, crosshair) animation/
  canvas/   particles/
```

- 第一批：Morph、Draw Path、Gooey、Displacement、Noise、Wave、Mask Reveal、Gradient Motion。
- 做一次的圖表封裝成 `createTimeSeriesChart({ data, zoom, crosshair, anomaly })`，下次直接組合。公開出來就是作品集。

## 需要的數學（按需求補，不必先背） {#1-15-2-3}

- 入門圖表：線性函數 mapping（`scaleLinear` 的 domain → range）、座標幾何。
- 圓餅/雷達/弧線：三角函數、極座標 x = r·cosθ、y = r·sinθ。
- 動畫：插值 f(t) = (1−t)·A + t·B；easing 就是函數曲線。
- 力導向圖、旋轉：向量、矩陣。進階：貝茲曲線、圖論、統計分布。
- WebGL 3D：線性代數（矩陣變換、點積叉積）、投影矩陣、光照模型。AI 能生成模型，但調整、除錯與客製仍需要數學。
- XR 門檻主要在 3D 數學、渲染效能與空間思維；前端切入點是 WebXR / Three.js 的展示型作品。

線性代數的幾何直覺見 [1-12-4](./1-12-4.md)。

## 作品集網頁 Prompt（Three.js 電影風） {#1-15-2-5}

出處：https://www.threads.com/share/FzpbhKK98/

```txt
你是一位資深的 WebGL / Three.js 互動前端工程師與創意技術指導。
請用我上傳的素材製作一個作品集網頁：

【首頁】
- 全螢幕循環播放 hero.mp4（靜音自動播放，右下角可開聲音）
- 影片用 Three.js 著色器渲染，加上跟隨滑鼠的互動效果
- 中央大標題 + 一個「進入作品集」按鈕
- 按下後用全螢幕著色器轉場進入作品頁（往下捲動也能進入）

【作品頁】
- 每件作品先顯示靜態原畫（w1.jpg）
- 點一下，從點擊位置開始用著色器轉場變成動態影片（w1.mp4）
- 再點一下回到靜態
- 每件作品有標題、一句簡介、規格（解析度 / 秒數 / fps）、放大觀看按鈕
- 第一件作品放大橫跨整排，其餘兩兩一排

【技術要求】
- Three.js 用 cdnjs 的 r128 版本
- 不支援 WebGL 時，退回一般的圓形展開轉場
- 手機版改為單欄
- 支援鍵盤操作與 prefers-reduced-motion

【風格】
好萊塢史詩奇幻預告片風格：黑底、寬銀幕黑邊、Cinzel 字體、
底片顆粒、變形鏡頭光斑、底片燒穿轉場。
```
