# 19-4 Promise.try() {#19-4}

執行一個函式，並把結果包成 Promise。不論函式是**同步回傳**、**同步拋出錯誤**，還是**回傳 Promise**，都能統一用 `.then()` / `.catch()` 處理。

```js
function getUser(id) {
  if (!id) throw new Error('id 為必填') // 同步拋出錯誤
  return fetch(`/api/users/${id}`) // 回傳 Promise
}

// 問題：同步拋出的錯誤不會進入 .catch()，而是直接中斷程式
getUser('').then(render).catch(showError) // Uncaught Error: id 為必填

// ES2025：同步錯誤也會變成 rejected Promise
Promise.try(() => getUser('')).then(render).catch(showError)
```

也可以把參數直接傳給 `Promise.try()`：

```js
Promise.try(getUser, userId).then(render).catch(showError)
```

### 和其他寫法的差別

```js
// 1. Promise.resolve().then(fn)：fn 會延後到下一個微任務才執行
Promise.resolve().then(() => getUser(id))

// 2. new Promise()：可以達到同樣效果，但比較冗長
new Promise((resolve) => resolve(getUser(id)))

// 3. Promise.try()：同步執行 fn，錯誤也會被捕捉
Promise.try(() => getUser(id))
```

`Promise.try()` 和第 2 種寫法等價，而且會**立即同步**呼叫函式，不像第 1 種會延遲執行。
