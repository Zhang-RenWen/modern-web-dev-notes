# 19-3 Import Attributes 與 JSON Modules {#19-3}

Import Attributes 讓 `import` 敘述可以附加額外資訊，告訴執行環境要如何載入模組。第一個標準化的用途是 JSON Modules：直接 `import` JSON 檔案。

```js
import config from './config.json' with { type: 'json' }

console.log(config.apiUrl)
```

動態載入與重新匯出也支援：

```js
// 動態 import()：第二個參數傳入 { with: {...} }
const { default: data } = await import('./data.json', { with: { type: 'json' } })

// 重新匯出
export { default as config } from './config.json' with { type: 'json' }
```

### 為什麼一定要寫 `type: 'json'`

瀏覽器以伺服器回傳的 MIME 類型判斷檔案內容。如果只寫 `import config from './config.json'`，而伺服器（或被入侵的 CDN）回傳的是 `text/javascript`，這個「JSON 檔」就會被當成程式碼執行。明確寫出 `type: 'json'` 後，執行環境會確認回應真的是 JSON，否則載入失敗，避免這類安全問題。

### 注意事項

- JSON 模組只有 `default` 匯出，不能用具名匯入，例如 `import { apiUrl } from './config.json' with { type: 'json' }` 會出錯。
- 同一個 JSON 模組在整個應用程式中只會載入一次，所有匯入的地方拿到的是同一個物件。修改它會影響其他地方。

::: warning 舊語法 assert 已被取代
早期的實作（例如 Chrome、Node.js 曾經支援的版本）使用的是 `assert { type: 'json' }`。標準化時改為 `with`，`assert` 已被棄用並陸續從瀏覽器與 Node.js 移除，請改用 `with`。
:::
