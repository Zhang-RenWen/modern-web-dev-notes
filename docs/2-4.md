# 2-4 其餘參數和展開運算子

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。修正原筆記範例的錯誤（`join` 傳錯分隔字串、字串展開結果漏掉空白、箭頭函式其餘參數的寫法），補上 ES2018 的物件展開。
:::

同樣是 `...`，**放在接收端是「其餘」（收集成陣列），放在提供端是「展開」（攤開成一個個值）**。

### 2-4-1 其餘參數 {#2-4-1}

取代 `arguments`（類陣列，不能直接用陣列方法，箭頭函式也沒有）：

```js
function join(separator, ...list) {
  return list.join(separator)
}
join('; ', 'first', 'second') // 'first; second'：已命名的參數不會進 list

const sumAll = (...numbers) => numbers.reduce((total, n) => total + n, 0) // 箭頭函式要加括號
```

其餘參數只能放在最後一個。

### 2-4-2 展開運算子 {#2-4-2}

可以展開任何**可迭代**的東西（陣列、字串、`Set`、`Map`、`arguments`、`NodeList`）：

```js
[...'ab c']                   // ['a', 'b', ' ', 'c']
['left', ...'abc', 'right']   // ['left', 'a', 'b', 'c', 'right']
[1, ...[2, 3], 4]             // [1, 2, 3, 4]
[...new Set([1, 1, 2])]       // [1, 2]：去重

Math.max(...[3, 9, 4])        // 9：把陣列當成多個參數
new Date(...[2015, 11, 31])   // ES5 要寫 new (Date.bind.apply(Date, [null, 2015, 11, 31]))
```

物件展開（ES2018）走的不是迭代器，而是複製自己的可列舉屬性：`{ ...defaults, ...overrides }`。

| 情境 | ES5 | 現在 |
| --- | --- | --- |
| 合併陣列 | `[1, 2].concat(more)` | `[1, 2, ...more]` |
| 把多個元素推進陣列 | `list.push.apply(list, items)` | `list.push(...items)` |
| 取第一個與其餘 | `a = list[0]; rest = list.slice(1)` | `const [a, ...rest] = list` |
| 類陣列轉陣列 | `Array.prototype.slice.call(arguments)` | `[...arguments]` 或 `Array.from(x)` |
| 複製並修改物件 | `Object.assign({}, obj, { a: 1 })` | `{ ...obj, a: 1 }` |

注意：

- 展開是**淺拷貝**，巢狀物件仍共用參考；需要深拷貝用 `structuredClone`。
- 展開很大的陣列當函式參數（`Math.max(...hugeArray)`）可能超過引擎的參數數量上限而報錯，這時改用 `reduce` 或迴圈。
