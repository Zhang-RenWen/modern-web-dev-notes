## 長期要熟的清單 {#1-1-7-1}

```txt
Flex / Grid / gap / place-items
aspect-ratio / object-fit / picture + srcset
rem / em / dvh / svh / cqi
clamp() / min() / max() / calc()
:is / :where / :has / :not
CSS variables（design tokens、一鍵換主題）
box-sizing reset / text-overflow ellipsis
border vs outline / box-shadow vs drop-shadow
transform + opacity 動畫
border-radius / clip-path / mask-image / backdrop-filter

```

## 容易講錯的觀念 {#1-1-7-2}

- Flex 主軸上 `justify-content: stretch` 不會撐開 item，要用 `flex: 1`。
- `:is()` 取裡面最高 specificity；`:where()` specificity 為 0，適合 reset 與基礎樣式。
- `!important` 不是 specificity，是 cascade 中較高優先級的宣告；只用於覆蓋第三方、utility、hotfix。
- 動畫優先 transform / opacity（較易走 compositor），改 left/top/width 易觸發 layout；但效能仍看 DOM 數量、陰影、濾鏡。
- `box-shadow` 照矩形框；`filter: drop-shadow()` 照 PNG/SVG 透明輪廓。
- `border` 佔空間；`outline` 不佔 layout，適合 `:focus-visible`。
- `overflow: hidden` 是硬切，`mask-image` 是柔切漸隱。
- 巢狀圓角：**外層 radius ≈ 內層 radius + padding**，否則間距看起來不均。
- 不要 `* { margin: 0; padding: 0 }` 全清，會影響表單與文章；用 `box-sizing: border-box` + `body { margin: 0 }`。
- `backdrop-filter` / 玻璃擬態適合品牌頁，不適合資料表與金融後台長列表。
- 層疊上下文不只 z-index：opacity 小於 1、transform、filter、position fixed/sticky、isolation 都會建立新的層疊上下文。z-index 最大值 2147483647（32 位元有號整數）。
- 長陰影：多層 `text-shadow` 每層位移 1px 堆疊；用 SCSS `@for` 迴圈生成。

## shape-outside（雜誌排版用，知道即可） {#1-1-7-3}

- 定義 **float** 元素周圍文字如何繞排，必須搭配 `float`。
- 圖片輪廓靠的是 **Alpha 透明通道**，不是 PNG 副檔名；JPG 沒有透明所以仍是矩形。
- `shape-margin` 控制間距，`shape-image-threshold` 控制透明度門檻；也支援 `circle()`、`ellipse()`、`polygon()`。
