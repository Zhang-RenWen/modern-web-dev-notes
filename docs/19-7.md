# 19-7 重複的命名匹配群組 {#19-7}

以前在同一個正規表示式中，命名匹配群組的名稱不能重複，即使它們位於 `|` 的不同分支也不行。ES2025 起，**不同分支**中可以使用相同的群組名稱。

```js
// 同時支援 2026-11 與 11/2026 兩種格式
const re = /(?<year>\d{4})-(?<month>\d{2})|(?<month>\d{2})\/(?<year>\d{4})/

'2026-11'.match(re).groups // { year: '2026', month: '11' }
'11/2026'.match(re).groups // { year: '2026', month: '11' }
```

以前只能取不同的名稱（例如 `year1`、`year2`），再自己判斷是哪一個有值。

### 限制

同一個分支中仍然不能重複，因為那樣同一次比對會有兩個值：

```js
/(?<x>a)(?<x>b)/ // SyntaxError: Duplicate capture group name
```

命名反向參考 `\k<name>` 會參考到實際比對成功的那個分支中的群組。
