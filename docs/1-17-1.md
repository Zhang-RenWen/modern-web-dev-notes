# 1-17-1 Linux 指令與排查 {#1-17-1}

::: info 新增（2026-11）
整理自 Notion「開發工具與 DevOps」第 5 節〈Linux〉。發行版比較見 [1-16-4](./1-16-4.md)。

**學習順序**：檔案 → 權限 → 文字處理 → 網路 → Process → systemd → Observability。目標不是背指令，而是能回答：服務跑在哪、log 在哪、port 有沒有開、process 活著嗎、為什麼不能寫檔。

| 等級 | 指令 |
| --- | --- |
| **A 必學** | ls cd pwd cp mv rm mkdir cat less head tail(-f) grep find xargs chmod chown du df tar zip/unzip ps top htop kill ping curl ssh scp rsync systemctl journalctl |
| **B 進階** | awk sed jq sort uniq wc tee stat file ln lsof strace ss ip dig mtr tcpdump iostat vmstat pidstat sar tmux nohup crontab |
| **C 效能 / SRE** | perf bcc bpftrace opensnoop execsnoop biolatency ftrace dmesg |
| **現代替代** | ifconfig→ip、netstat→ss、nslookup→dig、traceroute→mtr、telnet→ssh/nc、ftp→sftp/rsync、which→type/command -v、grep→rg、find→fd、md5sum→sha256sum |

- **Log 分析套路**：`grep "ERROR" access.log | sort | uniq -c | sort -nr`
- **權限排查**：不只看 `ls -l`，還要 `namei -l /path`（上層目錄沒通行權也會失敗）、`getfacl`。
- **危險**：腳本裡 `rm -rf $DIR/*`，若 `$DIR` 為空會刪錯東西。
- **重要目錄**：`/etc` 設定、`/var/log` log、`/proc` `/sys` kernel 虛擬資訊、`/tmp`、`/opt`。現代多數發行版已 usr-merge（`/bin` → `/usr/bin`）。
- **發行版**：Debian/Ubuntu（雲端主流）、RHEL / Rocky / Alma（CentOS Linux 已 EOL 的替代）、Alpine（Docker image 常見）、NixOS（可重現環境）。
- **效能排查要分層**：CPU（top、pidstat、perf）→ Memory（free、vmstat）→ Disk I/O（iostat、iotop）→ Network（ss、tcpdump）→ Syscall 卡住（strace、lsof）→ Kernel（eBPF）。不是只看 top。
