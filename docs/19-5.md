# 19-5 RegExp.escape() {#19-5}

把字串中所有在正規表示式裡有特殊意義的字元跳脫，讓它可以安全地放進 `new RegExp()`。以前每個專案都要自己寫一個 `escapeRegExp()` 函式。

```js
const keyword = '(1+1)'

// 沒有跳脫：( ) + 被當成正規表示式語法
new RegExp(keyword).test('答案是 (1+1)') // false

// ES2025
new RegExp(RegExp.escape(keyword)).test('答案是 (1+1)') // true

RegExp.escape('(1+1)') // '\\(1\\+1\\)'
RegExp.escape('.*') // '\\.\\*'
```

### 實際應用：搜尋並標示使用者輸入的關鍵字

```js
function highlight(text, keyword) {
  const re = new RegExp(RegExp.escape(keyword), 'gi')
  return text.replace(re, (match) => `<mark>${match}</mark>`)
}

highlight('價格 $9.99，原價 $19.99', '$9.99') // '價格 <mark>$9.99</mark>，原價 $19.99'
```

::: info 開頭的英數字也會被跳脫
如果字串**開頭**是數字或英文字母，會被轉成 `\x` 形式，例如 `RegExp.escape('abc')` 會得到 `'\\x61bc'`。這是為了避免和前面的跳脫序列黏在一起（例如接在 `\1` 後面變成另一個反向參考），結果仍然只會比對到原本的字串。
:::
