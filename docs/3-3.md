# 3-3 物件的內建功能強化

::: info 改寫（2026-11）
整理自《Practical Modern JavaScript》（2017）。修正原筆記第一個範例 `Object.assign(defaults, options)` 會改到 `defaults` 的錯誤；補上 2017 年之後加入的 `Object.entries`／`fromEntries`／`hasOwn`／`groupBy`。
:::

### 3-3-1 Object.assign 與物件展開 {#3-3-1}

把多個物件的屬性依序複製到第一個物件，同名屬性後面的覆蓋前面的：

```js
const defaults = { script: false, highlight: true }

function md(input, options) {
  const config = Object.assign({}, defaults, options) // 第一個參數要給新物件
  // 寫成 Object.assign(defaults, options) 會直接改掉 defaults，下一次呼叫就帶著上次的設定
}
```

現在多半直接用物件展開（ES2018），效果相同、比較好讀：

```js
const config = { ...defaults, ...options }
const grocery = { type: 'fruit', ...details, color: 'red' }
```

- 只複製**自己的、可列舉的**屬性（包含 Symbol 鍵），不複製原型上的。
- **淺拷貝**：巢狀物件直接整個被覆蓋，不會合併。`Object.assign({}, { a: { b: 1 } }, { a: { c: 2 } })` 的結果是 `{ a: { c: 2 } }`。需要深層合併用 lodash 的 `merge`，需要深拷貝用 `structuredClone`。
- 差別：`Object.assign` 對目標物件是**賦值**（會觸發 setter），展開是**定義新屬性**。

搭配其餘屬性，可以把已知欄位和其他欄位分開：

```js
const { name, type, ...meta } = { name: 'Carrot', type: 'vegetable', color: 'orange' }
meta // { color: 'orange' }
```

### 3-3-2 Object.is {#3-3-2}

和 `===` 幾乎一樣，只差兩個特殊值：

```js
NaN === NaN            // false
Object.is(NaN, NaN)    // true
+0 === -0              // true
Object.is(+0, -0)      // false
```

React 比較 state 和 Hook 依賴陣列時用的就是 `Object.is`。

### 3-3-3 Object.setPrototypeOf {#3-3-3}

```js
const baseCat = { type: 'cat', legs: 4 }
const cat = Object.create(baseCat)                         // 建立時就指定原型：推薦
const cat2 = Object.setPrototypeOf({ name: 'Dot' }, baseCat) // 事後改原型：避免
```

事後修改原型會讓 JS 引擎放棄針對這個物件的最佳化，所以盡量在建立時就用 `Object.create` 決定原型。

### 3-3-4 後來加入的常用方法 {#3-3-4}

| 方法 | 版本 | 用途 |
| --- | --- | --- |
| `Object.entries(obj)`、`Object.values(obj)` | ES2017 | 取得 `[鍵, 值]` 陣列，方便用陣列方法處理 |
| `Object.fromEntries(entries)` | ES2019 | 反過來，把 `[鍵, 值]` 陣列或 `Map` 變回物件 |
| `Object.hasOwn(obj, key)` | ES2022 | 取代 `obj.hasOwnProperty(key)`，對 `Object.create(null)` 的物件也能用 |
| `Object.groupBy(items, fn)` | ES2024 | 依回傳值分組 |

```js
// 篩選物件的屬性
const prices = { apple: 30, banana: 10, cherry: 80 }
const expensive = Object.fromEntries(Object.entries(prices).filter(([, p]) => p > 20))
// { apple: 30, cherry: 80 }

Object.groupBy([1, 2, 3, 4], (n) => (n % 2 ? 'odd' : 'even')) // { odd: [1, 3], even: [2, 4] }
```
